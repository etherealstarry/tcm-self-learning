    生理学 学习指南¶

    生理学是研究人体正常功能的学科——解剖学告诉你"人体是什么样"，生理学告诉你"人体怎么工作"。 这门课的特点是"机制多、流程图多"，要理解，不能只背。

    为什么这门课特别重要？¶

    • 执业医师考试占分约8-10%
    • 病理学、药理学、诊断学的基础——不懂生理，怎么理解病理？怎么理解药理？
    • 临床必备——生理指标（如血压、血糖、血气）是临床诊断的基础

    核心理论：生理学的四大基本过程¶

    过程 解释 举例
    物质代谢 物质的合成与分解 糖代谢、脂肪代谢、蛋白质代谢
    能量代谢 能量的生成与利用 ATP生成、基础代谢率
    信息传递 神经、内分泌调节 神经冲动传导、激素作用
    自我调节 稳态的维持 血压调节、血糖调节、体温调节

    重点内容详解¶

    1. 细胞生理（细胞膜的物质转运）¶

    细胞膜的物质转运方式（必背）¶

    方式 特点 举例
    单纯扩散 顺浓度差，不需要载体和能量 O₂、CO₂、乙醇
    易化扩散 顺浓度差，需要载体或通道，不需要能量 葡萄糖（载体）、Na⁺（通道）
    主动转运 逆浓度差，需要载体和能量 Na⁺-K⁺泵（最重要）
    胞吞/胞吐 大分子物质转运，需要能量 蛋白质、神经递质

    Na⁺-K⁺泵（最重要）

    • 每水解1分子ATP，泵出3个Na⁺，泵入2个K⁺
    • 维持细胞膜内外Na⁺、K⁺浓度差（膜电位的基础）
    • 抑制Na⁺-K⁺泵 → 细胞肿胀、坏死

    2. 血液生理¶

    血细胞的生成和调节（必背）¶

    血细胞 寿命 生成调节 功能
    红细胞 120天 促红细胞生成素（EPO） 运输O₂、CO₂
    白细胞 几天到几年 多种细胞因子 免疫防御
    血小板 7-14天 血小板生成素（TPO） 止血、凝血

    凝血机制（重点掌握）¶

    凝血因子（12个，罗马数字I-XII）：

    • 内源性凝血途径：血管内膜损伤 → 激活XII因子 → ... → 激活X因子
    • 外源性凝血途径：组织损伤 → 释放III因子 → ... → 激活X因子
    • 共同途径：激活X因子 → 凝血酶原（II）→ 凝血酶 → 纤维蛋白原（I）→ 纤维蛋白（凝血块）

    维生素K的作用

    维生素K是II、VII、IX、X因子合成必需的辅酶。

    维生素K缺乏 → 这些因子合成障碍 → 凝血障碍（出血倾向）。

    3. 循环生理（心脏、血管、心血管调节）¶

    心脏的泵血功能（重点掌握）¶

    心动周期（0.8秒）：

    心房收缩期（0.1秒）
        ↓
心室收缩期（0.3秒）
    ├── 等容收缩期（0.05秒）
    ├── 快速射血期（0.1秒）
    └── 减慢射血期（0.15秒）
        ↓
心室舒张期（0.5秒）
    ├── 等容舒张期（0.05秒）
    ├── 快速充盈期（0.11秒）
    └── 减慢充盈期（0.22秒）

    心输出量（重点掌握）¶

    • 每搏输出量（SV）：一侧心室每次搏动射出的血量（约70ml）
    • 心输出量（CO）：每分钟一侧心室射出的血量（CO = SV × HR，约5L/min）
    • 影响因素：
    • 前负荷（心室舒张末期容积）↑ → SV ↑
    • 后负荷（动脉血压）↑ → SV ↓
    • 心肌收缩力 ↑ → SV ↑
    • 心率（HR）↑ → CO ↑（但HR过快 → 充盈时间↓ → CO ↓）

    心血管活动的调节（重点掌握）¶

    神经调节：

    系统 受体 作用 举例
    交感神经 β₁受体 心率↑、心肌收缩力↑、传导↑ 肾上腺素
    迷走神经 M受体 心率↓、心肌收缩力↓、传导↓ 乙酰胆碱

    体液调节：

    物质 作用 机制
    肾上腺素 心率↑、心肌收缩力↑、血管（皮肤、肾）收缩 激动α、β受体
    去甲肾上腺素 血管（全身）收缩、血压↑ 激动α受体为主
    血管紧张素II 血管强烈收缩、血压↑、醛固酮分泌↑ 肾素-血管紧张素系统
    血管升压素（ADH） 血管（全身）收缩、血压↑、水重吸收↑ 下丘脑-神经垂体

    4. 呼吸生理¶

    肺的通气功能（重点掌握）¶

    肺容积和肺容量：

    指标 定义 正常值
    潮气量（TV） 平静呼吸时每次吸入或呼出的气量 500ml
    补吸气量（IRV） 平静吸气后再尽力吸气所能吸入的气量 1500-2000ml
    补呼气量（ERV） 平静呼气后再尽力呼气所能呼出的气量 900-1200ml
    残气量（RV） 最大呼气后肺内残留的气量 1000-1500ml
    肺活量（VC） 最大吸气后所能呼出的最大气量（VC = TV + IRV + ERV） 3500-4500ml
    功能残气量（FRC） 平静呼气末肺内残留的气量（FRC = ERV + RV） 2300ml
    肺总容量（TLC） 肺所能容纳的最大气量（TLC = VC + RV） 5000ml

    气体交换（重点掌握）¶

    气体分压（海平面）：

    气体 空气（mmHg） 肺泡气（mmHg） 动脉血（mmHg） 静脉血（mmHg）
    O₂ 159 104 100 40
    CO₂ 0.3 40 40 46

    影响气体交换的因素：

    • 气体分压差（主要动力）
    • 气体溶解度（CO₂溶解度是O₂的24倍）
    • 扩散面积（肺炎、肺不张 → 面积↓ → 交换↓）
    • 扩散距离（肺纤维化、肺水肿 → 距离↑ → 交换↓）

    5. 消化生理¶

    消化液的分泌（重点掌握）¶

    消化液 分泌量（L/天） pH 主要成分 作用
    唾液 1-1.5 6.6-7.1 淀粉酶 湿润、初步消化
    胃液 1.5-2.5 0.9-1.5 盐酸、胃蛋白酶原、内因子 杀菌、消化、吸收维生素B₁₂
    胰液 1-2 7.8-8.4 淀粉酶、脂肪酶、蛋白酶 消化（最重要）
    胆汁 0.8-1 7.4 胆盐、胆固醇、胆色素 乳化脂肪（不含消化酶）
    小肠液 1-3 7.6 多种酶 消化

    吸收（重点掌握）¶

    各部位吸收的物质：

    部位 吸收的物质
    口腔、食管 无明显吸收
    胃 酒精、少量水
    小肠（最主要） 葡萄糖、氨基酸、脂肪酸、甘油、水、电解质、维生素
    大肠 水、电解质、维生素K（肠道菌群合成）

    为什么小肠是吸收的主要部位？

    1. 面积大（皱襞、绒毛、微绒毛 → 表面积约200m²）
    2. 时间长（食糜在小肠停留3-8小时）
    3. 酶多（胰液、小肠液含多种消化酶）
    4. 血流丰富（利于物质转运）

    6. 泌尿生理（肾的排泄功能）¶

    尿的生成过程（重点掌握）¶

    血液 → 肾小球滤过 → 原尿（180L/天）
                ↓
    肾小管重吸收 → 终尿（1.5L/天）
                ↓
    肾小管分泌 → 终尿（排出体外）

    肾小球滤过功能（重点掌握）¶

    滤过率（GFR）： 每分钟两侧肾生成的原尿量（约125ml/min）

    影响滤过的因素：

    因素 变化 对GFR的影响
    肾小球毛细血管血压 ↑ GFR ↑
    囊内压 ↑（如尿路梗阻） GFR ↓
    血浆胶体渗透压 ↑（如脱水） GFR ↓
    肾血浆流量 ↑ GFR ↑

    肾小管重吸收（重点掌握）¶

    物质 重吸收部位 重吸收率 机制
    葡萄糖 近曲小管 100%（肾糖阈：血糖180mg/dl） 继发性主动转运
    Na⁺ 近曲小管（67%）、髓袢、远曲小管 99% 主动转运
    水 近曲小管（67%）、髓袢、集合管 99% 渗透作用（跟随Na⁺）
    HCO₃⁻ 近曲小管 99% 与H⁺结合，以CO₂形式重吸收

    7. 神经生理¶

    神经元的功能（重点掌握）¶

    神经冲动的传导：

    • 静息电位：-70mV（K⁺外流）
    • 动作电位：去极化（Na⁺内流）→ 复极化（K⁺外流）→ 后电位
    • 传导速度：有髓纤维 > 无髓纤维；粗纤维 > 细纤维

    突触传递（重点掌握）：

    动作电位到达突触前膜
        ↓
Ca²⁺内流
        ↓
突触小泡与前膜融合
        ↓
神经递质释放（胞吐）
        ↓
递质与突触后膜受体结合
        ↓
突触后电位（EPSP或IPSP）
        ↓
总和 → 动作电位（或抑制）

    神经递质（重点掌握）¶

    递质 合成部位 作用 灭活方式
    乙酰胆碱（ACh） 胆碱能神经元 兴奋（N受体）、抑制（M受体） 乙酰胆碱酯酶水解
    去甲肾上腺素（NE） 肾上腺素能神经元 兴奋（α、β受体） 重摄取、COMT/MAO降解
    多巴胺（DA） 多巴胺能神经元 调节运动、情绪 重摄取、COMT/MAO降解
    5-羟色胺（5-HT） 5-羟色胺能神经元 调节睡眠、情绪 重摄取、MAO降解
    γ-氨基丁酸（GABA） GABA能神经元 抑制（最重要抑制性递质） 重摄取、GABA转氨酶降解

    8. 内分泌生理¶

    下丘脑-垂体系统（重点掌握）¶

    下丘脑-腺垂体系统：

    下丘脑释放激素 腺垂体激素 靶腺/靶组织 作用
    TRH TSH 甲状腺 促进甲状腺激素分泌
    CRH ACTH 肾上腺皮质 促进糖皮质激素分泌
    GnRH FSH、LH 性腺 促进性激素分泌
    GHRH GH 全身 促进生长
    PRH PRL 乳腺 促进泌乳

    下丘脑-神经垂体系统：

    神经垂体激素 合成部位 作用
    血管升压素（ADH） 下丘脑视上核 促进水重吸收（抗利尿）
    催产素 下丘脑室旁核 促进子宫收缩、泌乳

    学习进度规划¶

    阶段 内容 时间
    第一阶段 细胞生理 + 血液生理 3天
    第二阶段 循环生理（心脏、血管、调节） 5天
    第三阶段 呼吸生理（通气、换气、运输） 3天
    第四阶段 消化生理（分泌、吸收） 3天
    第五阶段 泌尿生理（滤过、重吸收、分泌） 3天
    第六阶段 神经生理（神经元、突触、递质） 5天
    第七阶段 内分泌生理（下丘脑-垂体、靶腺） 3天
    第八阶段 复习 + 做真题 5天

    常见学习误区¶

    误区1：只背名词，不理解机制

    知道"心输出量"是什么，但不知道"怎么调节"——这是无效学习。

    正确做法： 每个生理过程都要画流程图，理解"输入 → 过程 → 输出 → 调节"。

    误区2：不背"正常值"

    生理指标的正常值是临床诊断的基础，不能不背。

    正确做法： 制作"生理指标正常值表"，每天背10个。

    误区3：忽略"调节机制"

    生理学的核心是"调节"——负反馈、正反馈、前馈。

    正确做法： 每个生理过程都要掌握"调节机制"（谁调节？怎么调节？）。

    自测习题¶

    ??? question "1. 患者血糖250mg/dl，尿中出现葡萄糖。为什么？" 答案： 血糖超过肾糖阈（180mg/dl），肾小管对葡萄糖的重吸收达到极限（转运极限），多余的葡萄糖随尿排出。

    **解析：** 葡萄糖的重吸收是**继发性主动转运**，需要载体（SGLT）。血糖过高 → 尿中葡萄糖浓度过高 → 载体饱和 → 重吸收达到极限 → 尿中出现葡萄糖。

    ??? question "2. 患者大量失血，血压下降至80/50mmHg。机体如何调节血压？" 答案： 主要通过压力感受性反射（减压反射）和肾素-血管紧张素系统。

    **解析：** 血压↓ → 压力感受器传入冲动↓ → 心交感紧张↑、心迷走紧张↓ → 心率↑、心肌收缩力↑ → 血压回升。同时，肾血流↓ → 肾素分泌↑ → 血管紧张素II生成↑ → 血管收缩、血压↑。

    ??? question "3. 患者缺氧（PaO₂ 50mmHg），CO₂潴留（PaCO₂ 60mmHg）。呼吸如何调节？" 答案： 主要刺激外周化学感受器（颈动脉体、主动脉体），使呼吸加深加快。

    **解析：** CO₂正常时，呼吸调节主要靠**中枢化学感受器**（对H⁺敏感，CO₂能通过血脑屏障，但H⁺不能）。但CO₂潴留时，中枢化学感受器适应 → 主要靠外周化学感受器。

    ??? question "4. 患者尿量减少（500ml/天），血Na⁺正常，血K⁺正常。最可能的原因是什么？" 答案： 血管升压素（ADH）分泌过多（如手术创伤、疼痛、恶心等刺激ADH分泌）。

    **解析：** ADH促进水的重吸收。ADH分泌过多 → 水重吸收↑ → 尿量减少（低渗尿）。血Na⁺正常（因为水重吸收↑，但Na⁺重吸收不↑ → 血Na⁺被稀释，但尿量太少，血Na⁺变化不大）。

    📝 自测习题¶

    ??? question "1. 静息电位和动作电位的离子基础分别是什么？" 答案： - 静息电位：主要是 K⁺ 外流 形成的（K⁺ 顺浓度梯度外流，膜内变负） - 动作电位去极化：主要是 Na⁺ 内流（Na⁺ 通道开放，Na⁺ 快速内流） - 动作电位复极化：主要是 K⁺ 外流

    **记忆：** 静息=K⁺出，去极=Na⁺入，复极=K⁺出。

    ??? question "2. 血浆渗透压包括哪两部分？各有什么生理意义？" 答案： - 晶体渗透压（主要由 NaCl 形成）：维持 细胞内外的水平衡，保持细胞正常形态 - 胶体渗透压（主要由白蛋白形成）：维持 血管内外的水交换，防止组织水肿

    **临床意义：** 低蛋白血症（白蛋白↓）→ 胶体渗透压↓ → 组织水肿。

    ??? question "3. 动脉血压的形成条件是什么？" 答案： 动脉血压形成需要 四个条件： - 前提条件：足够的血液充盈 - 必要条件：心脏射血 - 外周阻力：小动脉和微动脉的阻力 - 大动脉弹性储器作用：缓冲收缩压、维持舒张压

    **公式：** 平均动脉压 ≈ 舒张压 + 1/3 脉压

    ??? question "4. 影响心输出量的因素有哪些？" 答案： 心输出量 = 每搏输出量 × 心率

    **影响每搏输出量的因素：**
- **前负荷**（心室舒张末期容积）→  Frank-Starling 定律：前负荷↑ → 心肌初长度↑ → 收缩力↑
- **后负荷**（动脉血压）→ 后负荷↑ → 等容收缩期↑ → 每搏输出量↓
- **心肌收缩能力**（等长调节）→ 交感神经↑、Ca²⁺↑ → 收缩力↑

    ??? question "5. 呼吸的全过程包括哪几个环节？" 答案： 呼吸全过程包括 三个相互联系的环节： - 外呼吸：肺通气（肺与外界气体交换）+ 肺换气（肺泡与血液气体交换） - 气体在血液中的运输 - 内呼吸：组织细胞与血液之间的气体交换

    **临床意义：** 任何环节障碍 → 呼吸衰竭。

    ??? question "6. 影响肾小球滤过的因素有哪些？" 答案： - 有效滤过压（主要因素）= 肾小球毛细血管血压 -（血浆胶体渗透压 + 肾小囊内压） - 肾血浆流量：流量↑ → 滤过↑ - 滤过膜：面积↓或通透性↑ → 滤过异常（如肾炎时蛋白尿）

    **记忆：** 三高（高压、高流量、高通透性）→ 滤过↑；二低（低蛋白、低压）→ 滤过↓。

    ??? question "7. 胰岛素的生理作用是什么？缺乏时会出现什么？" 答案： - 胰岛素的作用：降低血糖（促进组织摄取葡萄糖、促进糖原合成、抑制糖异生） - 还促进：脂肪合成、蛋白质合成 - 缺乏时：胰岛素↓ → 血糖↑↑ → 糖尿病（1型=绝对缺乏；2型=相对缺乏+抵抗）

    **临床意义：** 胰岛素过量 → 低血糖休克（出冷汗、心悸、昏迷）。

    ??? question "8. 交感神经和副交感神经的功能有何不同？举例说明。" 答案：

    | 器官 | 交感神经（应激状态） | 副交感神经（安静状态） |
|------|-------------------|-------------------|
| 心脏 | 心率↑、收缩力↑ | 心率↓、收缩力↓ |
| 支气管 | 扩张（利于通气） | 收缩（利于排痰） |
| 消化管 | 抑制（血管收缩、蠕动↓） | 促进（蠕动↑、消化液分泌↑） |
| 瞳孔 | 扩大（视远物） | 缩小（视近物） |
| 汗腺 | 分泌↑（出汗） | 无作用 |

**记忆：** 交感="战斗或逃跑"；副交感="休息和消化"。
