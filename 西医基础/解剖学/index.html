    正常人体解剖学 学习指南¶

    解剖学是医学的基石——不认识人体结构，怎么诊断？怎么治病？ 这门课的特点是"名词多、结构多、要背的要死"，但也是有方法的。

    为什么这门课特别重要？¶

    • 执业医师考试占分约5-8%
    • 所有医学课程的基础——生理学、病理学、诊断学、内科学都要用到解剖学
    • 临床必备——不看懂解剖，怎么看CT、MRI？

    核心理论：人体的组成¶

    人体的九大系统（必背）¶

    系统 组成 功能
    运动系统 骨、关节、骨骼肌 支持、保护、运动
    消化系统 消化道、消化腺 摄取、消化、吸收、排泄
    呼吸系统 呼吸道、肺 气体交换
    泌尿系统 肾、输尿管、膀胱、尿道 生成和排泄尿液
    生殖系统 内生殖器、外生殖器 生殖
    循环系统 心脏、血管、淋巴 运输物质、免疫
    神经系统 中枢神经、周围神经 调节、控制
    内分泌系统 内分泌腺 调节、控制
    感觉系统 眼、耳、鼻、舌、皮肤 感受刺激

    重点内容详解¶

    1. 运动系统（骨学、关节学、肌学）¶

    骨学（206块骨，重点掌握）¶

    躯干骨：

    骨骼 数量 特点
    椎骨 26块（颈椎7、胸椎12、腰椎5、骶骨1、尾骨1） 椎孔连成椎管，容纳脊髓
    肋骨 12对 第1-7对为真肋，第8-10对为假肋，第11-12对为浮肋
    胸骨 1块 分胸骨柄、胸骨体、剑突三部分

    颅骨（23块）：

    骨骼 组成 特点
    脑颅骨 8块（额、顶、枕、颞各2，蝶、筛各1） 围成颅腔，保护脑
    面颅骨 15块（上颌、腭、颧、鼻、泪、下鼻甲各2，犁、下颌、舌各1） 构成面部支架

    四肢骨：

    部位 骨骼 特点
    上肢骨 锁骨、肩胛骨、肱骨、尺骨、桡骨、腕骨（8）、掌骨（5）、指骨（14） 肩关节灵活，肘关节稳定
    下肢骨 髋骨、股骨、髌骨、胫骨、腓骨、跗骨（7）、跖骨（5）、趾骨（14） 髋关节稳定，膝关节灵活

    关节学（重点掌握）¶

    关节 类型 运动 特点
    肩关节 球窝关节 前屈、后伸、外展、内收、旋转 最灵活，最不稳定
    肘关节 铰链关节 屈、伸 稳定，易脱位
    髋关节 球窝关节 前屈、后伸、外展、内收、旋转 稳定，承重
    膝关节 屈戌关节 屈、伸、旋转（屈曲时） 最大，最复杂
    椎间盘 纤维软骨关节 前屈、后伸、侧屈、旋转 缓冲震荡

    肌学（重点掌握）¶

    躯干肌：

    肌肉 起点 止点 作用 神经支配
    胸大肌 胸骨、锁骨 肱骨大结节 内收、内旋上臂 胸内、外侧神经
    背阔肌 胸椎、腰椎 肱骨小结节 后伸、内收、内旋上臂 胸背神经
    膈肌 胸骨、肋骨 中心腱 呼吸（吸气） 膈神经

    四肢肌：

    肌肉 起点 止点 作用 神经支配
    三角肌 肩胛骨 肱骨 外展上臂 腋神经
    肱二头肌 肩胛骨 桡骨 屈肘、前臂旋后 肌皮神经
    肱三头肌 肩胛骨、肱骨 尺骨 伸肘 桡神经
    股四头肌 髂骨、股骨 胫骨 伸膝 股神经
    股二头肌 坐骨、股骨 腓骨 屈膝、屈髋 坐骨神经

    2. 消化系统¶

    消化道（重点掌握）¶

    部位 结构特点 功能
    口腔 牙、舌、唾液腺 咀嚼、初步消化
    咽 鼻咽、口咽、喉咽 吞咽
    食管 三个狭窄（起始处、与左主支气管交叉处、穿膈处） 输送食物
    胃 贲门、胃底、胃体、幽门 储存、消化（胃酸分泌）
    小肠 十二指肠（25cm）、空肠（2m）、回肠（3m） 消化、吸收
    大肠 盲肠、阑尾、结肠、直肠、肛管 吸收水分、形成粪便

    消化腺（重点掌握）¶

    腺体 位置 分泌物 功能
    唾液腺 腮腺、下颌下腺、舌下腺 唾液（淀粉酶） 湿润、初步消化
    肝 右上腹 胆汁 乳化脂肪、代谢、解毒
    胆囊 肝下面 储存胆汁 浓缩胆汁
    胰 腹膜后 胰液（淀粉酶、脂肪酶、蛋白酶） 消化

    3. 呼吸系统¶

    呼吸道（重点掌握）¶

    部位 结构特点 功能
    鼻 外鼻、鼻腔、鼻窦 加温、加湿、过滤空气
    咽 鼻咽、口咽、喉咽 通道
    喉 会厌、声带 发声、保护气道
    气管 C形软骨环 通道
    支气管 树状分支 通道
    肺 肺泡（气体交换场所） 气体交换

    肺的结构（重点掌握）¶

    • 肺叶：右肺3叶（上、中、下），左肺2叶（上、下）
    • 肺段：右肺10段，左肺8段
    • 肺泡：气体交换场所，表面积约70m²

    4. 泌尿系统¶

    肾的结构（重点掌握）¶

    结构 功能
    肾单位（100万个/肾） 滤过、重吸收、分泌
    肾小球 滤过（形成原尿）
    肾小管 重吸收、分泌（形成终尿）
    集合管 浓缩尿液

    尿液的生成（重点掌握）¶

    血液 → 肾小球滤过 → 原尿（180L/天）
                ↓
    肾小管重吸收 → 终尿（1.5L/天）
                ↓
    集合管浓缩 → 终尿（排出体外）

    5. 循环系统¶

    心脏的结构（重点掌握）¶

    结构 功能
    右心房 接收静脉血
    右心室 泵静脉血到肺
    左心房 接收动脉血
    左心室 泵动脉血到全身
    瓣膜 防止血液反流（二尖瓣、三尖瓣、主动脉瓣、肺动脉瓣）

    血管的走向（重点掌握）¶

    体循环：左心室 → 主动脉 → 全身毛细血管 → 上、下腔静脉 → 右心房
肺循环：右心室 → 肺动脉 → 肺毛细血管 → 肺静脉 → 左心房

    6. 神经系统¶

    中枢神经（脑、脊髓）¶

    脑的结构：

    部位 功能
    大脑 高级神经活动（思维、记忆、语言）
    小脑 平衡、协调运动
    脑干（中脑、脑桥、延髓） 生命中枢（呼吸、心跳）
    间脑（丘脑、下丘脑） 感觉传导、内分泌调节

    脊髓的结构：

    • 灰质（蝴蝶形）：神经细胞体
    • 白质（周围）：神经纤维
    • 脊髓节段：31节（颈8、胸12、腰5、骶5、尾1）

    周围神经（脑神经、脊神经）¶

    脑神经（12对，重点掌握）：

    神经 性质 功能
    嗅神经（I） 感觉 嗅觉
    视神经（II） 感觉 视觉
    动眼神经（III） 运动 眼球运动（除外直肌、上斜肌）
    滑车神经（IV） 运动 眼球运动（上斜肌）
    三叉神经（V） 混合 面部感觉、咀嚼肌运动
    外展神经（VI） 运动 眼球运动（外直肌）
    面神经（VII） 混合 面部表情肌运动、味觉（前2/3）
    前庭蜗神经（VIII） 感觉 听觉、平衡觉
    舌咽神经（IX） 混合 咽部感觉、味觉（后1/3）
    迷走神经（X） 混合 内脏感觉、运动（最重要）
    副神经（XI） 运动 胸锁乳突肌、斜方肌运动
    舌下神经（XII） 运动 舌肌运动

    脊神经（31对）：

    • 颈神经8对、胸神经12对、腰神经5对、骶神经5对、尾神经1对
    • 前支：形成神经丛（颈丛、臂丛、腰丛、骶丛）
    • 后支：支配背部肌肉和皮肤

    学习进度规划¶

    阶段 内容 时间
    第一阶段 运动系统（骨学、关节学、肌学） 7天
    第二阶段 消化系统 + 呼吸系统 5天
    第三阶段 泌尿系统 + 生殖系统 3天
    第四阶段 循环系统（心脏、血管） 5天
    第五阶段 神经系统（中枢神经、周围神经） 7天
    第六阶段 内分泌系统 + 感觉系统 3天
    第七阶段 复习 + 做真题 5天

    常见学习误区¶

    误区1：只背名词，不理解位置

    知道"肱骨"是什么，但不知道在哪——这是无效学习。

    正确做法： 每个骨骼、每个肌肉都要在图谱上找，在自己身上摸。

    误区2：不背神经支配

    肌肉的神经支配是考试重点，不能只背肌肉起止点、不背神经支配。

    正确做法： 每个肌肉都要掌握"起点 + 止点 + 作用 + 神经支配"，四者缺一不可。

    误区3：忽略"临床意义"

    解剖学不是"死记硬背"，要知道每个结构的临床意义。

    正确做法： 学每个结构都要问"这个结构损伤了会怎样？"

    推荐学习资源¶

    类型 资源 特点
    教材 《系统解剖学》（人卫版） 考试标准
    图谱 《格氏解剖学图谱》 图文对照，便于记忆

    APP Complete Anatomy（3D解剖模型） 帮助理解空间结构
    习题 执业医师考试真题（解剖部分） 熟悉考试套路

    自测习题¶

    ??? question "1. 患者肩部外伤，肩峰下方凹陷（方肩畸形）。损伤了哪条神经？哪块肌肉瘫痪？" 答案： 腋神经损伤，三角肌瘫痪。

    **解析：** 三角肌受腋神经支配，三角肌瘫痪 → 肩峰下方凹陷（方肩畸形）。

    ??? question "2. 患者伸肘无力，腕下垂。损伤了哪条神经？" 答案： 桡神经损伤。

    **解析：** 肱三头肌（伸肘）和前臂伸肌（伸腕）都受桡神经支配 → 伸肘无力 + 腕下垂 = 桡神经损伤。

    ??? question "3. 患者右下肢瘫痪，右 Babinski 征阳性。病变在哪？" 答案： 左侧大脑运动皮层（或左侧锥体束）。

    **解析：** 运动传导通路是"交叉支配"——左侧大脑支配右侧身体。右下肢瘫痪 → 病变在左侧。

    ??? question "4. 患者吞咽困难，声音嘶哑。损伤了哪条神经？" 答案： 迷走神经损伤（喉返神经分支）。

    **解析：** 吞咽（咽肌）和发声（喉肌）都受迷走神经支配 → 吞咽困难 + 声音嘶哑 = 迷走神经损伤。

    📝 自测习题¶

    ??? question "1. 人体解剖学的标准姿势是什么？方位术语有哪些？" 答案： - 标准姿势（解剖学姿势）：身体直立，面向前，两眼平视正前方，上肢下垂于躯干两侧，手掌向前，两足并拢，足尖向前 - 方位术语：上（颅侧）/下（尾侧）、前（腹侧）/后（背侧）、内侧/外侧、内/外、浅/深、近侧/远侧（用于四肢）

    **为什么重要？** 描述任何结构位置，都必须以**解剖学姿势**为标准，不能按人体实际姿势描述！

    ??? question "2. 骨的基本结构和功能是什么？骨的分类有哪些？" 答案： - 基本结构：骨质（骨密质+骨松质）、骨膜（营养、生长、修复）、骨髓（红骨髓=造血；黄骨髓=脂肪）、血管神经 - 功能：支持、保护、运动杠杆、造血、钙磷储存 - 分类：长骨（肢骨）、短骨（腕骨、跗骨）、扁骨（颅骨、胸骨）、不规则骨（椎骨、颌骨）

    **临床意义：** 红骨髓是成人唯一的**终身造血组织**（除长骨骨骺两端、扁骨、不规则骨外，其他红骨髓会脂肪化）。

    ??? question "3. 关节的基本结构和辅助结构是什么？" 答案： - 基本结构（必备）：关节面（覆盖关节软骨）、关节囊（纤维层+滑膜层）、关节腔（负压，维持稳定） - 辅助结构（可有可无）：韧带（加强稳定）、关节盘（缓冲、增加适配性）、关节唇（加深关节窝）

    **临床意义：** 关节炎 = 滑膜炎症 → 关节液增多 → 关节肿胀、疼痛。

    ??? question "4. 脊柱的构成和生理弯曲是什么？临床意义？" 答案： - 构成：7 颈椎 + 12 胸椎 + 5 腰椎 + 骶骨（5 块融合）+ 尾骨（3-5 块融合）= 26 块椎骨 - 生理弯曲：颈曲（前凸）、胸曲（后凸）、腰曲（前凸）、骶曲（后凸） - 临床意义：生理弯曲增大了脊柱的弹性，缓冲行走、跳跃时的震荡；颈曲/腰曲是前凸的，支撑头颅和躯干重心

    **记忆：** 新生儿只有胸曲和骶曲，颈曲/腰曲是出生后抬头、站立才形成的。

    ??? question "5. 胸廓的构成和胸骨的角（Louis 角）有什么临床意义？" 答案： - 胸廓构成：12 块胸椎 + 12 对肋 + 胸骨 + 肋间肌和结缔组织 - 胸骨角（Louis 角）：胸骨柄和胸骨体连接处，微向前凸 - 临床意义（超重要！）：① 平对第 2 肋 → 计数肋骨的标志；② 平对第 4 胸椎体下缘；③ 气管分叉处；④ 上下纵隔分界平面

    **记忆：** 胸骨角 = 临床计数肋骨的"金标准"——找不到肋骨时，先找胸骨角！

    ??? question "6. 膈肌的裂孔有哪些？各通过什么结构？" 答案： - 主动脉裂孔（T12 水平）：主动脉 + 胸导管通过 - 食管裂孔（T10 水平）：食管 + 迷走神经通过 - 腔静脉孔（T8 水平）：下腔静脉通过

    **记忆口诀：** "主 12，食 10，腔 8"——数字代表椎体水平。

    ??? question "7. 腹股沟管的结构和内容物是什么？临床意义？" 答案： - 位置：腹股沟韧带内侧半上方 1.5cm 处，腹股沟韧带和耻骨结节之间 - 内容物：男性 = 精索通过；女性 = 子宫圆韧带通过 - 临床意义：腹股沟管是腹壁的薄弱区 → 腹腔内容物（肠管、大网膜）突入 → 腹股沟疝（斜疝从深环突入，直疝从腹股沟三角突入）

    **记忆：** 腹股沟疝 = 肠管"掉进"腹股沟管 → 阴囊或大阴唇处可见包块。

    ??? question "8. 体循环和肺循环的路径分别是什么？" 答案： - 体循环（大循环）：左心室 → 主动脉 → 各级动脉 → 全身毛细血管（物质交换）→ 各级静脉 → 上/下腔静脉 → 右心房 - 肺循环（小循环）：右心室 → 肺动脉 → 肺毛细血管（气体交换）→ 肺静脉 → 左心房

    **功能区别：** 体循环 = 输送氧气和营养物质到全身；肺循环 = 在肺进行气体交换（排 CO₂、摄 O₂）。
