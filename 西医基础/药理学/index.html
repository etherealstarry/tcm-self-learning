    药理学 学习指南¶

    药理学是研究药物与机体相互作用的学科——"药物怎么作用于机体"（药效学）、"机体怎么作用于药物"（药动学）。 这门课的特点是"受体 + 信号通路"，要理解机制，不能只背药名。

    为什么这门课特别重要？¶

    • 执业医师考试占分约8-10%
    • 临床用药的基础——不懂药理，怎么开药？怎么避免不良反应？
    • 中西医结合的关键——中药、西药都要懂

    核心理论：药效学和药动学¶

    药效学（药物怎么作用于机体）¶

    概念 定义 举例
    激动剂 与受体结合后，产生生物效应 肾上腺素（激动β₁受体 → 心率↑）
    拮抗剂 与受体结合后，不产生生物效应（阻断激动剂的作用） 普萘洛尔（阻断β受体 → 心率↓）
    治疗指数（TI） LD₅₀/ED₅₀（安全范围） TI越大，药物越安全
    效能 药物产生的最大效应 吗啡的效能 > 哌替啶
    效价强度 产生相同效应所需的剂量 吗啡的效价强度 > 哌替啶

    药动学（机体怎么作用于药物）¶

    吸收 → 分布 → 代谢 → 排泄
    过程 影响因素 临床意义
    吸收 给药途径（口服、注射、吸入）、剂型、食物 口服最常用，但首过效应大；注射起效快，但不便
    分布 血浆蛋白结合率、组织亲和力、血脑屏障 血浆蛋白结合率高的药物，游离药物少，作用弱
    代谢 肝药酶（CYP450） 肝药酶诱导剂（如苯巴比妥）→ 加速其他药物代谢；肝药酶抑制剂（如西咪替丁）→ 减慢其他药物代谢
    排泄 肾（主要）、胆汁、肺、乳汁 肾功能不全 → 药物排泄↓ → 易蓄积中毒

    重点内容详解¶

    1. 传出神经系统药理（重点掌握）¶

    传出神经的受体和效应（必背）¶

    受体 分布 效应 激动剂 拮抗剂
    α₁ 血管（皮肤、肾）、瞳孔开大肌 血管收缩、瞳孔扩大 去甲肾上腺素 哌唑嗪
    α₂ 突触前膜（负反馈调节） 抑制去甲肾上腺素释放 可乐定 育亨宾
    β₁ 心脏 心率↑、心肌收缩力↑、传导↑ 去甲肾上腺素、多巴酚丁胺 普萘洛尔、美托洛尔
    β₂ 支气管、血管（骨骼肌） 支气管舒张、血管舒张 沙丁胺醇 普萘洛尔
    M 心脏、平滑肌、腺体 心率↓、支气管收缩、腺体分泌↑ 毛果芸香碱 阿托品
    N 神经节、骨骼肌 神经节兴奋、骨骼肌收缩 尼古丁 筒箭毒碱（N₂）、六甲双铵（N₁）

    传出神经系统药物的分类（重点掌握）¶

    分类 作用 代表药 临床应用
    拟胆碱药 激动M、N受体 毛果芸香碱（M激动）、新斯的明（抗胆碱酯酶） 青光眼（毛果芸香碱）、重症肌无力（新斯的明）
    抗胆碱药 阻断M受体 阿托品 内脏绞痛、虹膜睫状体炎、有机磷中毒
    拟肾上腺素药 激动α、β受体 肾上腺素（α、β）、去甲肾上腺素（α）、异丙肾上腺素（β） 心脏骤停（肾上腺素）、过敏性休克（肾上腺素）
    抗肾上腺素药 阻断α、β受体 酚妥拉明（α阻断）、普萘洛尔（β阻断） 高血压（普萘洛尔）、心绞痛（普萘洛尔）

    2. 心血管系统药理（重点掌握）¶

    抗高血压药（重点掌握）¶

    分类 代表药 作用机制 不良反应
    利尿药 氢氯噻嗪 排Na⁺、水 → 血容量↓ → 血压↓ 低K⁺、高尿酸
    ACEI 卡托普利 抑制血管紧张素II生成 → 血管舒张 干咳（缓激肽蓄积）、高K⁺
    ARB 氯沙坦 阻断血管紧张素II受体 → 血管舒张 不引起干咳
    钙通道阻滞药 硝苯地平 阻断Ca²⁺内流 → 血管舒张 面部潮红、踝部水肿
    β受体阻断药 普萘洛尔 阻断β受体 → 心率↓、心肌收缩力↓ 支气管痉挛、心动过缓
    α受体阻断药 哌唑嗪 阻断α₁受体 → 血管舒张 首剂现象（体位性低血压）

    抗心绞痛药（重点掌握）¶

    分类 代表药 作用机制 临床应用
    硝酸酯类 硝酸甘油 释放NO → 血管舒张 → 心肌耗氧量↓ 各型心绞痛（首选）
    β受体阻断药 普萘洛尔 阻断β受体 → 心率↓、心肌收缩力↓ → 心肌耗氧量↓ 稳定型心绞痛（不宜用于变异型）
    钙通道阻滞药 硝苯地平 阻断Ca²⁺内流 → 血管舒张、心肌耗氧量↓ 变异型心绞痛（首选）

    抗心律失常药（重点掌握）¶

    心律失常的电生理机制：

    • 冲动形成异常（自律性↑）
    • 冲动传导异常（折返、传导阻滞）

    抗心律失常药的分类（Vaughan Williams分类）：

    分类 代表药 作用机制 临床应用
    I类（钠通道阻滞药） 奎尼丁（IA）、利多卡因（IB）、普罗帕酮（IC） 阻滞Na⁺内流 → 传导↓ 各种心律失常
    II类（β受体阻断药） 普萘洛尔 阻断β受体 → 自律性↓、传导↓ 窦性心动过速、房颤
    III类（延长APD药） 胺碘酮 阻滞K⁺外流 → APD↑ → ERP↑ 各种心律失常（广谱）
    IV类（钙通道阻滞药） 维拉帕米 阻滞Ca²⁺内流 → 房室结传导↓ 室上性心动过速（首选）

    3. 中枢神经系统药理（重点掌握）¶

    全身麻醉药（了解）¶

    分类 代表药 特点
    吸入麻醉药 异氟烷、七氟烷 诱导快、恢复快、可控性好
    静脉麻醉药 硫喷妥钠、丙泊酚 诱导快、恢复快、但可控性差

    镇静催眠药（重点掌握）¶

    分类 代表药 作用机制 特点
    苯二氮䓬类（BZ） 地西泮（安定） 激动GABAₐ受体 → Cl⁻内流↑ → 超极化 抗焦虑、镇静、催眠、抗惊厥、中枢性肌松（安全范围大，中毒可用氟马西尼解救）
    巴比妥类 苯巴比妥 激动GABAₐ受体（结合位点不同） 镇静、催眠、抗惊厥（安全范围小，易成瘾）

    抗癫痫药（重点掌握）¶

    癫痫类型 首选药
    部分性发作 卡马西平
    全面性强直-阵挛发作（大发作） 苯妥英钠
    失神发作（小发作） 乙琥胺
    癫痫持续状态 地西泮（静脉注射）
    混合型 丙戊酸钠（广谱）

    抗精神病药（重点掌握）¶

    分类 代表药 作用机制 不良反应
    典型抗精神病药（第一代） 氯丙嗪 阻断D₂受体 锥体外系反应（EPS）、催乳素↑
    非典型抗精神病药（第二代） 利培酮、奥氮平 阻断D₂ + 5-HT₂受体 EPS少，但代谢综合征风险↑

    抗抑郁药（重点掌握）¶

    分类 代表药 作用机制 特点
    三环类（TCA） 丙咪嗪 抑制NE、5-HT再摄取 疗效好，但不良反应多（抗胆碱、心血管）
    选择性5-HT再摄取抑制剂（SSRI） 氟西汀、帕罗西汀 抑制5-HT再摄取 疗效好，不良反应少（一线用药）
    选择性NE再摄取抑制剂（NRI） 瑞波西汀 抑制NE再摄取 疗效中等
    5-HT和NE再摄取抑制剂（SNRI） 文拉法辛 抑制5-HT、NE再摄取 疗效好，适用于严重抑郁

    4. 内分泌系统药理（重点掌握）¶

    糖皮质激素（重点掌握）¶

    生理作用：

    • 代谢：升糖、分解蛋白质、重新分布脂肪（向心性肥胖）
    • 抗炎：抑制炎症介质（PG、LT）、稳定溶酶体膜
    • 免疫抑制：抑制免疫细胞、减少抗体生成
    • 抗休克：扩张血管、改善微循环

    临床应用：

    • 替代治疗（肾上腺皮质功能减退症）
    • 抗炎（风湿病、肾小球肾炎）
    • 免疫抑制（器官移植、自身免疫病）
    • 抗休克（感染性休克）

    不良反应：

    • 类肾上腺皮质功能亢进症（满月脸、水牛背、向心性肥胖）
    • 诱发或加重感染
    • 消化系统并发症（溃疡）
    • 骨质疏松、股骨头坏死
    • 停药反应（医源性肾上腺皮质功能不全、反跳现象）

    胰岛素（重点掌握）¶

    作用：

    • 降糖（促进葡萄糖利用、抑制葡萄糖生成）
    • 促蛋白合成
    • 促脂肪合成

    临床应用：

    • 1型糖尿病（首选，终身使用）
    • 2型糖尿病（口服降糖药无效、并发症、应激状态）

    不良反应：

    • 低血糖（最常见、最严重）
    • 过敏反应
    • 胰岛素抵抗
    • 脂肪萎缩（注射部位）

    学习进度规划¶

    阶段 内容 时间
    第一阶段 药效学 + 药动学（基本概念） 2天
    第二阶段 传出神经系统药理（受体、效应、药物） 5天
    第三阶段 心血管系统药理（降压、抗心绞痛、抗心律失常） 5天
    第四阶段 中枢神经系统药理（镇静催眠、抗癫痫、抗精神病、抗抑郁） 5天
    第五阶段 内分泌系统药理（糖皮质激素、胰岛素） 3天
    第六阶段 抗菌药物（青霉素、头孢、大环内酯类、喹诺酮类） 5天
    第七阶段 复习 + 做真题 5天

    常见学习误区¶

    误区1：只背药名，不理解机制

    知道"普萘洛尔"是β受体阻断药，但不知道"为什么能降压"——这是无效学习。

    正确做法： 每个药物都要掌握"作用机制 → 药理作用 → 临床应用 → 不良反应"，四位一体。

    误区2：不背"禁忌症"

    药物的禁忌症是临床安全用药的关键，不能不背。

    正确做法： 每个药物都要掌握"禁忌症"（如普萘洛尔禁用于支气管哮喘）。

    误区3：忽略"药物相互作用"

    多种药物合用，可能发生相互作用（协同、拮抗、不良反应增加）。

    正确做法： 重点掌握常见药物的相互作用（如强心苷 + 排K⁺利尿药 → 心律失常）。

    自测习题¶

    ??? question "1. 患者支气管哮喘，不宜使用哪种药物？为什么？" 答案： 不宜使用普萘洛尔（β受体阻断药）。因为普萘洛尔阻断β₂受体 → 支气管收缩 → 加重哮喘。

    **解析：** β受体阻断药的禁忌症：支气管哮喘、严重心衰、心动过缓。因为阻断β₂受体 → 支气管收缩；阻断β₁受体 → 心肌抑制。

    ??? question "2. 患者高血压，伴糖尿病、蛋白尿。首选哪类降压药？为什么？" 答案： 首选ACEI（如卡托普利）或ARB（如氯沙坦）。

    **解析：** ACEI/ARB不仅能降压，还能**减少尿蛋白、延缓肾损害**（糖尿病肾病首选）。但ACEI可引起干咳（缓激肽蓄积），ARB不引起干咳。

    ??? question "3. 患者癫痫全面性强直-阵挛发作（大发作）。首选药？作用机制？" 答案： 首选苯妥英钠。作用机制：阻滞Na⁺内流 → 细胞膜稳定 → 神经元兴奋性↓ → 抗癫痫。

    **解析：** 各型癫痫的首选药不同：部分性发作（卡马西平）、大发作（苯妥英钠）、小发作（乙琥胺）、癫痫持续状态（地西泮 iv）、混合型（丙戊酸钠）。

    ??? question "4. 患者感染性休克，血压60/40mmHg。首选药？为什么？" 答案： 首选肾上腺素（或去甲肾上腺素）。

    **解析：** 感染性休克的血压维持：去甲肾上腺素（激动α受体 → 血管收缩 → 血压↑）是首选。肾上腺素用于心脏骤停、过敏性休克。

    📝 自测习题¶

    ??? question "1. 阿托品的药理作用、临床应用和不良反应是什么？" 答案： - 药理作用：M 受体阻断剂 → 抑制腺体分泌、散瞳、加快心率、松弛平滑肌 - 临床应用：麻醉前给药（减少呼吸道分泌）、有机磷中毒解救、缓慢性心律失常、内脏绞痛 - 不良反应：口干、视力模糊、心悸、皮肤潮红（过量→ 阿托品中毒：昏迷、呼吸麻痹）

    **记忆：** 阿托品的作用是"抗胆碱"→ 所有胆碱能效应都被阻断。

    ??? question "2. 肾上腺素的临床应用有哪些？为什么是抢救过敏性休克的首选？" 答案： - 临床应用：心脏骤停、过敏性休克（首选！）、支气管哮喘急性发作、局部止血（与局麻药合用延长麻醉时间） - 为什么是过敏性休克首选？ 过敏性休克的病理是：小血管扩张 + 毛细血管通透性↑ + 支气管痉挛。肾上腺素能：① 兴奋 α 受体 → 收缩血管、升高血压；② 兴奋 β₂ 受体 → 扩张支气管、缓解呼吸困难

    **记忆：** 过敏性休克 = 血压掉 + 喘不过气 → 肾上腺素"升压 + 平喘"双管齐下。

    ??? question "3. 青霉素的抗菌机制是什么？过敏反应怎么预防？" 答案： - 抗菌机制：抑制细菌细胞壁粘肽的合成（与 PBPs 结合→ 细胞壁缺损→ 细菌膨胀裂解） - 为什么对 G⁺ 菌强？ G⁺ 菌细胞壁粘肽层厚，青霉素作用靶点多 - 过敏反应预防：① 询问过敏史；② 做皮试（用药前必须！）；③ 备好肾上腺素（抢救过敏性休克）

    **临床意义：** 青霉素过敏是临床最常见、最严重的药物过敏 → 必须皮试！

    ??? question "4. 糖皮质激素的药理作用、临床应用和不良反应分别是什么？" 答案： - 药理作用：抗炎（抑制炎症介质）、免疫抑制、抗毒（提高机体对细菌内毒素的耐受）、抗休克、允许作用（增强儿茶酚胺的缩血管作用） - 临床应用：严重感染（中毒性感染）、自身免疫病、过敏性疾病、休克、血液病（再障、急淋） - 不良反应：类肾上腺皮质功能亢进（满月脸、水牛背）、诱发或加重感染、消化性溃疡、骨质疏松、停药反应（反跳、肾上腺皮质萎缩）

    **记忆：** 糖皮质激素="四抗"（抗炎、抗毒、抗休克、免疫抑制），但长期用副作用多。

    ??? question "5. 强心苷（地高辛）的作用机制、临床应用和不良反应是什么？" 答案： - 作用机制：抑制 Na⁺-K⁺-ATP 酶 → 细胞内 Na⁺↑ → Na⁺-Ca²⁺ 交换↑ → 细胞内 Ca²⁺↑ → 心肌收缩力↑ - 临床应用：充血性心力衰竭（CHF）、 atrial fibrillation（控制心室率） - 不良反应：心律失常（最严重！室性早搏、室性心动过速）、胃肠道反应、中枢神经系统反应

    **解救：** 强心苷中毒引起的心律失常 → 用苯妥英钠或利多卡因。

    ??? question "6. 胰岛素的适应症和不良反应是什么？" 答案： - 适应症：1 型糖尿病（绝对适应症）、2 型糖尿病（口服降糖药无效时）、糖尿病酮症酸中毒、妊娠糖尿病 - 不良反应：低血糖反应（最常见、最危险）→ 出冷汗、心悸、昏迷；过敏反应；胰岛素抵抗

    **记忆：** 胰岛素过量 → 低血糖休克 → 立即静注 50% 葡萄糖！

    ??? question "7. 常用降压药的分类和代表药是什么？" 答案： - 利尿药 → 氢氯噻嗪（早期轻度高血压） - ACEI → 卡托普利（抑制血管紧张素转化酶→AngⅡ↓）→ 改善胰岛素抵抗、保护肾脏 - ARB → 氯沙坦（阻断 AT₁ 受体）→ 与 ACEI 类似，但不引起干咳 - 钙拮抗剂 → 硝苯地平（阻断 Ca²⁺ 通道→ 血管扩张）→ 适合老年高血压 - β 受体阻断剂 → 普萘洛尔（降低心输出量）→ 适合年轻高血压、心率快者

    **记忆口诀：** 利尿 ACEI、ARB、钙阻、β 阻——五大类降压药。

    ??? question "8. 有机磷农药中毒的解救原则是什么？" 答案： 有机磷中毒 = 胆碱酯酶被抑制 → 乙酰胆碱蓄积 → M 样症状（流涎、流泪、缩瞳、肺水肿）+ N 样症状（肌束震颤、肌无力）

    **解救：** ① **阿托品**（对抗 M 样症状，足量、反复使用至"阿托品化"）；② **胆碱酯酶复活药**（氯解磷定、解磷定→ 恢复胆碱酯酶活性）

**关键：** 阿托品 + 胆碱酯酶复活药 **联合使用**，效果更好！
