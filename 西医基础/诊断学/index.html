    诊断学 学习指南¶

    诊断学是研究诊断疾病的方法的学科——怎么采集病史？怎么体格检查？怎么解读辅助检查？ 这门课的特点是"动手课"——不仅要会"问"，还要会"查"、会"看"。

    为什么这门课特别重要？¶

    • 执业医师考试占分约10-15%
    • 所有临床课程的基础——不会诊断，怎么治疗？
    • 临床必备——采集病史、体格检查、解读化验单，是每个医生的基本功

    核心理论：诊断的基本步骤¶

    采集病史（问诊）
    ↓
体格检查（视、触、叩、听）
    ↓
辅助检查（实验室、影像学）
    ↓
综合分析（诊断思维）
    ↓
确立诊断

    重点内容详解¶

    1. 问诊（重点掌握）¶

    问诊的内容（必背）¶

    内容 解释 临床意义
    主诉 患者就诊的最主要原因（症状 + 时间） 引导诊断方向
    现病史 本次疾病的发生、发展、诊疗经过 诊断的主要依据
    既往史 过去的疾病史、手术史、外伤史 排除相关疾病
    系统回顾 各系统的症状回顾 发现遗漏的症状
    个人史 生活习惯、职业、旅居史 发现病因线索
    婚姻史 婚姻状况、配偶健康 性传播疾病、遗传疾病
    月经史、生育史 月经情况、生育情况（女性） 妇科病、内分泌病
    家族史 直系亲属的疾病史 遗传疾病、家族聚集性疾病

    常见症状的特点（重点掌握）¶

    发热：

    • 热度：低热（37.3-38℃）、中等热（38.1-39℃）、高热（39.1-41℃）、超高热（>41℃）
    • 热型：稽留热（大叶性肺炎）、弛张热（败血症）、间歇热（疟疾）、回归热（回归热）、波状热（布鲁菌病）、不规则热（结核病）

    疼痛：

    • 部位、性质、程度、持续时间、诱发因素、缓解因素、伴随症状
    • 举例：心绞痛（胸骨后压榨性疼痛，持续3-5分钟，劳累诱发，休息缓解）

    水肿：

    • 部位：全身性（心、肝、肾）、局部性（静脉、淋巴）
    • 性质：凹陷性（心、肝、肾）、非凹陷性（黏液性水肿、象皮肿）

    2. 体格检查（重点掌握）¶

    基本检查方法（必会）¶

    方法 操作 适用
    视诊 用眼睛观察 全身状态、皮肤、黏膜、舌苔
    触诊 用手触摸 体温、湿度、压痛、肿块
    叩诊 用手指叩击 肺部（清音、浊音、实音）、心脏（浊音）、腹部（鼓音、浊音）
    听诊 用听诊器听 心脏（心音、杂音）、肺部（呼吸音、啰音）、腹部（肠鸣音）

    各系统体格检查（重点掌握）¶

    生命体征：

    指标 正常值 异常意义
    体温 36-37℃（腋温） ↑发热、↓休克、甲减
    脉搏 60-100次/分 ↑心动过速、↓心动过缓
    呼吸 12-20次/分 ↑呼吸过速、↓呼吸过缓
    血压 <120/80mmHg ↑高血压、↓休克

    头部和颈部：

    • 瞳孔：大小、形状、对光反射（瞳孔散大 → 颅内压↑、阿托品中毒；瞳孔缩小 → 有机磷中毒、吗啡中毒）
    • 扁桃体：肿大分度（I度：不超过咽腭弓；II度：超过咽腭弓；III度：达到咽后壁中线）
    • 甲状腺：肿大分度（I度：不能看出但能触及；II度：能看出也能触及，但在胸锁乳突肌以内；III度：超过胸锁乳突肌）

    胸部：

    • 胸廓：正常、桶状胸（肺气肿）、扁平胸（慢性消耗性疾病）、鸡胸（佝偻病）
    • 肺部叩诊：清音（正常）、浊音（肺炎、肺不张）、实音（胸腔积液）、鼓音（气胸）

    • 肺部听诊：正常呼吸音、异常呼吸音（哮鸣音、湿啰音）、胸膜摩擦音

    • 心脏叩诊：心界（梨形心 → 二尖瓣狭窄；靴形心 → 高血压、主动脉瓣关闭不全）

    • 心脏听诊：心音（S1、S2、S3、S4）、杂音（收缩期、舒张期、连续性）、心包摩擦音

    腹部：

    • 腹形：平坦、膨隆（肥胖、腹水、巨大卵巢囊肿）、凹陷（消瘦）
    • 腹壁静脉：门静脉高压（海蛇头征）、上腔静脉阻塞（血流向上）、下腔静脉阻塞（血流向下）
    • 肝脾触诊：大小、质地、表面、压痛、搏动
    • 腹部听诊：肠鸣音（正常4-5次/分；亢进 → 机械性肠梗阻；减弱/消失 → 麻痹性肠梗阻）

    四肢和神经系统：

    • 肌力：0-5级（0级：完全瘫痪；5级：正常）
    • 肌张力：增高（锥体束损害）、减低（小脑损害、周围神经损害）
    • 生理反射：浅反射（角膜反射、腹壁反射）、深反射（肱二头肌反射、膝反射、跟腱反射）
    • 病理反射：Babinski征（锥体束损害）、Oppenheim征、Gordon征、Hoffmann征
    • 脑膜刺激征：颈强直、Kernig征、Brudzinski征（脑膜炎、蛛网膜下腔出血）

    3. 辅助检查（重点掌握）¶

    实验室检查（重点掌握）¶

    血常规：

    指标 正常值 异常意义
    血红蛋白（Hb） 男120-160g/L；女110-150g/L ↓贫血、↑脱水
    红细胞（RBC） 男（4.0-5.5）×10¹²/L；女（3.5-5.0）×10¹²/L ↓贫血、↑脱水
    白细胞（WBC） （4.0-10.0）×10⁹/L ↑感染（细菌）、↓病毒感染、血液病
    中性粒细胞（N） 50-70% ↑细菌感染、↓病毒感染
    淋巴细胞（L） 20-40% ↑病毒感染、↓免疫缺陷
    血小板（PLT） （100-300）×10⁹/L ↓出血倾向、↑血栓风险

    生化检查：

    指标 正常值 异常意义
    空腹血糖（FBG） 3.9-6.1mmol/L ↑糖尿病、↓低血糖
    肌酐（Cr） 男53-106μmol/L；女44-97μmol/L ↑肾功能不全
    尿素氮（BUN） 2.9-7.5mmol/L ↑肾功能不全、脱水
    谷丙转氨酶（ALT） <40U/L ↑肝细胞损伤
    谷草转氨酶（AST） <40U/L ↑肝细胞损伤、心肌梗死
    总胆红素（TBIL） 5.1-22.2μmol/L ↑黄疸（溶血性、肝细胞性、阻塞性）

    动脉血气分析：

    指标 正常值 异常意义
    pH 7.35-7.45 <7.35酸中毒、>7.45碱中毒
    PaCO₂ 35-45mmHg ↑呼吸性酸中毒、↓呼吸性碱中毒
    PaO₂ 80-100mmHg ↓缺氧
    HCO₃⁻ 22-27mmol/L ↑代谢性碱中毒、↓代谢性酸中毒

    心电图（重点掌握）¶

    正常心电图：

    • P波：心房除极（<0.11秒，<0.25mV）
    • PR间期：0.12-0.20秒
    • QRS波群：心室除极（<0.11秒）
    • ST段：等电位线（偏移 >0.05mV = 异常）
    • T波：心室复极（方向与QRS主波一致）
    • QT间期：0.32-0.44秒

    异常心电图：

    异常 表现 临床意义
    心肌梗死 ST段抬高、病理性Q波、T波倒置 急性心肌梗死
    心律失常 P波异常、QRS波群异常、节律不齐 窦性心动过速/过缓、房颤、室早、室速、室颤
    房室传导阻滞 PR间期延长（I度）、部分P波后无QRS（II度）、P波与QRS无关（III度） 房室传导阻滞

    影像学检查（了解）¶

    检查 适用 特点
    X线 肺部、骨骼 便宜、快速，但分辨率低
    CT 头部、胸部、腹部 分辨率高，但辐射大
    MRI 神经系统、软组织 无辐射，但价格高、时间长
    超声 腹部、妇科、心脏 无辐射、实时，但受气体干扰

    学习进度规划¶

    阶段 内容 时间
    第一阶段 问诊（内容、技巧） 2天
    第二阶段 体格检查（基本方法、生命体征） 3天
    第三阶段 头部、颈部、胸部体格检查 5天
    第四阶段 腹部、四肢、神经系统体格检查 5天
    第五阶段 实验室检查（血常规、生化、血气） 3天
    第六阶段 心电图（正常、异常） 3天
    第七阶段 影像学检查（X线、CT、MRI、超声） 2天
    第八阶段 复习 + 做真题 5天

    常见学习误区¶

    误区1：只背"正常值"，不练"操作"

    知道"膝反射"怎么查，但不会做——这是无效学习。

    正确做法： 找同学互相练，把每个体格检查操作都练熟。

    误区2：不背"病理反射"

    病理反射是神经系统疾病的重要体征，不能不背。

    正确做法： 每个病理反射都要掌握"检查方法 + 阳性意义"。

    误区3：忽略"病历书写"

    病历书写是临床基本功，也是执业医师考试的必考内容。

    正确做法： 学完诊断学，要能独立写一份完整病历（主诉、现病史、体格检查、辅助检查、初步诊断、诊疗计划）。

    自测习题¶

    ??? question "1. 患者呕血，面色苍白，血压80/50mmHg，心率120次/分。诊断？首选检查？" 答案： 诊断：上消化道出血、失血性休克。首选检查：血常规（Hb、RBC）、凝血功能、肝功能、胃镜。

    **解析：** 呕血 + 休克表现（血压↓、心率↑）= 上消化道出血、失血性休克。首先检查血常规（了解贫血程度）、凝血功能（排除凝血障碍）、肝功能（排除肝硬化食管静脉曲张破裂）、胃镜（明确病因、止血）。

    ??? question "2. 患者胸痛，ST段抬高。诊断？紧急处理？" 答案： 诊断：急性心肌梗死。紧急处理：卧床休息、吸氧、心电监护、止痛（吗啡）、抗凝（阿司匹林、肝素）、再灌注治疗（溶栓、PCI）。

    **解析：** 胸痛 + ST段抬高 = 急性心肌梗死（STEMI）。紧急处理原则是**尽快开通梗死相关血管**（再灌注治疗）。

    ??? question "3. 患者昏迷，瞳孔针尖样大小，口唇樱桃红色。诊断？" 答案： 诊断：有机磷中毒。

    **解析：** 昏迷 + 瞳孔针尖样（有机磷、吗啡中毒）+ 口唇樱桃红色（一氧化碳中毒）→ 有机磷中毒（阿托品中毒 → 瞳孔散大；吗啡中毒 → 呼吸抑制、针尖样瞳孔，但口唇无樱桃红色）。

    ??? question "4. 患者大量腹水，腹壁静脉血流方向：脐以上向上，脐以下向上。为什么？" 答案： 下腔静脉阻塞。

    **解析：** 正常腹壁静脉血流方向：脐以上向上（汇入上腔静脉）、脐以下向下（汇入下腔静脉）。脐以上向上、脐以下向上 = 下腔静脉阻塞（血流不能往下，只能往上）。门静脉高压 = 脐以上向上、脐以下向下（但血流方向是从脐向四周，呈"海蛇头"状）。

    📝 自测习题¶

    ??? question "1. 发热的分度和临床意义是什么？" 答案： - 低热：37.3～38℃ - 中等热：38.1～39℃ - 高热：39.1～41℃ - 超高热：>41℃

    **临床意义：** 发热是机体对致热原的反应。高热常见于大叶性肺炎、败血症；长期低热常见于结核、甲亢。

    ??? question "2. 匙状甲（反甲）和反甲的特点和临床意义？" 答案： - 匙状甲：指甲中央凹陷、边缘翘起，形如匙状 - 常见疾病：缺铁性贫血（最常见）、风湿热、高原疾病

    **检查方法：** 用手指轻压指甲，正常指甲会发白，松开后立即恢复——缺铁性贫血时恢复缓慢。

    ??? question "3. 胸膜摩擦音和心包摩擦音如何鉴别？" 答案： - 胸膜摩擦音：呼吸两相均可闻及，屏气时消失，深呼吸时增强，常见于纤维素性胸膜炎 - 心包摩擦音：心率快慢一致，屏气时仍存在，常见于心包炎

    **记忆：** 屏气消失 = 胸膜；屏气仍在 = 心包。

    ??? question "4. 舒张期奔马律和收缩期期前收缩（早搏）的鉴别？" 答案： - 舒张期奔马律（S3/S4）：额外心音，心率>100次/分时出现"室性奔马律"，提示严重心室衰竭 - 期前收缩（早搏）：提前出现的心跳，有完全/不完全代偿间歇，听诊有"期前心音 + 代偿间歇"

    **临床意义：** 奔马律 = 严重心衰；频发早搏 = 冠心病、心肌病、电解质紊乱。

    ??? question "5. 墨菲征（Murphy's sign）和麦氏点压痛的区别？" 答案： - 墨菲征：左手拇指按压右肋缘下胆囊点，患者深吸气时因拇指触及发炎胆囊而突然屏气 = 阳性 → 急性胆囊炎 - 麦氏点压痛：右下腹麦氏点（脐与右髂前上棘连线中、外1/3交界）压痛 → 阑尾炎

    **记忆：** 深吸气屏气 = 墨菲征（胆囊）；固定点压痛 = 麦氏点（阑尾）。

    ??? question "6. 移动性浊音的检查方法和临床意义？" 答案： - 检查方法：患者仰卧时叩诊腹部，浊音区在脐部；侧卧时浊音区移至低处（如右侧卧位时浊音在右侧腹部）——浊音随体位移动 = 移动性浊音阳性 - 临床意义：腹腔内游离液体 >1000mL 时出现，提示大量腹水（肝硬化、结核性腹膜炎、恶性肿瘤）

    **注意：** <1000mL 时移动性浊音阴性，需用液波震颤或 B 超确认。

    ??? question "7. 脑膜刺激征包括哪些？如何检查？临床意义？" 答案： - 颈强直：被动屈颈时阻力增高、疼痛 = 阳性 - Kernig 征：仰卧屈髋屈膝90°，被动伸膝时阻力增高、疼痛 = 阳性 - Brudzinski 征：仰卧被动屈颈时，双侧髋膝关节反射性屈曲 = 阳性

    **临床意义：** 脑膜刺激征阳性 = 脑膜炎、蛛网膜下腔出血、颅内压增高。

    ??? question "8. 血红蛋白（Hb）和红细胞（RBC）的正常值、减少的临床意义？" 答案： - 正常值：男性 Hb 120-160g/L，RBC (4.0-5.5)×10¹²/L；女性 Hb 110-150g/L，RBC (3.5-5.0)×10¹²/L - 减少（贫血）： - 轻度：Hb 90-正常低限 - 中度：Hb 60-90g/L - 重度：Hb 30-60g/L - 极重度：Hb <30g/L

    **临床意义：** 贫血 = 缺氧。急性大出血时 RBC/Hb 不立即下降（血浆和RBC等比例丢失），3-4小时后才出现稀释性贫血。
