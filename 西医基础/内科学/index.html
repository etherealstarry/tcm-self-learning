    内科学 学习指南¶

    内科学是临床医学的核心——前面学的解剖、生理、病理、药理、诊断，全都在这门课里综合应用。 这门课的特点是"疾病多、机制复杂"，要会"辨证（中医） + 辨病（西医）"。

    为什么这门课特别重要？¶

    • 执业医师考试占分约15-20%（比重最大！）
    • 临床的核心——内科医生每天都要用
    • 中西医结合的关键——中医内科和西医内科要"打通"

    核心理论：内科疾病的诊断思路¶

    采集病史（症状）
    ↓
体格检查（体征）
    ↓
辅助检查（实验室、影像学）
    ↓
综合分析 → 初步诊断
    ↓
鉴别诊断（排除相似疾病）
    ↓
确立诊断 → 制定治疗方案

    重点内容详解¶

    1. 呼吸系统疾病¶

    慢性阻塞性肺疾病（COPD）¶

    诊断标准（必背）：

    • 症状：慢性咳嗽、咳痰、气短或呼吸困难
    • 危险因素：吸烟、职业粉尘/化学物质、空气污染
    • 肺功能：FEV₁/FVC < 70%（不完全可逆性气流受限）

    分期：

    • 急性加重期：短期内咳嗽、咳痰、气短加重，痰量增多，脓痰
    • 稳定期：咳嗽、咳痰、气短症状稳定

    治疗：

    分期 治疗
    急性加重期 控制感染（抗生素）、平喘（β₂激动剂、抗胆碱药、糖皮质激素）、祛痰、氧疗
    稳定期 戒烟、支气管扩张剂（β₂激动剂、抗胆碱药）、糖皮质激素（吸入）、长期家庭氧疗（LTOT）

    支气管哮喘¶

    诊断标准（必背）：

    • 反复发作的喘息、气急、胸闷或咳嗽
    • 发作时双肺可闻及散在或弥漫性哮鸣音
    • 上述症状可经治疗缓解或自行缓解
    • 排除其他疾病引起的喘息

    分期：

    • 急性发作期：喘息、气急、胸闷加重
    • 慢性持续期：症状持续存在
    • 缓解期：症状、体征消失

    治疗（重点掌握）：

    分类 代表药 作用 适用
    β₂受体激动剂 沙丁胺醇 舒张支气管 急性发作（首选）
    抗胆碱药 异丙托溴铵 舒张支气管 慢性持续期
    糖皮质激素 布地奈德（吸入） 抗炎 慢性持续期（控制炎症）
    白三烯调节剂 孟鲁司特 抗炎 轻度哮喘、运动诱发哮喘

    肺炎¶

    分类（重点掌握）：

    分类 代表病原体 特点
    社区获得性肺炎（CAP） 肺炎链球菌（最常见） 院外发病，常见
    医院获得性肺炎（HAP） 革兰阴性杆菌（铜绿假单胞菌） 入院48小时后发病，耐药菌多

    临床表现：

    • 症状：发热、咳嗽、咳痰（铁锈色痰 = 肺炎链球菌）、胸痛
    • 体征：肺实变体征（叩诊浊音、语颤增强、支气管呼吸音）

    治疗：

    • CAP：青霉素（肺炎链球菌）、大环内酯类（非典型病原体）
    • HAP：三代头孢 + 氨基糖苷类（覆盖革兰阴性杆菌）

    2. 循环系统疾病¶

    高血压¶

    诊断标准（必背）：

    • 未服降压药的情况下，非同日3次测量血压，收缩压 ≥140mmHg 和/或舒张压 ≥90mmHg
    • 或：既往有高血压史，目前正在服降压药

    分级（重点掌握）：

    分级 收缩压（mmHg） 舒张压（mmHg）
    正常血压 <120 <80
    正常高值 120-139 80-89
    1级高血压（轻度） 140-159 90-99
    2级高血压（中度） 160-179 100-109
    3级高血压（重度） ≥180 ≥110
    单纯收缩期高血压 ≥140 <90

    治疗（重点掌握）：

    • 非药物治疗：低盐饮食、减重、运动、戒烟限酒
    • 药物治疗：利尿剂（氢氯噻嗪）、ACEI（卡托普利）、ARB（氯沙坦）、钙通道阻滞药（硝苯地平）、β受体阻断药（普萘洛尔）

    冠心病¶

    分型（重点掌握）：

    分型 特点 治疗
    稳定型心绞痛 劳力诱发，休息缓解 硝酸甘油（急性发作）、β受体阻断药（预防）
    不稳定型心绞痛 劳力诱发，但更严重（休息时也痛） 住院、抗凝、PCI（支架）
    急性心肌梗死（AMI） 持续胸痛 >30分钟，ST段抬高 再灌注治疗（溶栓、PCI）、抗凝、止痛

    急性心肌梗死的治疗（重点掌握）：

    1. 一般治疗：卧床休息、吸氧、心电监护
    2. 止痛：吗啡（静脉注射）
    3. 再灌注治疗：
    4. 溶栓（发病12小时内，无禁忌症）
    5. PCI（经皮冠状动脉介入治疗，优先选择）
    6. 抗凝：阿司匹林（终身服用）、氯吡格雷（至少1年）、肝素（短期使用）
    7. 其他：β受体阻断药（减少心肌耗氧）、ACEI（改善心室重构）

    3. 消化系统疾病¶

    消化性溃疡¶

    病因（重点掌握）：

    • 幽门螺杆菌（Hp）感染（最主要）
    • 非甾体抗炎药（NSAIDs）使用
    • 胃酸、胃蛋白酶分泌过多

    临床表现：

    • 胃溃疡（GU）：餐后痛（进食 → 疼痛 → 缓解）
    • 十二指肠溃疡（DU）：空腹痛、夜间痛（疼痛 → 进食 → 缓解）

    并发症：

    • 出血（最常见）
    • 穿孔
    • 幽门梗阻
    • 癌变（GU可癌变，DU不癌变）

    治疗（重点掌握）：

    • 根除Hp：PPI + 两种抗生素（克拉霉素、阿莫西林/甲硝唑）
    • 抑制胃酸：PPI（奥美拉唑）、H₂受体拮抗剂（雷尼替丁）
    • 保护胃黏膜：硫糖铝、枸橼酸铋钾

    肝硬化¶

    病因（重点掌握）：

    • 病毒性肝炎（乙肝、丙肝，最常见）
    • 酒精性肝病
    • 非酒精性脂肪性肝病（NAFLD）
    • 胆汁淤积、药物损伤、自身免疫性肝病

    临床表现：

    • 代偿期：症状轻（乏力、食欲减退、腹胀）
    • 失代偿期：
    • 肝功能减退：黄疸、出血倾向、内分泌紊乱（蜘蛛痣、肝掌）、肝病面容
    • 门静脉高压：腹水、食管胃底静脉曲张、脾大、腹壁静脉曲张

    并发症（重点掌握）：

    • 上消化道出血（最常见，食管胃底静脉曲张破裂）
    • 肝性脑病（最严重，氨中毒）
    • 感染（自发性细菌性腹膜炎）
    • 原发性肝癌

    治疗：

    • 病因治疗：抗病毒（乙肝、丙肝）、戒酒
    • 并发症治疗：腹水（利尿、放腹水、TIPS）、上消化道出血（止血、降门脉压）、肝性脑病（降血氨）
    • 肝移植（终末期）

    4. 泌尿系统疾病¶

    慢性肾小球肾炎（慢性肾炎）¶

    临床表现（重点掌握）：

    • 蛋白尿（必有）
    • 血尿（镜下或肉眼）
    • 高血压（常见）
    • 水肿（轻到中度）
    • 肾功能损害（进行性）

    治疗：

    • 限制蛋白摄入
    • 控制血压（ACEI/ARB优先，因能减少尿蛋白）
    • 避免肾损害因素（感染、劳累、肾毒性药物）

    慢性肾衰竭（CRF）¶

    分期（重点掌握）：

    分期 GFR（ml/min） 特点
    1期 ≥90 肾损害，GFR正常
    2期 60-89 GFR轻度↓
    3期 30-59 GFR中度↓
    4期 15-29 GFR重度↓
    5期（尿毒症期） <15 需要透析或移植

    临床表现（重点掌握）：

    • 水、电解质、酸碱平衡紊乱：水钠潴留、高钾、高磷、低钙、代谢性酸中毒
    • 各系统症状：
    • 心血管：高血压、心衰、尿毒症性心包炎
    • 血液：贫血（EPO减少）、出血倾向（血小板功能异常）
    • 神经：尿毒症脑病、周围神经病变
    • 消化道：食欲不振、恶心、呕吐（尿素氮从唾液排出，被细菌分解为氨 → 刺激胃黏膜）
    • 皮肤：皮肤瘙痒（钙磷沉积）、尿毒症面容（面色苍黄）

    治疗：

    • 保守治疗：低蛋白饮食、纠正水电解质紊乱、纠正贫血（EPO）、降压
    • 肾脏替代治疗：血液透析、腹膜透析、肾移植（最理想）

    5. 内分泌与代谢疾病¶

    糖尿病¶

    诊断标准（必背）：

    • 空腹血糖 ≥7.0mmol/L
    • 或：OGTT 2小时血糖 ≥11.1mmol/L
    • 或：随机血糖 ≥11.1mmol/L + 糖尿病症状（多饮、多尿、多食、体重减轻）
    • 或：HbA1c ≥6.5%

    分型（重点掌握）：

    分型 特点 治疗
    1型糖尿病 青少年发病、胰岛β细胞破坏、胰岛素绝对缺乏 胰岛素（终身使用）
    2型糖尿病 成年发病、胰岛素抵抗 + 分泌相对不足、有遗传倾向 生活方式干预 + 口服降糖药 ± 胰岛素

    并发症（重点掌握）：

    • 急性：糖尿病酮症酸中毒（DKA，1型多见）、高渗性高血糖状态（HHS，2型多见）
    • 慢性：微血管病变（糖尿病肾病、糖尿病视网膜病变）、大血管病变（冠心病、脑卒中、下肢动脉硬化）、神经病变（周围神经病变、自主神经病变）

    治疗（重点掌握）：

    分类 代表药 作用机制 不良反应
    双胍类 二甲双胍 抑制肝糖输出、改善胰岛素敏感性 胃肠道反应、乳酸酸中毒（罕见）
    磺脲类 格列美脲 促进胰岛素分泌 低血糖、体重增加
    格列奈类 瑞格列奈 促进胰岛素分泌（餐时） 低血糖、体重增加
    α-糖苷酶抑制剂 阿卡波糖 延缓碳水化合物吸收 腹胀、排气增多
    噻唑烷二酮类（TZD） 罗格列酮 改善胰岛素敏感性 水肿、心力衰竭、骨折风险↑
    DPP-4抑制剂 西格列汀 增加GLP-1水平 → 促进胰岛素分泌 上呼吸道感染、胰腺炎（罕见）
    SGLT-2抑制剂 达格列净 促进尿糖排泄 泌尿生殖道感染、酮症酸中毒（罕见）
    GLP-1受体激动剂 利拉鲁肽 促进胰岛素分泌、抑制胰高血糖素分泌、延缓胃排空 恶心、呕吐、胰腺炎（罕见）
    胰岛素 各种胰岛素 补充胰岛素 低血糖、体重增加、注射部位脂肪萎缩

    学习进度规划¶

    阶段 内容 时间
    第一阶段 呼吸系统疾病（COPD、哮喘、肺炎） 5天
    第二阶段 循环系统疾病（高血压、冠心病、心力衰竭） 7天
    第三阶段 消化系统疾病（消化性溃疡、肝硬化、胰腺炎） 5天
    第四阶段 泌尿系统疾病（慢性肾炎、慢性肾衰竭） 3天
    第五阶段 内分泌与代谢疾病（糖尿病、甲状腺疾病） 5天
    第六阶段 血液系统疾病（贫血、白血病、淋巴瘤） 3天
    第七阶段 风湿性疾病（类风湿关节炎、系统性红斑狼疮） 3天
    第八阶段 复习 + 做真题 7天

    常见学习误区¶

    误区1：只背诊断标准，不背"鉴别诊断"

    诊断标准只是"入门"，鉴别诊断是"精髓"——很多疾病症状相似，要能区分。

    正确做法： 每个疾病都要掌握"鉴别诊断"（如肺炎 vs 肺癌 vs 肺结核）。

    误区2：不背"并发症"

    并发症是疾病严重程度的重要标志，也是执业医师考试的重点。

    正确做法： 每个疾病都要掌握"并发症"（如消化性溃疡的并发症：出血、穿孔、幽门梗阻、癌变）。

    误区3：忽略"治疗原则"

    治疗原则是临床决策的基础，不能只背药名、不背原则。

    正确做法： 每个疾病都要掌握"治疗原则"（如高血压的治疗原则：非药物治疗 + 药物治疗，从小到大、单药到联合）。

    指南 各疾病诊疗指南（如高血压指南、糖尿病指南） 了解最新诊疗规范

    自测习题¶

    ??? question "1. 患者反复喘息、气急，发作时双肺闻及哮鸣音，症状可自行缓解。诊断？急性发作首选药？" 答案： 诊断：支气管哮喘。急性发作首选药：沙丁胺醇（β₂受体激动剂，吸入）。

    **解析：** 反复发作的喘息 + 双肺哮鸣音 + 可自行缓解 = 支气管哮喘。急性发作时，首选β₂受体激动剂（沙丁胺醇）吸入，快速舒张支气管。

    ??? question "2. 患者持续胸痛 >30分钟，ST段抬高。诊断？紧急处理原则？" 答案： 诊断：急性心肌梗死（STEMI）。紧急处理原则：再灌注治疗（溶栓或PCI，优先PCI）。

    **解析：** 持续胸痛 >30分钟 + ST段抬高 = 急性心肌梗死（STEMI）。再灌注治疗是**挽救心肌、改善预后**的关键，越快越好（发病12小时内）。

    ??? question "3. 患者空腹葡萄糖 8.5mmol/L，HbA1c 7.5%，多饮多尿多食欲减轻。诊断？分型？首选治疗？" 答案： 诊断：糖尿病。分型：2型糖尿病（成年发病、症状不重）。首选治疗：生活方式干预 + 二甲双胍。

    **解析：** 空腹血糖 ≥7.0mmol/L + 糖尿病症状 = 糖尿病。成年发病、症状不重 = 2型糖尿病（1型糖尿病青少年发病、症状重、酮症倾向）。2型糖尿病首选治疗：生活方式干预 + 二甲双胍（改善胰岛素敏感性，不增加体重）。

    ??? question "4. 患者腹胀、腹水，腹壁静脉曲张，脾大。诊断？最可能的原因？" 答案： 诊断：肝硬化失代偿期（门静脉高压）。最可能的原因：乙型肝炎（中国最常见）。

    **解析：** 腹胀、腹水 + 门静脉高压体征（腹壁静脉曲张、脾大）= 肝硬化失代偿期。中国是乙肝大国，乙肝是肝硬化最常见的原因（西方国家是酒精）。

    📝 自测习题¶

    ??? question "1. COPD（慢性阻塞性肺疾病）的诊断标准和治疗原则？" 答案： - 诊断标准：① 吸烟史/职业粉尘接触史；② 慢性咳嗽咳痰 + 进行性呼吸困难；③ 肺功能：FEV₁/FVC <70%（使用支气管扩张剂后）确认持续气流受限 - 治疗原则：戒烟（最关键！）、支气管扩张剂（β₂激动剂、抗胆碱能药）、糖皮质激素（急性加重时）、长期氧疗（PaO₂<55mmHg）

    **临床意义：** COPD 是**不可逆**气流受限（与哮喘不同，哮喘是可逆的）。

    ??? question "2. 慢性心衰（CHF）的 NYHA 心功能分级是什么？" 答案： - I 级：日常活动无气促（心功能代偿期） - II 级：日常活动轻度受限（快走、爬楼时气促） - III 级：日常活动明显受限（平地步行 100 米即气促） - IV 级：安静时也气促（端坐呼吸、夜间阵发性呼吸困难）

    **记忆：** I 级 = 正常活动；II 级 = 稍受限；III 级 = 明显受限；IV 级 = 卧床也喘。

    ??? question "3. 消化性溃疡（GU/ DU）的疼痛特点和鉴别？" 答案： - 胃溃疡（GU）：餐后 0.5-1 小时痛（进食→胃分泌胃酸→刺激溃疡面），疼痛规律 = 进食→疼痛→缓解 - 十二指肠溃疡（DU）：空腹痛、夜间痛（空腹时胃酸直接刺激溃疡面），疼痛规律 = 进食→缓解→疼痛（下次进食前又痛）

    **并发症（四大）：** 出血（最常见）、穿孔、幽门梗阻、癌变（GU 可癌变，DU 不癌变）。

    ??? question "4. 急性心肌梗死（AMI）的 ECG 演变和心肌酶演变？" 答案： - ECG 演变：T 波高尖（超急性期）→ ST 段弓背向上抬高（急性期）→ 病理性 Q 波（陈旧期）→ ST 段回落、T 波倒置 - 心肌酶演变：肌红蛋白（2h 内升高，最早！）→ CK-MB（4-6h 升高，特异性较高）→ 肌钙蛋白（cTnI/cTnT，12-24h 升高，特异性最高、持续时间最长）

    **临床意义：** cTn 是 AMI **诊断金标准**（特异性最高）。

    ??? question "5. 肝硬化腹水形成的机制是什么？" 答案： 肝硬化腹水 = 多因素共同作用： - 门脉高压：肝内血流阻力↑ → 肠系膜毛细血管压力↑ → 液体漏入腹腔 - 低白蛋白血症：肝细胞合成白蛋白↓ → 血浆胶体渗透压↓ - 继发性醛固酮增多：肝灭活醛固酮↓ → 水钠潴留 - 淋巴液生成增多：肝窦压力↑ → 肝淋巴液生成↑ → 超过胸导管引流能力 → 淋巴液漏入腹腔

    **治疗：** 限钠、利尿（螺内酯 + 呋塞米）、排放腹水 + 白蛋白输注。

    ??? question "6. 糖尿病的并发症有哪些？酮症酸中毒（DKA）的处理原则？" 答案： - 急性并发症：DKA（1 型常见）、高渗性高血糖状态（HHS，2 型常见）、低血糖 - 慢性并发症：大血管（冠心病、脑卒中、下肢动脉硬化）、微血管（糖尿病肾病、糖尿病视网膜病变）、神经病变、糖尿病足 - DKA 处理：① 补液（首选等渗盐水，先快后慢）；② 胰岛素输注（降低血糖、抑制酮体生成）；③ 纠正电解质紊乱（补钾！）；④ 纠正酸中毒（pH<7.1 时才补碱）

    **记忆：** DKA = 高血糖 + 酮体 + 代谢性酸中毒。

    ??? question "7. 缺铁性贫血（IDA）的实验室特点和治疗方案？" 答案： - 实验室特点：小细胞低色素性贫血（MCV↓、MCH↓、MCHC↓）、血清铁↓、总铁结合力↑、转铁蛋白饱和度↓、血清铁蛋白↓（最敏感、最特异的早期指标） - 治疗：去除病因（最关键！如月经过多、消化道出血）+ 补铁（口服琥珀酸亚铁，餐前1h或餐后2h服用，不与茶/咖啡同服）→ 血红蛋白正常后继续补铁 3-6 个月（补充储存铁）

    **临床意义：** 铁蛋白是**最早期**的铁缺乏指标（比 Hb 下降早）。

    ??? question "8. 肾病综合征（NS）的诊断标准和病理类型？" 答案： - 诊断标准（三高一低）：① 大量蛋白尿（>3.5g/d）；② 低白蛋白血症（<30g/L）；③ 高度水肿；④ 高脂血症 - 常见病理类型：微小病变型肾病（儿童多见、激素敏感）、膜性肾病（中老年多见、激素抵抗）、局灶节段性肾小球硬化、系膜增生性肾小球肾炎

    **并发症：** 感染（最常见、最主要死因）、血栓栓塞（肾静脉血栓最常见）、急性肾衰、蛋白质及脂质代谢紊乱。
