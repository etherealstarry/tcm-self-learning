    中医基础学¶

    这门课是中医的"世界观"——它不教你治什么病，而是教你用中医的眼光看人体。 学完这门课，你应该能回答：为什么中医说"肝火旺"？为什么"补肾"能治耳鸣？

    🎯 这门课到底在学什么？¶

    很多自学中医的人一开始就很挫败：阴阳五行这些东西，到底有什么用？

    先给你一个宏观框架，知道每个理论是干什么用的：

    中医基础学 = 解释人体运行规律的 4 个模型

模型1：阴阳学说    →  解释"身体什么时候平衡、什么时候生病"
模型2：五行学说    →  解释"五脏六腑怎么互相影响"
模型3：藏象学说    →  解释"每个脏腑具体干什么活"
模型4：经络学说    →  解释"脏腑之间怎么传递信息"

加上：气血津液（身体的"燃料"和"润滑油"）
加上：病因病机（身体怎么被搞坏的）
加上：防治原则（怎么让它恢复正常）

    你学每一章时，都要问自己一个问题：这个理论，是用来解释什么现象的？能解释什么具体问题？

    📖 保姆级学习路线¶

    学习顺序（非常重要）

    不要按教材章节顺序死磕！建议按这个顺序：

    第一阶段（建立直觉） 1. 先学「整体观念 + 辨证论治」→ 搞懂中医和其他医学最根本的区别 2. 再学「阴阳学说」→ 先只学"阴阳是什么"，别急着学应用

    第二阶段（建立模型） 3. 学「五行学说」→ 用表格把五脏归属记熟 4. 学「藏象学说」→ 一个一个脏腑来，每个脏腑画一张"功能卡片"

    第三阶段（理解运行） 5. 学「气血津液」→ 理解身体里的"能量"和"物质"怎么跑来跑去 6. 学「经络学说」→ 配合针灸学一起学，效果更好

    第四阶段（理解疾病） 7. 学「病因病机」→ 回头看前面的模型，理解"模型怎么被破坏" 8. 学「防治原则」→ 理解中医怎么"修复模型"

    🔥 第一章：阴阳学说（保姆级详解）¶

    1.1 阴阳到底是什么？（先建立直觉）¶

    不要用"科学"去理解阴阳，用"观察"去理解。

    古人观察自然，发现万物都可以分成两类：

    你观察到的现象 归类 为什么
    白天 / 黑夜 昼=阳，夜=阴 白天明亮温暖（阳的特性），黑夜暗淡寒冷（阴的特性）
    太阳 / 月亮 日=阳，月=阴 太阳发热（阳），月亮反光不发热（阴）
    男 / 女 男=阳，女=阴 男性外向主动（阳），女性内敛主静（阴）
    火 / 水 火=阳，水=阴 火炎热上升（阳），水寒冷润下（阴）

    所以阴阳的本质是：对自然界一切事物"对立又统一"的两面性的概括。

    自测：下面这些属阴还是属阳？

    • 山峰的南坡（向阳）→ 属阳 ☀️
    • 山峰的北坡（背阴）→ 属阴 🌙
    • 运动 → 属阳（动=阳）
    • 静坐 → 属阴（静=阴）
    • 沸腾的水 → 属阳（热=阳）
    • 冰冷的石头 → 属阴（寒=阴）

    1.2 阴阳的 4 个规律（这是核心中的核心）¶

    规律1：阴阳对立制约¶

    一句话解释：阳想往上跑，阴想往下拉，互相"较劲"，身体才平衡。

    具体例子： - 你的体温维持在 37℃ 左右 → 阳气（产热）和阴气（制热）互相制约的结果 - 如果阳气太盛（发烧）→ 需要用"寒凉"的药（属阴）来制约它 - 如果阴气太盛（畏寒肢冷）→ 需要用"温热"的药（属阳）来制约它

    💡 记忆方法：想象一个天平，左边放阳，右边放阴，两边重量相等 → 身体健康。哪边重了，就往另一边加砝码。

    规律2：阴阳互根互用¶

    一句话解释：阳不能离开阴单独存在，阴也不能离开阳单独存在——没有"下"就无所谓"上"。

    具体例子： - 人体的气（阳） 需要血（阴） 作为载体："气为血之帅，血为气之母" - 如果失血过多（阴亏了）→ 气也留不住（气随血脱） - 如果气虚到极点（阳虚了）→ 血也化不生（阳虚血不生）

    ⚠️ 临床意义：这就是为什么治贫血不能只"补血"，还要"补气"（补气以生血）；治虚脱不能只"滋阴"，还要"扶阳"（扶阳以配阴）。

    规律3：阴阳消长平衡¶

    一句话解释：阴阳不是固定不变的，而是动态变化的，但只要变化在范围内，就是健康。

    具体例子： - 一天之中：清晨阳气渐长（消长）→ 中午阳气最盛 → 傍晚阳气渐消、阴气渐长 → 半夜阴气最盛 - 健康的人：这个消长过程平稳，你感觉不到 - 生病的人：消长失衡了 → 比如"阴虚则热"（阴消太多、阳相对偏盛）→ 出现潮热、盗汗

    📈 画个图理解：想象一条正弦曲线，阳是一条线，阴是另一条线，两条线此消彼长，但整体维持在中间区间 → 这就是"动态平衡"。

    规律4：阴阳相互转化¶

    一句话解释：在极端情况下，阳可以变成阴，阴可以变成阳——"重阴必阳，重阳必阴"。

    具体例子： - 感冒初起：恶寒重、发热轻（寒邪在表，属阴）→ 如果没治好，可能突然变成高热、口渴、咽喉肿痛（热邪，属阳）→ 寒转热 - 高热不退：本来是阳证（高热、面红、口渴）→ 突然变成四肢厥冷、脉微欲绝（阴证）→ 热转寒（热深厥深）

    🔥 为什么会出现这种转化？ 因为阴阳的力量对比到了极端，就会"物极必反"。《黄帝内经》说："重阴必阳，重阳必阴"，"寒极生热，热极生寒"。

    1.3 阴阳学说在中医里的具体应用¶

    用在诊断上：¶

    观察对象 阳证表现 阴证表现
    面色 红赤 苍白
    口渴 口渴喜冷饮 口不渴或喜热饮
    大便 秘结、臭秽 稀溏、无臭
    小便 短赤 清长
    舌苔 黄、燥 白、润
    脉象 浮、洪、数、大 沉、细、迟、弱

    💡 记忆口诀：阳证 = 红、热、燥、实；阴证 = 白、寒、润、虚。

    用在治则上：¶

    • 调整阴阳（根本治则）→ "损其有余，补其不足"
    • 阳偏盛（实热）→ 清热泻火（损其有余）
    • 阴偏盛（实寒）→ 温里散寒（损其有余）
    • 阳偏衰（虚寒）→ 温补阳气（补其不足）
    • 阴偏衰（虚热）→ 滋阴清热（补其不足）

    📖 经典原文（《黄帝内经·素问·至真要大论》）： "谨察阴阳所在而调之，以平为期。" → 翻译：仔细观察阴阳哪里失调，然后调整它，以恢复平衡为目标。

    1.4 自测习题¶

    习题1：概念理解

    为什么说"阴阳是相对的"而不是"绝对的"？请举一个例子说明。

    点击查看答案要点

    答案要点： - 阴阳是"相比较而言"的，不是固定标签 - 例如：上午 vs 下午 → 上午属阳（相对下午而言），但上午 vs 中午 → 上午又属阴（相对中午而言） - 再例如：背部属阳，腹部属阴；但背部和背部比，背上部又属阳，背下部属阴 - 结论：阴阳的划分要看"跟谁比"，没有绝对的标准

    习题2：临床应用

    患者女，28岁。症状：面色潮红，手足心热，口干咽燥，盗汗，舌红少苔，脉细数。

    请判断： 1. 这是阴证还是阳证？（答：阴证——阴虚则热，属阴亏） 2. 治疗原则应该是什么？（答：滋阴清热——补其不足）

    点击查看详细分析

    分析： 1. 面色潮红、手足心热、口干咽燥 → 这些都是"热象" 2. 但注意：这种热是"虚热"（病人同时有盗汗、舌红少苔、脉细数 → 都是阴虚的表现） 3. 所以不是"阳盛"（实热），而是"阴虚"（阴液不足，阳气相对偏亢） 4. 治疗：应该"滋阴"（补阴液）+ "清虚热"（不能用苦寒泻火的药，那会更伤阴）

    🔥 第二章：五行学说（保姆级详解）¶

    2.1 五行到底是什么？¶

    五行不是"5种物质"，而是"5种功能属性"。

    古人观察自然，把万物的功能特性归纳成 5 类：

    五行 特性（原文） 白话解释 对应自然现象
    木 木曰曲直 能屈能伸，向上向外舒展 春天树木发芽，向上生长
    火 火曰炎上 发热、向上 火苗总是往上烧
    土 土爰稼穑 播种和收获，承载万物 土地能种庄稼，也能承载房屋
    金 金曰从革 顺从变革，能柔能刚 金属可以锻造变形，也能削割东西
    水 水曰润下 滋润、向下 水滋润万物，而且往低处流

    💡 重点：五行学说的核心不是"木火土金水"这5种物质，而是它们代表的5种功能模式。中医用它来归类脏腑之间的关系。

    2.2 五行的 2 个基本规律¶

    规律1：五行相生（互相滋养）¶

    木 → 火 → 土 → 金 → 水 →（回到）木
（木生火）（火生土）（土生金）（金生水）（水生木）

    具体解释： - 木生火：木头能烧火 → 肝（木）藏血以养心（火） - 火生土：火烧完变成灰，灰归土 → 心（火）温煦脾（土），助脾运化 - 土生金：土里能挖出金属 → 脾（土）散精上输于肺（金） - 金生水：金属熔化变成液态（像水）→ 肺（金）肃降以助肾（水）行水 - 水生木：水能养树 → 肾（水）藏精以养肝（木）

    💡 记忆口诀：肝养心、心温脾、脾输肺、肺助肾、肾养肝（形成一个环）

    规律2：五行相克（互相制约）¶

    木 → 土 → 水 → 火 → 金 →（回到）木
（木克土）（土克水）（水克火）（火克金）（金克木）

    具体解释： - 木克土：树根能突破土壤 → 肝（木）疏泄太过会犯脾（土）（肝木乘脾土） - 土克水：土能筑堤挡水 → 脾（土）运化水湿，防止肾水泛滥 - 水克火：水能灭火 → 肾水（水）上济心火，防止心火过亢 - 火克金：火能熔金 → 心火（火）温煦肺金，但心火过亢会伤肺金 - 金克木：金属能砍树 → 肺金（金）肃降，防止肝木过度疏泄

    ⚠️ 临床意义：如果相克太过 → 叫"相乘"（比如肝郁犯脾 → 腹胀腹泻）；如果反向克制 → 叫"相侮"（比如肝火犯肺 → 咳嗽胸胁痛）

    2.3 五行归属表（必须背熟！）¶

    这是整门课最重要的表格，必须背到不需要想就能说出来：

    五行 五脏 五腑 五官 五体 五志 五液 五季
    木 肝 胆 目 筋 怒 泪 春
    火 心 小肠 舌 脉 喜 汗 夏
    土 脾 胃 口 肉 思 涎 长夏
    金 肺 大肠 鼻 皮 悲 涕 秋
    水 肾 膀胱 耳 骨 恐 唾 冬

    🔥 怎么背？ 不要死记！用"功能关联法"： - 肝主筋，筋连目（看东西靠眼球的筋）→ 肝开窍于目 - 心主血脉，舌上有丰富的血管 → 心开窍于舌 - 脾主肌肉，嘴唇是肌肉最外露的地方 → 脾其华在唇 - 肺主皮毛，鼻子是呼吸的门户 → 肺开窍于鼻 - 肾主骨，骨头里有骨髓，脑为髓海，耳通于脑 → 肾开窍于耳

    2.4 自测习题¶

    习题1：相生相克

    根据五行相生规律，肝（木）虚了，应该"虚则补其母"，请问应该补哪个脏腑？

    点击查看答案

    答案：应该补肾（水）。

    理由： - 五行相生：水 → 木（水生木） - 肾属水，肝属木 - 肾（水）是肝（木）的"母"（因为水生木） - 肝虚了 → "虚则补其母" → 补肾（水）以养肝（木） - 这个方法叫"滋水涵木法"（补肾阴以养肝阴）

    习题2：临床应用

    💉 第四章：气血津液（身体的"燃料"和"润滑油"）¶

    4.1 气（身体的动力）¶

    气到底是什么？

    不要用"空气"去理解气，用"功能活动"去理解。

    气 = 身体里所有推动、温煦、防御、固摄、气化的功能活动。

    气的5大功能：

    功能 解释 生活例子
    推动作用 气推动生长发育、血液运行、津液输布 气虚 → 乏力、懒动、发育迟缓
    温煦作用 气维持体温、温煦脏腑 气虚 → 畏寒肢冷、体温偏低
    防御作用 气护卫肌表，抵抗外邪 气虚 → 易感冒、反复感冒
    固摄作用 气控制血液、津液不溢出脉外 气虚 → 出血、自汗、尿频
    气化作用 气促进精、气、血、津液的相互转化 气虚 → 水肿、痰饮、代谢失常

    💡 记忆口诀：推温防固气，五功能要记。

    4.2 血（身体的营养物质）¶

    血的功能： 1. 营养滋润 → 面色红润、毛发润泽、肌肉丰满 2. 神志活动 → 血足则神安，血虚则失眠多梦

    气与血的关系（考试必考！）：

    关系 解释 临床意义
    气为血之帅 气能生血、行血、摄血 补血要补气（当归补血汤：黄芪5份 + 当归1份）
    血为气之母 血能载气、养气 失血过多 → 气也跟着脱（气随血脱）

    ⚠️ 临床意义：为什么治贫血要补气？因为"气为血之帅"，气能生血。为什么大出血病人会休克？因为"血为气之母"，血脱则气也跟着脱。

    4.3 津液（身体的"润滑油"）¶

    津液的功能： 1. 滋润濡养 → 润泽皮肤、濡养脏腑、充养骨髓 2. 调节平衡 → 通过出汗、排尿调节体温和水平衡

    津液代谢（谁在主宰？）：

    津液代谢全过程：
饮食入胃（胃主受纳）
    ↓
脾运化水液（脾主运化）
    ↓
上输于肺（肺主通调水道）
    ↓
肺宣发（布散到皮肤、头面）+ 肺肃降（下输到肾）
    ↓
肾气化（分清泌浊）→ 清者回吸收，浊者成尿
    ↓
膀胱储存和排泄（膀胱主气化）
    ↓
三焦是通道（三焦主通行元气和水液）

    💡 为什么治水肿要温肾阳？ 因为肾阳是水液代谢的根本动力，肾阳虚 → 水液不能气化 → 水肿。 💡 为什么脾虚会生湿？ 因为脾主运化水液，脾虚 → 水液停聚 → 痰湿内生。

    习题1：气的功能

    🌊 第五章：经络学说（脏腑之间的"信息高速公路"）¶

    5.1 经络到底是什么？¶

    不要用"神经"去理解经络，用"功能联系网络"去理解。

    经络 = 身体里所有运行气血、联络脏腑、沟通内外的功能网络。

    经络系统的组成：

    经络系统
├── 经脉（主干道）
│   ├── 正经（12条）：手足三阴三阳经
│   │   手三阴经：手太阴肺经、手厥阴心包经、手少阴心经
│   │   手三阳经：手阳明大肠经、手少阳三焦经、手太阳小肠经
│   │   足三阳经：足阳明胃经、足少阳胆经、足太阳膀胱经
│   │   足三阴经：足太阴脾经、足厥阴肝经、足少阴肾经
│   └── 奇经（8条）：督脉、任脉、冲脉、带脉、阴跷、阳跷、阴维、阳维
└── 络脉（支线）：十五别络 + 浮络 + 孙络

    💡 生活例子： - 你按揉合谷穴（手阳明大肠经）→ 能治牙痛、头痛 → 因为经络"联络"了手、面、牙齿 - 你踢到小腿（足阳明胃经经过）→ 好久都痛 → 因为胃经循行经过小腿 - 孕妇不能按合谷、三阴交 → 因为这两条经"联络"子宫，按了可能导致流产

    5.2 十二经脉的走向规律（必背！）¶

    走向规律： 1. 手三阴经：从胸走手（胸 → 手） 2. 手三阳经：从手走头（手 → 头） 3. 足三阳经：从头走足（头 → 足） 4. 足三阴经：从足走胸（足 → 胸）

    💡 记忆口诀： 手三阴：胸 → 手（心肺包在胸，经气往下走） 手三阳：手 → 头（手经往上走到头） 足三阳：头 → 足（头经往下走到足） 足三阴：足 → 胸（足经往上走回胸）

    为什么这样走？ → 形成一个"循环"：胸 → 手 → 头 → 足 → 胸…

    5.3 经络的4大功能¶

    功能 解释 临床应用
    运行气血 经络是气血运行的通道 针灸推拿 → 通过经络输送气血到病所
    联络脏腑 经络把五脏六腑联络成一个整体 肝病会传到脾（肝木乘脾土）→ 通过经络联系
    沟通内外 体表穴位能治内脏病 按合谷治牙痛、按足三里治胃胀
    感应传导 针灸的"得气"感会沿着经络传导 针刺合谷 → 酸麻胀感传到食指

    5.4 常见病证的经络辨证¶

    病证 病经 取穴举例
    牙痛 手阳明大肠经 合谷（原穴）、颊车（局部穴）
    头痛（前额） 足阳明胃经 头维、内庭
    头痛（两侧） 足少阳胆经 风池、足临泣
    头痛（后枕） 足太阳膀胱经 天柱、昆仑
    失眠 手少阴心经、督脉 神门、百会
    胃痛 足阳明胃经 足三里、中脘

    💡 记忆方法： - 牙痛 → 大肠经"入下齿中" → 取合谷 - 胃痛 → 胃经"属胃络脾" → 取足三里 - 失眠 → 心经"系舌本、属心" → 取神门

    点击查看答案

    🔥 第六章：病因与病机（身体怎么被搞坏的）¶

    6.1 外感病因（外来的病邪）¶

    六淫（风、寒、暑、湿、燥、火）¶

    重点：六淫不是"六种天气"，而是六种致病因素，它们有各自的"性格"。

    病邪 性格特点 典型症状 生活例子
    风邪 善行数变，轻扬开泄 怕风、汗出、皮疹瘙痒、游走性疼痛 荨麻疹 → 风邪（皮疹来去无常）
    寒邪 收引凝滞，损伤阳气 恶寒重发热轻、腹痛喜温、脉象紧 冬天淋雨 → 寒战、腹痛 → 寒邪
    暑邪 炎热升散，耗气伤津 高热、多汗、口渴、乏力 夏天中暑 → 暑邪
    湿邪 重浊黏滞，阻遏气机 头重如裹、四肢沉重、舌苔腻、病程长 长期住地下室 → 关节沉重、舌苔腻 → 湿邪
    燥邪 干涩伤津 口鼻干燥、皮肤干燥、干咳少痰 秋天干燥 → 口唇干裂、干咳 → 燥邪
    火邪 炎热上炎，耗气伤津 高热、口渴、面红、出血、谵语 感染高热 → 火邪

    💡 记忆口诀： 风善行数变（来去无常），寒收引凝滞（疼痛痉挛） 暑炎热升散（夏天特有），湿重浊黏滞（缠绵难愈） 燥干涩伤津（秋天特有），火炎热上炎（红肿热痛）

    6.2 内伤病因（自己作出来的病）¶

    七情（喜、怒、忧、思、悲、恐、惊）：

    情志 伤的脏腑 病机 生活例子
    怒 伤肝 肝气上逆、肝阳上亢 生气 → 头痛、面红目赤
    喜 伤心 心气涣散 过度兴奋 → 失眠、心悸
    思 伤脾 脾气郁结、运化失常 思虑过度 → 腹胀、食欲不振
    悲 伤肺 肺气消沉 悲伤过度 → 气短、乏力
    恐 伤肾 肾气不固 受惊吓 → 尿频、遗精
    惊 伤心肾 心神不宁 受惊 → 心悸、失眠多梦

    ⚠️ 临床意义：为什么"思虑过度会腹胀"？因为"思伤脾"，脾主运化，思虑过度 → 脾气郁结 → 运化失常 → 腹胀、食欲不振。 为什么"生气会头痛"？因为"怒伤肝"，肝气上逆 → 肝阳上亢 → 头痛、面红目赤。

    6.3 病机（疾病发生发展的机制）¶

    正邪相争¶

    关系 解释 临床表现
    正胜邪退 正气强，驱邪外出 病愈
    邪胜正衰 邪气强，正气不支 病进、恶化
    正邪相持 正气和邪气势均力敌 病情缠绵、反复发作

    💡 临床意义：为什么有些人感冒很快好，有些人感冒拖很久？因为"正气"强弱不同。正气强 → 正胜邪退 → 很快好；正气弱 → 正邪相持 → 拖很久。

    阴阳失调¶

    失调类型 解释 临床表现
    阴虚则热 阴液不足，阳气相对偏亢 潮热、盗汗、五心烦热、舌红少苔
    阳虚则寒 阳气不足，阴气相对偏盛 畏寒肢冷、夜尿多、面色白
    阳盛则热 阳气过盛（实热） 高热、口渴、面红、舌红苔黄
    阴盛则寒 阴气过盛（实寒） 恶寒重发热轻、腹痛喜温、舌淡苔白

    ⚠️ 重点区分： - 阴虚则热 = 虚热（潮热、盗汗、舌红少苔）→ 滋阴清热 - 阳盛则热 = 实热（高热、口渴、舌红苔黄）→ 清热泻火 - 阳虚则寒 = 虚寒（畏寒肢冷、夜尿多）→ 温补阳气 - 阴盛则寒 = 实寒（恶寒重、腹痛喜温）→ 温里散寒

    6.4 自测习题¶

    习题1：六淫辨证

    患者男，20岁。症状：恶寒重，发热轻，无汗，头身疼痛，鼻流清涕，舌苔薄白，脉浮紧。

    请判断：这是什么病邪导致的？为什么？

    点击查看答案

    答案： 1. 恶寒重发热轻 + 无汗 + 头身疼痛 + 鼻流清涕 + 舌苔薄白 + 脉浮紧 → 风寒感冒（寒邪） 2. 为什么是寒邪？→ 寒性"收引凝滞"，束缚肌表 → 恶寒重发热轻、无汗、头身疼痛 3. 脉浮紧 → 浮主表证，紧主寒邪 4. 治疗原则：辛温解表（麻黄汤、桂枝汤） 5. 为什么不用寒凉药？→ 寒证要用温热药，"寒者热之"

    习题2：七情致病

    患者女，35岁。症状：腹胀纳呆，便溏，情志抑郁，爱叹气，舌淡苔白，脉缓弱。

    请分析：这和七情中的哪个有关？为什么会出现腹胀纳呆？

    点击查看答案

    答案： 1. 腹胀纳呆 + 便溏 + 情志抑郁 + 爱叹气 → 思虑过度伤脾（思伤脾） 2. 为什么会出现腹胀纳呆？→ "思伤脾"，脾主运化，思虑过度 → 脾气郁结 → 运化失常 → 腹胀纳呆、便溏 3. 爱叹气 + 情志抑郁 → 肝气郁结（木克土，肝郁犯脾） 4. 治疗原则：健脾益气 + 疏肝理气 5. 常用方：逍遥散（疏肝健脾）

    🛡️ 第七章：防治原则（怎么让身体恢复正常）¶

    7.1 预防原则（未病先防，既病防变）¶

    未病先防：

    方法 解释 生活应用
    调养精神 保持情志舒畅，避免七情过激 少生气、少思虑、多开心
    锻炼身体 适度运动，增强体质 太极拳、八段锦、散步
    饮食有节 定时定量，不暴饮暴食 少喝冰饮、少吃辛辣
    起居有常 作息规律，不熬夜 11点前睡觉、不熬夜
    避邪防疫 避免外邪侵袭 天冷加衣、夏天防暑

    既病防变：

    💡 核心思想：有病了要早治，防止病情加重、传变。

    例子： - 肝有病 → 要先实脾（防止肝病传脾）→ "见肝之病，知肝传脾，当先实脾" - 这叫"先安未受邪之地"

    7.2 治疗原则（调整阴阳，扶正祛邪）¶

    治病求本：

    💡 翻译：治病要找根本原因，不要只治表面症状。

    例子： - 头痛 → 不一定是头的问题，可能是肝阳上亢、可能是血虚、可能是风寒 - 要治根本原因（肝火、血虚、风寒），不是只吃止痛药

    调整阴阳（根本治则）：

    原则 解释 应用
    损其有余 谁多了就削减谁 阳盛（实热）→ 清热泻火；阴盛（实寒）→ 温里散寒
    补其不足 谁少了就补充谁 阴虚（虚热）→ 滋阴清热；阳虚（虚寒）→ 温补阳气

    扶正与祛邪：

    原则 适用 例子
    扶正 正虚为主 气虚 → 补气（四君子汤）
    祛邪 邪实为主 食积 → 消食（保和丸）
    扶正祛邪并用 正虚邪实并存 气虚感冒 → 补气 + 解表（参苏饮）

    7.3 三因制宜（因时、因地、因人）¶

    原则 解释 例子
    因时制宜 根据季节气候调整治疗 夏天不用过热药，冬天不用过凉药
    因地制宜 根据地理环境调整治疗 南方多湿 → 多用祛湿药；北方多寒 → 多用温热药
    因人制宜 根据体质、年龄、性别调整治疗 老人虚衰 → 补益为主；小儿稚阴稚阳 → 清解为多

    💡 生活例子： - 同样感冒，夏天感冒多夹湿 → 加祛湿药；冬天感冒多夹寒 → 加温散寒药 - 同样胃痛，南方人多见湿热 → 清热祛湿；北方人多见虚寒 → 温中散寒
