    推拿学 学习指南¶

    推拿学是中医的特色疗法，通过手法作用于人体体表，达到防治疾病的目的。 这门课的特点是"动手能力强"——手法要练，治疗要练，不能只背书。

    为什么学推拿学？¶

    • 执业医师考试占分约5%
    • 临床实用性强：推拿科、康复科、骨伤科都用到推拿
    • "简、便、验、廉"：推拿成本低、无副作用，患者接受度高

    核心理论：推拿的作用原理¶

    推拿的基本作用（必背）¶

    作用 解释 适用
    疏通经络 推拿能疏通经络，调和气血 经络不通、气血瘀滞
    行气活血 推拿能促进气血运行，消除瘀滞 气滞血瘀、疼痛
    理筋整复 推拿能理顺筋络，复位关节 肌腱损伤、关节错位
    调整脏腑 推拿能调节脏腑功能，恢复平衡 脏腑功能失调
    增强体质 推拿能增强机体抵抗力 亚健康、慢性病

    推拿基本手法（必会）¶

    推拿手法有八大类，每类都有多个具体手法。

    1. 摆动类手法¶

    手法 操作 主治
    一指禅推法 用拇指指端或罗纹面着力，做往复摆动 头痛、失眠、胃脘痛
    滚法 用手背近小指侧部分附着于穴位，做往返滚动 腰腿痛、肩周炎

    2. 摩擦类手法¶

    手法 操作 主治
    推法 用指、掌或肘着力，做单向直线推动 头痛、失眠、便秘
    摩法 用手掌面或手指指面附着于穴位，做环形摩擦 脘腹胀痛、消化不良
    擦法 用手掌面、鱼际或小鱼际附着于穴位，做直线来回摩擦 腰腿痛、风寒感冒

    3. 振动类手法¶

    手法 操作 主治
    振法 用指或掌着力，做高频率振动 失眠、头痛、胃脘痛

    4. 挤压类手法¶

    手法 操作 主治
    按法 用指或掌着力，做垂直向下按压 腰腿痛、头痛
    拿法 用拇指和其余手指相对用力，提捏肌肤 颈椎病、肩周炎
    捏法 用拇指和食指相对用力，捏提肌肤 小儿积滞、消化不良
    掐法 用指甲重刺穴位 晕厥、中暑（急救）

    5. 叩击类手法¶

    手法 操作 主治
    拍法 用虚掌拍打体表 腰腿痛、肌肉疲劳
    击法 用拳、掌根或指尖叩击体表 腰腿痛、肩周炎

    6. 运动关节类手法¶

    手法 操作 主治
    摇法 使关节做被动旋转运动 颈椎病、肩周炎
    扳法 使关节做被动伸展运动，常伴"咔嗒"声 颈椎病、腰椎间盘突出
    拔伸法 对关节做对抗性牵引 颈椎病、腰椎间盘突出

    扳法和拔伸法的注意事项

    这两种手法风险较高，需要在老师指导下练习，不能自学自用！

    禁忌症： 骨质疏松、骨折、肿瘤、结核、感染等。

    常见病证的推拿治疗¶

    1. 颈椎病¶

    辨证分型：

    证型 特点 治法 主穴/部位
    颈型 颈肩痛，活动受限 舒筋通络、活血止痛 颈肩部、风池、天柱、肩井
    神经根型 颈肩痛 + 上肢放射痛、麻木 舒筋通络、活血止痛、松解粘连 颈肩部、上肢部、曲池、合谷
    椎动脉型 颈肩痛 + 眩晕、恶心 舒筋通络、活血止痛、平肝潜阳 颈肩部、头面部、风池、百会
    交感神经型 颈肩痛 + 心慌、胸闷、多汗 舒筋通络、活血止痛、调节植物神经 颈肩部、胸背部、心俞、内关
    脊髓型 颈肩痛 + 下肢无力、行走不稳 慎用推拿（易加重病情） 建议手术治疗

    推拿操作（颈型）：

    1. 放松手法：用滚法、按法、拿法放松颈肩部肌肉（5-10分钟）
    2. 点穴：点按风池、天柱、肩井、曲池、合谷（每穴1分钟）
    3. 运动关节：摇颈椎（左右旋转、前屈后伸）（各5-10次）
    4. 整理手法：用拍法、叩击法放松颈肩部（2-3分钟）

    2. 肩周炎（五十肩）¶

    特点： 50岁左右发病，肩关节疼痛 + 活动受限（"冻结肩"）

    推拿操作：

    1. 放松手法：用滚法、按法、拿法放松肩背部肌肉（5-10分钟）
    2. 点穴：点按肩髃、肩髎、肩贞、曲池、合谷（每穴1分钟）
    3. 运动关节：摇肩关节（前屈、后伸、外展、内收、内旋、外旋）（各10-20次）
    4. 松解粘连：用扳法、拔伸法松解粘连（轻柔操作，避免暴力）
    5. 整理手法：用拍法、叩击法放松肩背部（2-3分钟）

    肩周炎的"爬墙"锻炼

    推拿治疗后，患者要坚持锻炼——面对墙壁，用患侧手指沿墙壁慢慢向上爬，每天爬高一点，帮助恢复肩关节活动度。

    3. 腰椎间盘突出症¶

    特点： 腰痛 + 下肢放射痛、麻木（坐骨神经痛）

    推拿操作：

    1. 放松手法：用滚法、按法放松腰臀部肌肉（10-15分钟）
    2. 点穴：点按肾俞、大肠俞、环跳、委中、阳陵泉、悬钟（每穴1分钟）
    3. 运动关节：用扳法（斜扳法、后伸扳法）调整腰椎关节（轻柔操作）
    4. 牵引：用拔伸法牵引腰椎（需两人配合）
    5. 整理手法：用拍法、叩击法放松腰臀部（3-5分钟）

    腰椎间盘突出症的推拿禁忌症

    • 中央型腰椎间盘突出（易压迫马尾神经）
    • 伴有马尾综合征（大小便失禁）
    • 骨质疏松、骨折
    • 肿瘤、结核、感染

    以上情况禁用扳法和拔伸法！

    4. 小儿推拿（特色内容）¶

    小儿推拿是推拿学的特色分支，用手法治疗小儿常见病。

    常用手法：

    手法 操作 主治
    推法 用拇指桡侧缘或指面做单向直线推动 发热、腹泻、便秘
    揉法 用指或掌做环形揉动 腹痛、腹泻、消化不良
    按法 用指或掌做垂直向下按压 腹痛、头痛
    摩法 用手掌面做环形摩擦 腹胀、消化不良
    捏脊法 用拇指和食指捏提脊柱两侧皮肤 小儿积滞、厌食、体弱

    常见病治疗：

    病证 主穴/部位 手法
    小儿腹泻 脾俞、胃俞、大肠俞、足三里 推法、揉法、按法
    小儿厌食 脾俞、胃俞、中脘、足三里 推法、揉法、摩法
    小儿发热 大椎、曲池、合谷 推法、揉法、拿法
    小儿积滞 脾俞、胃俞、中脘、足三里 捏脊法、摩法

    推拿注意事项（必背）¶

    推拿禁忌症

    以下情况禁用或慎用推拿：

    • 皮肤破损、感染、溃疡
    • 骨折、脱位、韧带撕裂
    • 肿瘤、结核、感染
    • 出血倾向（如血友病、白血病）
    • 妊娠妇女（腹部、腰骶部禁用）
    • 严重心、脑、肾疾病
    • 情绪不稳定、醉酒、过度疲劳

    推拿操作注意事项

    1. 明确诊断：推拿前要先诊断，不能"盲目推拿"
    2. 手法轻柔：手法要由轻到重，由慢到快，不能暴力
    3. 密切观察：推拿过程中要观察患者反应，如有不适，立即停止
    4. 术后休息：推拿后要让患者休息10-15分钟，避免立即剧烈活动

    学习进度规划¶

    阶段 内容 时间
    第一阶段 推拿基本手法（摆动类、摩擦类） 3天
    第二阶段 推拿基本手法（振动类、挤压类、叩击类） 3天
    第三阶段 推拿基本手法（运动关节类） 2天
    第四阶段 常见病证的推拿治疗（颈椎病、肩周炎） 5天
    第五阶段 常见病证的推拿治疗（腰椎间盘突出症） 3天
    第六阶段 小儿推拿 3天
    第七阶段 复习 + 手法练习 5天

    常见学习误区¶

    误区1：只背手法名称，不练手法

    知道"滚法"是什么，但不会做——这是无效学习。

    正确做法： 每个手法都要在同学身上练，练到"得心应手"。

    误区2：推拿治疗不辨证

    推拿也要辨证——同一种病，不同证型，手法和操作部位可能不同。

    正确做法： 学每个病证的推拿治疗，都要先辨证，再选手法、选部位。

    误区3：忽略推拿禁忌症

    推拿不是"万能的"，有些情况禁用或慎用推拿。

    正确做法： 推拿禁忌症要背熟，临床中遇到这些情况，要果断转诊。

    自测习题¶

    ??? question "1. 患者颈椎病（颈型），颈肩痛，活动受限。推拿操作的第一步是什么？" 答案： 放松手法（用滚法、按法、拿法放松颈肩部肌肉）。

    **解析：** 推拿操作的一般顺序：放松手法 → 点穴 → 运动关节 → 整理手法。

    ??? question "2. 患者肩周炎，肩关节疼痛，活动受限。除了推拿治疗，还要做什么？" 答案： 坚持锻炼（如"爬墙"锻炼）。

    **解析：** 肩周炎的治疗，**推拿 + 锻炼**缺一不可。不锻炼，肩关节活动度恢复不了。

    ??? question "3. 患者腰椎间盘突出症，中央型，伴有马尾综合征（大小便失禁）。能不能做推拿？为什么？" 答案： 不能。因为中央型腰椎间盘突出 + 马尾综合征是推拿的禁忌症，盲目推拿可能加重病情，甚至导致瘫痪。

    **解析：** 推拿前要**明确诊断**，排除禁忌症。

    ??? question "4. 小儿推拿的"捏脊法"主治什么？操作方法是怎样的？" 答案： 主治小儿积滞、厌食、体弱。操作方法：用拇指和食指捏提脊柱两侧皮肤，从长强穴（尾骨端）捏到大椎穴（第七颈椎棘突下），每天捏3-5遍。

    **解析：** 捏脊法是小儿推拿的**特色手法**，能调理脾胃、增强体质。

    下一步¶

    • 练习推拿基本手法（推、拿、按、摩、揉、捏）
    • 学习常见病证的推拿治疗（颈椎病、肩周炎、腰椎间盘突出症）
    • 了解小儿推拿的特色手法和常见病治疗
    • 学习西医基础（解剖学、生理学、病理学）

    记住： 推拿学的核心是"手法 + 辨证"—— 手法要练熟，辨证要准确，才能在临床中取得好效果。
