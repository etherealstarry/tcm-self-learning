    针灸治疗学 学习指南¶

    针灸治疗学是针灸推拿的临床课——前面学的经络腧穴学是"工具"，这门课是"怎么用工具治病"。 这门课的核心是"辨证选穴"——知道什么病选什么穴。

    为什么这门课特别重要？¶

    • 执业医师考试占分约8-10%
    • 针灸科临床的核心——每个针灸科医生都要掌握
    • "辨证 + 选穴 + 操作"三位一体——不仅要会辨证，还要会选穴、会操作

    核心理论：针灸治疗原则¶

    1. 基本治疗原则（必背）¶

    原则 适用 举例
    补虚泻实 虚证用补法，实证用泻法 气虚 → 补法；气滞 → 泻法
    清热温寒 热证用清法，寒证用温法 风热 → 针泻法；风寒 → 灸法
    治病求本 找病因、病机，从根本上治疗 腰痛 → 不全是"肾虚"，要辨证
    三因制宜 因时、因地、因人制宜 春夏浅刺，秋冬深刺

    2. 配穴方法（必背）¶

    方法 解释 举例
    本经配穴 选用病变经脉的穴位 肺病 → 选肺经穴位（列缺、尺泽）
    表里经配穴 选用相表里经脉的穴位 肺与大肠相表里 → 肺病可选大肠经穴位（合谷）
    上下配穴 选用上肢和下肢的穴位 头痛（上） + 足三里（下）
    前后配穴 选用胸腹和背腰的穴位 胃病 → 中脘（前） + 胃俞（后）
    左右配穴 选用左右两侧的穴位 偏瘫 → 针刺健侧 + 患侧

    各科病证的治疗（重点）¶

    1. 内科病证¶

    中风（脑卒中）¶

    辨证分型：

    分期 证型 主穴 配穴
    中经络（无意识障碍） 肝阳暴亢 水沟、内关、三阴交、极泉、尺泽、委中 太冲、太溪
    风痰阻络 同上 丰隆、合谷
    痰热腑实 同上 曲池、内庭
    气虚血瘀 同上 足三里、气海
    阴虚风动 同上 太溪、风池
    中脏腑（有意识障碍） 闭证（实证） 水沟、十二井、太冲、丰隆 痰热 + 曲池；痰火 + 行间
    脱证（虚证） 关元、神阙（隔盐灸） 汗出 + 复溜；鼾声 + 天突

    中风治疗的"醒脑开窍"法（石学敏院士）

    主穴：水沟、内关、三阴交（必选）

    操作：水沟用雀啄法，以眼球湿润为度；内关用提插捻转泻法；三阴交用提插补法。

    眩晕¶

    证型 主穴 配穴
    肝阳上亢 百会、风池、太冲、行间、侠溪 耳鸣 + 翳风
    痰湿中阻 百会、风池、头维、中脘、丰隆 胸闷 + 膻中
    气血亏虚 百会、风池、气海、血海、足三里 心悸 + 内关
    肾精不足 百会、风池、肾俞、太溪、悬钟 遗精 + 关元

    头痛¶

    分部辨证（必背）：

    部位 经络 主治穴位
    前额痛（阳明经） 阳明经 印堂、上星、阳白、合谷
    侧头痛（少阳经） 少阳经 太阳、率谷、风池、外关
    后头痛（太阳经） 太阳经 天柱、玉枕、后溪
    巅顶痛（厥阴经） 厥阴经 百会、四神聪、太冲

    2. 妇科病证¶

    月经不调¶

    类型 主穴 配穴
    月经先期 关元、三阴交、血海 气虚 + 足三里、脾俞；血热 + 行间、地机
    月经后期 气海、三阴交、归来 血虚 + 足三里、脾俞；血寒 + 命门、神阙（灸）
    月经先后无定期 关元、三阴交、肝俞 肝郁 + 太冲、期门；肾虚 + 肾俞、太溪

    痛经¶

    辨证分型：

    证型 主穴 配穴
    气滞血瘀 关元、三阴交、地机、次髎 胁痛 + 阳陵泉；乳房胀痛 + 太冲
    寒凝血瘀 同上 冷痛 + 命门、神阙（灸）
    湿热瘀阻 同上 带下黄稠 + 阴陵泉、行间
    气血虚弱 关元、三阴交、足三里、气海 乏力 + 脾俞、胃俞
    肾气亏虚 关元、三阴交、肾俞、太溪 头晕耳鸣 + 悬钟

    痛经治疗的"经验穴"

    • 地机（脾经郄穴）→ 痛经要穴
    • 次髎 → 妇科要穴，尤善治痛经
    • 三阴交 → 妇科第一穴，所有妇科病都可用

    3. 骨伤科病证¶

    面瘫（周围性面神经麻痹）¶

    辨证： 急性期（发病1-2周）→ 风寒或风热侵袭；恢复期（2周后）→ 气血不足、经络瘀阻

    分期 主穴 配穴
    急性期 翳风、风池、合谷、太冲 风寒 + 列缺；风热 + 曲池
    恢复期 阳白、四白、颊车、地仓、颧髎、合谷 抬眉困难 + 攒竹；鼻唇沟变浅 + 迎香；口角歪斜 + 承浆

    操作要点： - 急性期：面部穴位浅刺、少刺，避免过重刺激 - 恢复期：面部穴位可深刺、透刺（如地仓透颊车） - 翳风穴：急性期重刺激，恢复期轻刺激

    坐骨神经痛¶

    证型 主穴 配穴
    寒湿阻络 腰夹脊、环跳、委中、阳陵泉、悬钟 冷痛 + 命门、神阙（灸）
    瘀血阻络 同上 刺痛 + 膈俞、血海
    湿热蕴结 同上 灼热痛 + 曲池、内庭

    针灸操作方法（必会）¶

    1. 进针方法¶

    方法 适用 操作
    指切进针法 短针（1寸以下） 用指甲切压穴位，针尖紧贴指甲边缘进针
    夹持进针法 长针（2寸以上） 用左手拇、食指捏住针身下端，右手持针柄进针
    提捏进针法 皮肉浅薄处（如印堂） 用左手拇、食指捏起穴位皮肤，右手持针从捏起处进针
    舒张进针法 皮肤松弛处（如腹部） 用左手拇、食指撑开穴位皮肤，右手持针从撑开处进针

    2. 行针手法¶

    手法 操作 适用
    提插法 针尖向上提、向下插，反复进行 催气、行气
    捻转法 针柄向左、向右旋转，反复进行 催气、行气
    刮柄法 用指甲刮针柄，使针身颤动 催气
    弹针法 用手指弹针柄，使针身颤动 催气

    3. 补泻手法（必背）¶

    手法 操作 适用
    捻转补泻 补法：捻转角度小、用力轻、频率慢、时间短；泻法：相反 所有穴位
    提插补泻 补法：先浅后深、重插轻提、幅度小、频率慢；泻法：相反 所有穴位
    疾徐补泻 补法：进针慢、出针快；泻法：进针快、出针慢 所有穴位
    开阖补泻 补法：出针后按闭针孔；泻法：出针后不按针孔 所有穴位

    学习进度规划¶

    阶段 内容 时间
    第一阶段 针灸治疗原则 + 配穴方法（背诵） 2天
    第二阶段 内科病证（中风、眩晕、头痛） 5天
    第三阶段 妇科病证（月经不调、痛经） 3天
    第四阶段 骨伤科病证（面瘫、坐骨神经痛） 3天
    第五阶段 其他病证（胃痛、泄泻、失眠等） 5天
    第六阶段 针灸操作方法（练习） 3天
    第七阶段 复习 + 做病例分析题 5天

    常见学习误区¶

    误区1：只背主穴，不背配穴

    考试时，病例分析题会要求"随证配穴"——只知道主穴，配不上穴，拿不到全分。

    正确做法： 每个病证的主穴（必选）和配穴（随证加减）都要背。

    误区2：不练操作

    针灸是动手课，不练操作，到了临床就不会扎。

    正确做法： 找同学互相练，先练进针、行针，再练补泻手法。

    误区3：忽略"急症"的针灸治疗

    中风、晕厥、休克等急症，针灸是首选疗法（醒脑开窍）。

    正确做法： 急症的针灸治疗要重点掌握（水沟、十二井、合谷、太冲等）。

    自测习题¶

    ??? question "1. 患者中风中经络，右侧偏瘫，口角歪斜。主穴有哪些？" 答案： 水沟、内关、三阴交、极泉、尺泽、委中。

    **解析：** 这是"醒脑开窍"法的主穴，所有中风中经络都要选。

    ??? question "2. 患者前额痛，连及眉棱骨。属于哪条经？选哪些穴位？" 答案： 阳明经头痛。选穴：印堂、上星、阳白、合谷。

    **解析：** 前额痛 = 阳明经头痛（四总穴歌："面口合谷收"）。

    ??? question "3. 患者痛经，经前小腹胀痛，经色暗有块，胸胁胀痛。证型？主穴？配穴？" 答案： 气滞血瘀证。主穴：关元、三阴交、地机、次髎。配穴：胁痛 + 阳陵泉；乳房胀痛 + 太冲。

    **解析：** 经前小腹胀痛 + 经色暗有块 + 胸胁胀痛 = 气滞血瘀 → 理气活血、化瘀止痛。

    ??? question "4. 患者面瘫，发病3天，耳后疼痛，恶寒发热。分期？主穴？操作要点？" 答案： 急性期。主穴：翳风、风池、合谷、太冲。操作要点：面部穴位浅刺、少刺，避免过重刺激；翳风穴重刺激。

    **解析：** 发病3天 = 急性期 → 风寒或风热侵袭 → 面部穴位浅刺（避免过重刺激加重水肿）。

    下一步¶

    • 掌握针灸治疗原则和配穴方法
    • 逐个学习各科病证的辨证分型和主穴、配穴
    • 练习针灸操作方法（进针、行针、补泻）
    • 学习推拿学

    记住： 针灸治疗学的核心是"辨证选穴"—— 知道什么病（诊断），知道什么证（辨证），才能选对穴、治好病。
