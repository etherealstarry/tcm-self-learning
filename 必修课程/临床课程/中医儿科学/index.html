    中医儿科学 学习指南¶

    中医儿科学主要研究小儿生理、病理特点和儿科常见病的辨证论治。 这门课的特点是"脏腑辨证"为主，尤其是肺、脾、肾三脏。

    为什么学中医儿科学？¶

    • 执业医师考试占分约5-8%
    • 临床需求大：儿科病（感冒、咳嗽、泄泻、厌食）发病率高
    • 中医优势明显：小儿"脏气清灵，易趋康复"，中药治疗效果好

    核心理论：小儿生理病理特点¶

    小儿生理特点（必背）¶

    小儿生理特点

    1. 脏腑娇嫩，形气未充（稚阴稚阳）
    2. 生机蓬勃，发育迅速（纯阳之体）

    解释： - "稚阴稚阳" → 小儿脏腑功能不完善，容易被外邪侵袭 - "纯阳之体" → 小儿生长发育快，需要大量营养

    小儿病理特点（必背）¶

    小儿病理特点

    1. 发病容易，传变迅速
    2. 脏气清灵，易趋康复

    解释： - "发病容易" → 小儿抵抗力弱，容易生病 - "传变迅速" → 小儿病情变化快，容易"化热、化火" - "脏气清灵" → 小儿对药物反应敏感，治疗效果好

    💡 生活例子： - 小儿感冒 → 只要辨证准确，1-2付药就能退烧（脏气清灵，易趋康复） - 但小儿感冒也容易"化热" → 今天风寒，明天就变成风热（传变迅速） - 所以小儿用药要"轻、巧、准"，不能像大人那样"重剂量"

    ⚠️ 红旗警告：小儿高热+惊厥 → 小儿惊厥！要立刻物理降温+送医院，不能在家硬扛！ ⚠️ 红旗警告：小儿腹泻+口渴+尿少 → 脱水！要立刻口服补液盐，不能只喝白水！

    重点病证详解¶

    1. 肺系病证（感冒、咳嗽、肺炎喘嗽）¶

    小儿肺系病证最常见，因为小儿"肺脏娇嫩"，容易被外邪侵袭。

    💡 生活例子： - 小儿感冒 → 只要辨证准确，1-2付药就能退烧（脏气清灵，易趋康复） - 但小儿感冒也容易"化热" → 今天风寒，明天就变成风热（传变迅速） - 所以小儿用药要"轻、巧、准"，不能像大人那样"重剂量"

    感冒（小儿感冒）¶

    证型 特点 代表方
    风寒感冒 恶寒发热，无汗，鼻塞流清涕 荆防败毒散
    风热感冒 发热重，有汗，鼻塞流黄涕，咽痛 银翘散
    暑湿感冒 发热，头重如裹，胸闷，苔腻（夏季） 新加香薷饮
    时疫感冒 高热，全身症状重，传染性强（流感） 银翘散 + 板蓝根

    💡 临床意义：小儿感冒与成人不同！ - 小儿感冒传变迅速 → 很容易从表证变成里证（like 肺炎） - 小儿感冒容易化热 → 即使初起是风寒，1-2天后也容易变成风热 - 所以小儿感冒不能按成人剂量用药，要"轻清宣透"

    ⚠️ 红旗警告：小儿感冒+高热惊厥 → 小儿惊厥！要立刻物理降温+送医院，不能在家硬扛！

    咳嗽（小儿咳嗽）¶

    证型 特点 代表方
    风寒咳嗽 咳嗽频作，痰白稀薄，恶寒 金沸草散
    风热咳嗽 咳嗽不爽，痰黄稠，咽痛 桑菊饮
    痰热咳嗽 咳嗽痰多，色黄稠，苔黄腻 清金化痰汤
    阴虚咳嗽 干咳少痰，午后潮热，盗汗 沙参麦冬汤

    💡 生活例子：小儿咳嗽与成人不同！ - 小儿咳嗽痰多 → 因为小儿"脾常不足"，容易生湿成痰 - 小儿咳嗽容易化热 → 痰白稀很快变成痰黄稠 - 所以小儿咳嗽要早治，不能"扛一扛就好"

    肺炎喘嗽（小儿肺炎）¶

    证型 特点 代表方
    风寒闭肺 恶寒发热，咳嗽气急，痰白稀 华盖散
    风热闭肺 发热，咳嗽气急，痰黄稠，咽痛 银翘散 + 麻杏石甘汤
    痰热闭肺 高热，咳嗽气急，痰黄稠，喘促，苔黄腻 五虎汤 + 葶苈大枣泻肺汤
    毒热闭肺 高热不退，咳嗽剧烈，喘促鼻煽，苔黄燥 黄连解毒汤 + 麻杏石甘汤
    阴虚肺热 低热盗汗，干咳少痰，舌红少苔 沙参麦冬汤
    肺脾气虚 低热起伏，咳嗽无力，乏力，纳差 人参五味子汤

    ⚠️ 红旗警告：小儿肺炎+喘促鼻煽+高热 → 重症肺炎！要立刻送医院，不能在家自行处理！ ⚠️ 红旗警告：小儿肺炎+口唇紫绀 → 缺氧！要立刻吸氧+送医院！

    ??? question "自测：患儿3岁，发热，咳嗽气急，痰黄稠，咽痛，舌尖红，苔薄黄，脉浮数。证型？用方？" 答案： 风热闭肺证，银翘散合麻杏石甘汤。

    **解析：** 发热 + 咳嗽气急 + 痰黄稠 + 咽痛 + 舌尖红/苔薄黄/脉浮数 = 风热闭肺 → 辛凉宣肺、清热化痰。

    2. 脾胃病证（泄泻、厌食、积滞）¶

    小儿脾胃病证非常常见，因为小儿"脾常不足"。

    泄泻（小儿腹泻）¶

    证型 特点 代表方
    风寒泄泻 大便清稀，臭气不甚，肠鸣腹痛 藿香正气散
    湿热泄泻 大便水样，色黄褐，臭秽，发热，苔黄腻 葛根黄芩黄连汤
    伤食泄泻 大便酸臭，夹未消化食物，脘腹胀满 保和丸
    脾虚泄泻 大便稀溏，色淡不臭，食后作泻，乏力 参苓白术散
    脾肾阳虚泄泻 久泻不愈，大便清稀，完谷不化，肢冷 附子理中汤 + 四神丸

    💡 生活例子： - 吃了冷饮后拉肚子、大便清稀 → 这是"风寒泄泻" - 吃了不干净的东西后拉肚子、大便臭秽、发热 → 这是"湿热泄泻" - 吃太多、大便酸臭、有未消化食物 → 这是"伤食泄泻"（积食引起的腹泻） - 长期拉肚子、吃什么拉什么 → 这是"脾虚泄泻"，需要健脾益气

    ⚠️ 红旗警告：小儿腹泻+口渴+尿少+眼窝凹陷 → 重度脱水！要立刻口服补液盐或送医院输液！

    泄泻的辨证要点

    • 暴泻（急性）→ 多属实证（风寒、湿热、伤食）
    • 久泻（慢性）→ 多属虚证（脾虚、脾肾阳虚）

    厌食（小儿厌食）¶

    证型 特点 代表方
    脾胃不和 食欲不振，脘腹胀满，大便不调 不换金正气散
    脾胃气虚 食欲不振，面色萎黄，乏力，大便溏薄 健脾丸
    脾胃阴虚 食欲不振，口干多饮，大便干结，舌红少苔 养胃增液汤

    💡 生活例子： - 孩子吃饭不香、肚子胀、大便不规律 → 这是"脾胃不和"型厌食 - 孩子面色发黄、不想吃饭、大便稀 → 这是"脾胃气虚"型，需要健脾益气 - 孩子口干、多喝水、大便干结 → 这是"脾胃阴虚"型，需要养胃滋阴

    ⚠️ 红旗警告：小儿厌食+消瘦+腹胀如鼓 → 可能是疳积！严重时会影响生长发育，必须调理脾胃！

    积滞（小儿积食）¶

    证型 特点 代表方
    乳食内积 脘腹胀满，嗳腐吞酸，大便酸臭 消乳丸（乳积）、保和丸（食积）
    脾虚夹积 脘腹胀满，不思饮食，乏力，大便溏薄 健脾丸

    💡 生活例子： - 吃太多肉食、零食后肚子胀、打嗝有酸臭味 → 这是"乳食内积"型积滞 - 长期消化不良、肚子胀但不厉害、乏力 → 这是"脾虚夹积"型，需要健脾消食

    ⚠️ 红旗警告：小儿积滞长期不愈+消瘦+腹胀如鼓 → 可能是疳积！严重影响生长发育，必须及早调理！

    3. 心肝病证（惊风、癫痫）¶

    急惊风（小儿惊厥）¶

    证型 特点 代表方
    风热动风 发热，惊厥，咳嗽，咽痛 银翘散
    气营两燔 高热，惊厥，口渴，苔黄燥 清瘟败毒饮
    邪陷心肝 高热，惊厥，烦躁，神昏 羚角钩藤汤
    湿热疫毒 高热，惊厥，痢下脓血（中毒性痢疾） 黄连解毒汤
    惊恐惊风 惊惕，惊厥，夜卧不安 琥珀抱龙丸

    慢惊风（慢性惊厥）¶

    证型 特点 代表方
    脾虚肝亢 抽搐无力，面色萎黄，乏力 缓肝理脾汤
    脾肾阳衰 抽搐无力，手足蠕动，肢冷，舌淡 固真汤
    阴虚风动 抽搐无力，手足蠕动，低热，盗汗 大定风珠

    4. 肾系病证（水肿、遗尿）¶

    水肿（小儿肾炎）¶

    证型 特点 代表方
    风水相搏 眼睑浮肿，继则四肢全身，恶寒发热 麻黄连翘赤小豆汤
    湿热内侵 浮肿，小便短赤，苔黄腻 五味消毒饮 + 小蓟饮子
    肺脾气虚 浮肿不著，乏力，易感冒 参苓白术散
    脾肾两虚 全身浮肿，腰以下为甚，肢冷，舌淡 真武汤

    遗尿（小儿尿床）¶

    证型 特点 代表方
    肾气不足 遗尿，面色㿠白，腰酸，畏寒 菟丝子散
    脾肺气虚 遗尿，乏力，食欲不振，大便溏薄 补中益气汤
    心肾不交 遗尿，寐不安宁，烦躁，舌红 导赤散 + 交泰丸

    儿科用药特点（必背）¶

    儿科用药"五宜五不宜"

    • 宜轻清，不宜重浊
    • 宜平和，不宜峻猛
    • 宜清灵，不宜滋腻
    • 宜量少，不宜量大
    • 宜中病即止，不宜过剂

    解释： 小儿"脏腑娇嫩"，用药要轻、清、灵，不能像成人那样用重药。

    学习进度规划¶

    阶段 内容 时间
    第一阶段 肺系病证（感冒、咳嗽、肺炎喘嗽） 3天
    第二阶段 脾胃病证（泄泻、厌食、积滞） 3天
    第三阶段 心肝病证（惊风） + 肾系病证（水肿、遗尿） 3天
    第四阶段 复习 + 做真题 2天

    常见学习误区¶

    误区1：把小儿病证和成人病证混淆

    小儿感冒和成人感冒的辨证分型不完全一样（小儿有"暑湿感冒"，成人少见）。

    正确做法： 小儿病证的辨证分型要单独记，不能照搬成人。

    误区2：忽略小儿"易虚易实"的特点

    小儿病情变化快，今天还是"风寒感冒"，明天可能就"化热"了。

    正确做法： 学每个病证都要知道"传变规律"，不能只记"定型"。

    误区3：儿科用药剂量记不清

    小儿用药剂量是按年龄/体重计算的，不能和成人一样。

    正确做法： 记住"小儿用药剂量表"（如新生儿用成人量的1/6，婴儿用1/3，幼儿用1/2，学龄前用2/3，学龄用成人量）。

    自测习题¶

    ??? question "1. 患儿2岁，大便清稀，夹未消化食物，脘腹胀满，嗳腐吞酸，舌苔厚腻，脉滑。证型？用方？" 答案： 伤食泄泻，保和丸。

    **解析：** 大便夹未消化食物 + 脘腹胀满 + 嗳腐吞酸 + 舌苔厚腻/脉滑 = 伤食 → 消食化滞、和胃止泻。

    ??? question "2. 患儿4岁，发热，咳嗽气急，痰黄稠，咽痛，舌尖红，苔薄黄，脉浮数。证型？用方？" 答案： 风热闭肺证（肺炎喘嗽），银翘散合麻杏石甘汤。

    **解析：** 发热 + 咳嗽气急 + 痰黄稠 + 咽痛 + 舌尖红/苔薄黄/脉浮数 = 风热闭肺 → 辛凉宣肺、清热化痰。

    ??? question "3. 患儿5岁，遗尿，面色㿠白，腰酸，畏寒，舌淡苔白，脉沉无力。证型？用方？" 答案： 肾气不足证，菟丝子散。

    **解析：** 遗尿 + 面色㿠白 + 腰酸 + 畏寒 + 舌淡/脉沉无力 = 肾气不足 → 温补肾阳、固涩小便。

    ??? question "4. 患儿1岁，高热，惊厥，烦躁，口渴，苔黄燥，脉数。证型？用方？" 答案： 气营两燔证（急惊风），清瘟败毒饮。

    **解析：** 高热 + 惊厥 + 烦躁 + 口渴 + 苔黄燥/脉数 = 气营两燔 → 清气凉营、息风开窍。

    📝 自测习题¶

    ??? question "1. 患儿1岁，发热，咳嗽，气促，鼻翼煽动，舌红苔黄，脉浮数。证型？用方？" 答案： 风热闭肺证，麻杏石甘汤。

    **解析：** 发热 + 咳嗽 + 气促 + 鼻翼煽动 + 舌红苔黄/脉浮数 = 风热闭肺 → 辛凉宣肺、清热化痰。

    ??? question "2. 患儿3岁，厌食，面色萎黄，乏力，大便溏薄，舌淡苔白，脉缓弱。证型？用方？" 答案： 脾胃气虚证，参苓白术散。

    **解析：** 厌食 + 面色萎黄 + 乏力 + 大便溏薄 + 舌淡苔白/脉缓弱 = 脾胃气虚 → 健脾益气、运脾开胃。

    ??? question "3. 患儿5岁，遗尿，面色晄白，乏力，腰膝酸软，舌淡苔白，脉沉弱。证型？用方？" 答案： 下元虚寒证，菟丝子散。

    **解析：** 遗尿 + 面色晄白 + 乏力 + 腰膝酸软 + 舌淡苔白/脉沉弱 = 下元虚寒 → 温补肾阳、固涩止遗。

    ??? question "4. 患儿2岁，腹泻，大便黄稀，臭秽，发热，舌红苔黄腻，脉滑数。证型？用方？" 答案： 湿热泻证，葛根黄芩黄连汤。

    **解析：** 腹泻 + 大便黄稀臭秽 + 发热 + 舌红苔黄腻/脉滑数 = 湿热泻 → 清热利湿、分利止泻。

    ??? question "5. 患儿4岁，紫癜，皮疹色红，瘙痒，发热，舌红苔黄，脉浮数。证型？用方？" 答案： 风热伤络证，连翘败毒散。

    **解析：** 紫癜 + 皮疹色红瘙痒 + 发热 + 舌红苔黄/脉浮数 = 风热伤络 → 疏风清热、凉血止血。

    下一步¶

    • 掌握小儿生理病理特点（"稚阴稚阳"、"纯阳之体"）
    • 逐个学习肺系病证（感冒、咳嗽、肺炎喘嗽）的辨证分型

    • 熟悉儿科用药特点（"五宜五不宜"）

    记住： 中医儿科的核心是"脏腑辨证"—— 小儿病多变在肺、脾、肾三脏，抓住这三脏，就能解决80%的儿科问题。
