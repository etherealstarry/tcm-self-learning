    中医内科学 学习指南¶

    中医内科学是中医临床的核心课程，是中医执业医师考试的重中之重。 这门课学不好，临床就是"瞎开方"。

    为什么这门课特别重要？¶

    中医内科学是桥梁课——前面学的中医基础、诊断、中药、方剂，全都在这门课里综合应用。

    • 学完中医基础 → 知道"什么是阴虚"
    • 学完中医诊断 → 知道"怎么判断阴虚"
    • 学完中药方剂 → 知道"用什么药治阴虚"
    • 学完中医内科学 → 知道"感冒阴虚的人，具体怎么开方"

    这就是临床思维。

    课程结构¶

    中医内科学按病证分类，每个病证的学习路径都是一样的：

    病名 → 概念 → 病因病机 → 辨证分型 → 治法方药 → 调护

    全书大约覆盖 50+ 个常见病证，重点掌握以下大类：

    章节 代表病证 重要程度
    肺系病证 感冒、咳嗽、哮病、喘证 ⭐⭐⭐⭐⭐
    心系病证 心悸、胸痹、不寐 ⭐⭐⭐⭐⭐
    脾胃病证 胃痛、痞满、呕吐、泄泻、便秘 ⭐⭐⭐⭐⭐
    肝胆病证 胁痛、黄疸、积聚 ⭐⭐⭐⭐
    肾系病证 水肿、淋证、癃闭 ⭐⭐⭐⭐
    气血津液病证 郁证、血证、痰饮、消渴 ⭐⭐⭐⭐⭐
    肢体经络病证 痹证、痿证、腰痛 ⭐⭐⭐

    保姆级学习法：以"咳嗽"为例¶

    第一步：搞懂"病"是什么¶

    咳嗽是"肺气上逆作声，咳吐痰液"的病症。

    ??? question "自测：咳嗽和喘有什么区别？" 咳嗽以咳为主，喘以呼吸急促为主。 简单记：咳嗽是"嗓子痒想咳"，喘是"气不够用"。

    第二步：记住分型（考试/临床都考这个）¶

    咳嗽的分型是固定的，每个病证的分型都要背。

    证型 特点 代表方
    风寒袭肺 咳嗽声重，痰白稀薄，怕冷 三拗汤 + 止嗽散
    风热犯肺 咳嗽频剧，痰黄稠，咽痛 桑菊饮
    风燥伤肺 干咳无痰，咽干鼻燥 桑杏汤
    痰湿蕴肺 咳嗽痰多，痰白黏腻，胸闷 二陈汤 + 三子养亲汤
    痰热郁肺 咳嗽气粗，痰黄稠，苔黄腻 清金化痰汤
    肝火犯肺 咳嗽阵作，情绪激动加重，胸胁胀痛 黛蛤散 + 泻白散
    肺阴亏耗 干咳少痰，午后潮热，盗汗 沙参麦冬汤

    第三步：用"生活例子"记住每个分型¶

    • 风寒咳嗽 → 冬天淋雨后咳嗽，痰白稀，怕冷 → 像感冒初期
    • 风热咳嗽 → 感冒后期，嗓子疼，黄痰 → 像"上火"了
    • 痰湿咳嗽 → 胖人，痰多，吃完油腻更咳 → 像"脾虚生痰"
    • 肝火犯肺 → 生气后咳嗽加重 → 像"气的咳嗽"
    • 肺阴亏耗 → 长期干咳，消瘦，下午脸红 → 像"肺结核"的咳嗽

    第四步：辨证"公式化"（考试必背）¶

    考试时，题目会给一段病例描述，你要从中提取信息，判断证型。

    提取公式：

    主症（咳嗽） + 兼症（痰的颜色、伴随症状） + 舌脉 = 证型

    举例：

    病例：患者咳嗽3天，痰黄稠，咽痛，发热，舌尖红，苔薄黄，脉浮数。

    提取信息： - 主症：咳嗽 - 痰：黄稠 → 热 - 伴随：咽痛、发热 → 表证未解 - 舌脉：舌尖红、苔薄黄、脉浮数 → 风热

    结论：风热犯肺证 → 桑菊饮

    ??? question "自测：患者咳嗽，痰白黏腻，胸闷，舌苔白腻，脉滑。这是什么证型？" 答案：痰湿蕴肺证。 关键词：痰白黏腻 + 胸闷 + 舌苔白腻/脉滑 = 痰湿。

    每个病证的"必背清单"¶

    对每个病证，都要整理出以下清单（考试/临床都用得上）：

    1. 概念（名词解释）¶

    咳嗽是指肺气上逆作声、咳吐痰液而言的病证。

    2. 病因（选择题常考）¶

    • 外邪袭肺（风寒、风热、风燥）
    • 脏腑功能失调（脾湿生痰、肝火犯肺、肾虚纳气失常）

    3. 病机（简答题常考）¶

    咳嗽的病机： 肺气上逆，宣降失常。

    分虚实： - 实证：外邪袭肺，肺气被遏 - 虚证：肺脏虚损，肺气上逆

    4. 辨证要点（临床思维）¶

    • 辨外感内伤：外感咳嗽起病急、病程短；内伤咳嗽起病缓、病程长
    • 辨寒热：痰黄稠为热，痰白稀为寒
    • 辨虚实：久病、体弱为虚；新病、体壮为实

    5. 分型 + 代表方（考试核心）¶

    必须背到"条件反射"的程度：

    看到"痰白稀" → 想到"风寒" → 想到"三拗汤" 看到"痰黄稠" → 想到"风热" → 想到"桑菊饮" 看到"干咳少痰" → 想到"阴虚" → 想到"沙参麦冬汤"

    学习进度规划¶

    阶段 内容 时间
    第一阶段 肺系病证（感冒、咳嗽、哮病、喘证） 2周
    第二阶段 心系病证（心悸、胸痹、不寐） 1周
    第三阶段 脾胃病证（胃痛、痞满、呕吐、泄泻、便秘） 2周
    第四阶段 肾系病证 + 气血津液病证 2周
    第五阶段 复习 + 做真题 2周

    常见学习误区¶

    误区1：只背分型，不背"为什么"

    只知道"风寒咳嗽用三拗汤"，但不知道为什么用三拗汤。

    正确做法： 每个方子都要知道"方解"——麻黄宣肺散寒、杏仁降气止咳、甘草调和诸药。

    误区2：病证之间不串联

    咳嗽的"痰湿蕴肺"和胃痛的"痰湿中阻"，病机是一样的——都是脾虚生湿成痰。

    正确做法： 学完一个病证，想想和其他病证的联系。

    误区3：不做病例分析题

    中医内科学的考试，病例分析题占50%以上。

    正确做法： 每学完一个病证，找3-5个病例题练手，训练"提取信息→判断证型→选方"的思维。

    自测习题¶

    ??? question "1. 咳嗽痰黄稠，咽痛，发热，舌尖红，苔薄黄，脉浮数。证型？用方？" 答案： 风热犯肺证，桑菊饮。

    **解析：** 痰黄稠+咽痛+舌尖红+苔薄黄 = 风热；脉浮数 = 表证未解。

    ??? question "2. 咳嗽痰白黏腻，胸闷，舌苔白腻，脉滑。证型？用方？" 答案： 痰湿蕴肺证，二陈汤合三子养亲汤。

    **解析：** 痰白黏腻+胸闷+舌苔白腻/脉滑 = 痰湿。

    ??? question "3. 干咳少痰，午后潮热，盗汗，舌红少苔，脉细数。证型？用方？" 答案： 肺阴亏耗证，沙参麦冬汤。

    **解析：** 干咳+午后潮热+盗汗+舌红少苔/脉细数 = 阴虚。

    ??? question "4. 咳嗽阵作，情绪激动加重，胸胁胀痛，舌红苔薄黄，脉弦数。证型？用方？" 答案： 肝火犯肺证，黛蛤散合泻白散。

    **解析：** 咳嗽+情绪激动加重+胸胁胀痛+脉弦数 = 肝火犯肺。

    下一步¶

    • 按照"保姆级学习法"，逐个病证整理笔记
    • 每学完一个病证，做3-5个病例分析题
    • 制作"分型+代表方"速记卡片
    • 2周后，复习肺系病证（感冒、咳嗽、哮病、喘证）

    记住： 中医内科学不是"背下来"就完了，而是要学会临床思维—— 看到病人，先收集信息（望闻问切），再分析（辨证），最后决策（立法、选方、用药）。 这才是真正的"中医内科学"。
