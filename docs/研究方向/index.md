### 保研（推免）

```
时间线：
  - 大三下学期（3-5 月）：确定目标院校/导师，联系导师
  - 大四上学期（9 月）：各高校发布推免招生简章
  - 9-10 月：参加复试
  - 10 月：推免系统填报、录取
```

### 考研

```
时间线：
  - 大三下学期：确定目标院校，开始复习
  - 大四上学期（12 月）：参加全国硕士研究生统一招生考试
  - 次年 2-3 月：出成绩、复试线公布
  - 3-4 月：参加复试
  - 5-6 月：录取通知书发放
```

## 💻 科研工具与技能（待补充）

### 文献检索

- **CNKI**（中国知网）：中文文献主要来源
- **万方数据库**：学位论文、会议论文
- **维普资讯**：中文期刊全文数据库
- **PubMed**：国际医学文献数据库（英文）
- **Web of Science**：SCI 论文检索

### 数据分析工具

| 工具 | 用途 | 学习资源 |
|------|------|----------|
| SPSS | 统计分析（最常用） | B站有丰富教程 |
| GraphPad Prism | 科研作图 | 官方教程 + B站 |
| R / RStudio | 统计分析与可视化 | 《R语言实战》 |
| Python | 数据分析、机器学习 | （参考你的 Kinesiology 项目） |

### 学术写作

- **中文论文写作**：参照《北京中医药大学学报》投稿指南
- **英文论文写作**：参照 PubMed 上高引中文作者的论文写作风格
- **LaTeX**：学位论文排版（推荐 Overleaf 在线编辑）

## 💡 研究想法从何而来？

:::tip 寻找研究想法的五个途径
1. **从临床中来**：跟诊时遇到的疑难病例，思考其病机、治法、方药
2. **从经典中来**：重读经典，思考古人观点的现代科学解释
3. **从文献中来**：读最新发表的论文，找研究空白（research gap）
4. **从交叉中来**：中医 + 现代科技（AI、大数据、神经科学等）
5. **从争议中来**：学术争议点，往往就是最好的研究切入点
:::
