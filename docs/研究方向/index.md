# 🔬 研究方向

> 中医科研是中医现代化的重要方向。本章介绍**中医常见研究方向**、**科研方法**、**论文写作**、**导师选择**等保姆级指导。

---

## 🔎 中医常见研究方向

### 方向1：中医基础理论现代化研究

**研究内容**：
- 阴阳学说的现代科学解释
- 五行学说的系统论研究
- 藏象学说的分子生物学基础
- 经络实质的现代研究

**适合人群**：对中医理论感兴趣，有一定哲学思维。

**就业方向**：高校任教、科研院所。

---

### 方向2：中医临床研究

**研究内容**：
- 某方/某药治疗某病的随机对照试验（RCT）
- 名老中医经验传承研究
- 中医证候客观化研究
- 中医治疗方案优化研究

**适合人群**：想做临床医生，同时做科研。

**就业方向**：三甲医院中医科、中医院。

---

### 方向3：中药药理研究

**研究内容**：
- 单味中药的药效物质基础
- 中药复方的配伍机理
- 中药药理作用机制（信号通路、靶点）
- 中药新药研发

**适合人群**：对药理、分子生物学感兴趣。

**就业方向**：药企、科研院所、药监局。

---

### 方向4：针灸机理研究

**研究内容**：
- 针灸镇痛的神经机制
- 穴位特异性的fMRI研究
- 针灸治疗某病的随机对照试验
- 针灸参数的优化研究

**适合人群**：对针灸感兴趣，有一定神经科学基础。

**就业方向**：中医院针灸科、科研院所。

---

### 方向5：中医文献研究

**研究内容**：
- 中医古籍整理与校注
- 中医学术流派研究
- 中医名词术语规范化研究
- 中医史学研

**适合人群**：对古籍、文献感兴趣，古文功底好。

**就业方向**：高校、图书馆、古籍出版社。

---

### 方向6：中西医结合研究

**研究内容**：
- 中西医结合治疗某病的临床研究
- 中医证型的现代医学解释
- 中西医结合基础理论研究

**适合人群**：想走"中西医结合"路线。

**就业方向**：三甲医院中西医结合科。

---

## 🎓 如何选择研究方向？（保姆级）

### 第一步：评估自己的兴趣

**问自己三个问题**：
1. 我喜欢**临床**（看病），还是**科研**（做实验）？
2. 我喜欢**中医理论**，还是**现代医学**？
3. 我未来的职业目标是**临床医生**，还是**高校教师/科研人员**？

**根据答案选择**：
- 喜欢临床 + 中医理论 → 中医临床研究
- 喜欢科研 + 现代医学 → 中药药理研究/针灸机理研究
- 喜欢中医理论 + 科研 → 中医基础理论现代化研究
- 喜欢古籍 + 文献 → 中医文献研究

---

### 第二步：评估导师的研究方向

**为什么要看导师方向？**

研究生阶段，**导师的研究方向 = 你的研究方向**。

如果你对"中医临床研究"感兴趣，但导师是做"中药药理"的——那你只能跟着导师做药理，没法做临床。

**怎么看导师方向？**
1. 去学院官网 → 导师介绍 → 看研究方向
2. 去知网 → 搜导师名字 → 看近年发表的论文（就知道导师在做什么）
3. 联系学长学姐 → 问导师的研究方向、课题情况、指导风格

---

### 第三步：评估就业前景

**不同研究方向的就业前景**：

| 研究方向 | 就业前景 | 薪资水平 |
|----------|----------|----------|
| 中医临床研究 | ⭐⭐⭐⭐⭐（最好） | 高 |
| 针灸机理研究 | ⭐⭐⭐⭐ | 中高 |
| 中药药理研究 | ⭐⭐⭐⭐ | 中高 |
| 中医基础理论 | ⭐⭐⭐ | 中 |
| 中医文献研究 | ⭐⭐ | 中低 |
| 中西医结合 | ⭐⭐⭐⭐ | 中高 |

> **❗ 重要提醒**：选研究方向要**兼顾兴趣和就业**。
> 不能只凭兴趣，不考虑就业；也不能只看重就业，不考虑兴趣。

## 📊 科研方法（保姆级）

### 方法1：临床研究（最常用）

**研究设计**：
- **随机对照试验（RCT）**：金标准，但实施难
- **队列研究**：前瞻性，证据等级较高
- **病例对照研究**：回顾性，实施较容易
- **横断面研究**：描述性，适合初步探索

**样本量计算**：
- 用PASS软件计算
- 一般RCT需要**60-120例**（每组30-60例）
- 要考虑到**脱落率**（约10-20%）

**伦理审查**：
- 所有临床研究都要过**伦理委员会**
- 要签**知情同意书**
- 不能违背医学伦理

---

### 方法2：实验研究（药理/针灸机理）

**研究设计**：
- **动物实验**：细胞实验 → 动物实验 → 临床试验（递进）
- **分子生物学实验**：PCR、Western Blot、免疫荧光等
- **网络药理学**：预测中药/方剂的靶点（性价比高）

**实验记录**：
- 用**实验记录本**（手写，不能涂改）
- 记录：日期、实验目的、实验方法、实验结果、实验人员
- 数据要**可溯源**（原始数据不能删改）

---

### 方法3：文献研究（古籍/流派）

**文献检索**：
- **中文数据库**：知网、万方、维普、 SinoMed
- **古籍数据库**：国学大师、瀚堂典藏、CADAL
- **外文数据库**：PubMed、Cochrane Library、Web of Science

**文献管理**：
- 用**Zotero**（免费，好用）
- 用**EndNote**（付费，功能强）
- 用**Mendeley**（免费，界面友好）

---

## 📝 论文写作（保姆级）

### 论文结构（IMRaD格式）

| 部分 | 内容 | 篇幅 |
|------|------|------|
| **I**ntroduction（引言） | 研究背景、研究目的、研究意义 | 1页 |
| **M**ethods（方法） | 研究对象、干预措施、评价指标、统计方法 | 1-2页 |
| **R**esults（结果） | 统计数据、图表 | 2-3页 |
| **D**iscussion（讨论） | 结果解释、与既往研究比较、局限性、结论 | 2-3页 |
| **Abstract**（摘要） | 目的、方法、结果、结论（250字左右） | 半页 |
| **Keywords**（关键词） | 3-5个 | 几行 |

---

### 写作技巧（避坑指南）

**技巧1：先写Methods和Results，再写Introduction和Discussion**
- Methods和Results是"客观描述"，好写
- Introduction和Discussion是"主观论述"，难写
- 先写容易的，建立信心

**技巧2：每天写一点点，不要"憋大招"**
- 每天写**300-500字**（约1小时）
- 不要等到"有时间"再写——你永远不会有"有时间"的那天
- **Deadline**是第一生产力，但要提前1个月完成初稿

**技巧3：多用图表，少用文字**
- 一个图 = 1000字
- 表格可以清晰展示数据
- 但图表**不能重复**（图展示趋势，表展示精确数据）

**技巧4：讨论部分要"谦虚"**
- 不要说"本研究首次发现……"（容易被审稿人打脸）
- 要说"本研究提示……"，"可能与……有关"
- 要讨论**局限性**（样本量小、单中心、未随访等）

---

### 选刊技巧（保姆级）

**第一步：看导师要求**
- 有的导师要求**SCI**（国际期刊）
- 有的导师接受**核心期刊**（国内权威）
- 有的导师接受**普通期刊**（随便发发）

**第二步：看论文质量**
- 研究设计严谨 + 样本量大 + 阳性结果 → 冲**SCI**
- 研究设计一般 + 样本量中等 + 阴性结果 → 投**核心期刊**
- 研究设计简单 + 样本量小 → 投**普通期刊**

**第三步：看期刊偏好**
- 临床研究 → 投**中医杂志**、**中国中西医结合杂志**
- 药理研究 → 投**中国药理学通报**、**药学学报**
- 文献研究 → 投**中华医史杂志**、**中医文献杂志**

> **❗ 重要提醒**：不要一稿多投！
> 同一篇论文，不能同时投给多个期刊——这是学术不端。

## 👨🏫 如何选择导师？（保姆级）

### 导师的"硬指标"

| 指标 | 说明 |
|------|------|
| **职称** | 教授 > 副教授 > 讲师（但不绝对） |
| **课题** | 有国家自然科学基金（NSFC）的导师，经费充足 |
| **论文** | 近年发表SCI论文数量多、影响因子高 |
| **学术兼职** | 担任核心期刊编委、学会常委等 |
| **传承** | 是否是名老中医传承工作室成员 |

---

### 导师的"软指标"（更重要！）

| 指标 | 说明 |
|------|------|
| **指导风格** | 放手型（自己摸索）vs 手把手型（事无巨细） |
| **人品** | 是否侵占学生成果（把学生名字从一作改成自己的） |
| **关系网** | 毕业时能否推荐工作 |
| **实验室氛围** | 师兄师姐是否和睦，是否经常加班 |

**怎么了解"软指标"？**
- 联系**学长学姐**（最靠谱）
- 去**导师实验室**实地考察（看氛围）
- 查**导师历年毕业生的去向**（就业好 = 导师关系网强）

---

### 避坑指南（血泪教训）

**坑1：导师有课题，但没时间指导学生**
- 表现：导师是"空中飞人"，一个月见不到一次
- 后果：学生自己摸索，毕业难
- **怎么避坑**：选导师时，问清楚"指导频率"（每周见面？每月见面？）

**坑2：导师没课题，学生没经费**
- 表现：导师近年没有新课题，实验室设备陈旧
- 后果：实验做不了，论文发不出，毕业难
- **怎么避坑**：选导师时，查"近5年课题"（NSFC官网可查）

**坑3：导师抢占学生成果**
- 表现：学生一作论文，被导师改成导师一作
- 后果：学生毕业没有成果，找工作难
- **怎么避坑**：选导师时，查"导师历年学生的论文署名"（是否正常）
