# 使用指南

欢迎使用**中医自学指南**！本指南按照 **CS自学指南（csdiy.wiki）** 的保姆级标准制作。

## 🎯 首先，确定你的学习目标

在开始之前，请先明确你属于哪一类学习者：

### 类型A：零基础自学中医爱好者
- **目标**：了解中医基础，能给自己和家人做简单辨证，会用常见中成药
- **时间**：每天1-2小时，坚持2-3年
- **路径**：[零基础入门规划](学习规划/零基础入门规划.md)

### 类型B：中医专业学生（本科/研究生）
- **目标**：系统学习，通过执业医师考试，未来从事中医临床
- **时间**：按学校教学安排，配合本指南深化理解
- **路径**：[中医学生规划](学习规划/中医学生规划.md)

### 类型C：在职医务人员（西医转中医/中西医结合）
- **目标**：快速掌握中医临床技能，通过相关考试
- **时间**：每天2-3小时，坚持1-2年
- **路径**：[在职自学规划](学习规划/在职自学规划.md)

### 类型D：备考执业医师/考研
- **目标**：短期冲刺，通过考试
- **时间**：集中3-6个月高强度复习
- **路径**：[执业医师考试备考](index.md) | [考研指南](index.md)

## 🚀 快速开始：第一次使用本网站

### 如果你是**零基础**：
1. 先读 [零基础入门规划](学习规划/零基础入门规划.md) → 明确学习顺序
2. 从 [中医基础学](必修课程/中医基础/中医基础学.md) 开始 → 每天读1-2节
3. 配合 [Anki记忆卡片](学习工具/记忆工具.md) → 背诵中药、方剂
4. 遇到问题 → 查 [常见问题](#常见问题) 或 [学术资源](拓展资源/学术资源导航.md)

### 如果你是**中医专业学生**：
1. 先读 [中医学生规划](学习规划/中医学生规划.md) → 配合学校课程
2. 每学完教材一章 → 来本网站对应页面**深化理解**（看生活例子、临床意义）
3. 每章学完 → 做 [自测题](#自测习题) 检验效果
4. 实习前 → 重点读 [临床跟师指南](拓展资源/临床跟师指南.md) 和 [名老中医医案](拓展资源/名老中医医案.md)

### 如果你是**备考执业医师**：
1. 直接去 [执业医师考试](index.md) 板块
2. 先读 [考试大纲](执业医师考试/考试大纲.md) → 明确范围
3. 按 [备考规划](执业医师考试/备考规划.md) 安排时间
4. 刷 [历年真题](执业医师考试/历年真题.md) → 熟悉题型

## 💡 保姆级学习法：如何最大化利用本网站

### 第一步：学前预习（5分钟）
- 打开要学的章节 → 先看**学习目标**和**重点提示**
- 浏览**知识框架图** → 了解整体结构

### 第二步：正式学习（30-60分钟）
- **读正文** → 重点看**生活例子**（用大白话解释概念）
- **理解临床意义** → 每个知识点都讲"有什么用"
- **做笔记** → 用 [Obsidian](学习工具/笔记工具.md) 整理

### 第三步：学后测试（10-15分钟）
- 做 **自测习题**（每个页面底部都有）→ 检验掌握程度
- 错题 → 记在 [Anki](学习工具/记忆工具.md) 里复习

### 第四步：临床联系（可选）
- 读对应的 [名老中医医案](拓展资源/名老中医医案.md) → 看临床怎么用
- 如果有条件 → 去诊所/医院见习，观察实际病例

## ❓ 常见问题解答

### Q1：学中医一定要背很多东西吗？
**A**：是的，但**理解后的背诵**比死记硬背有效10倍。本网站每个知识点都配了**生活例子**和**记忆口诀**，帮你理解后自然记住。

### Q2：零基础能学会中医吗？
**A**：能！但要有心理准备：中医理论体系独特，初期会有"玄学"感。坚持学完**中医基础学**和**中医诊断学**后，你会突然"开窍"。

### Q3：学中医需要学西医内容吗？
**A**：需要！现代中医必须**中西医并重**。本网站包含 [西医基础](index.md) 板块，就是为了解决这个问题。

### Q4：如何检验学习效果？
**A**：每个页面底部的 [自测习题](必修课程/中医基础/中医基础学.md#自测习题) 就是为你设计的。做对80%以上 → 过关；低于80% → 回头重学。

### Q5：跟师学习重要吗？
**A**：**极其重要**！中医是**经验医学**，很多东西教材里没有，必须跟师。详见 [临床跟师指南](拓展资源/临床跟师指南.md)。
