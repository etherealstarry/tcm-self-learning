## 📖 学习建议

:::tip 经典学习四步法
1. **第一步：读白话翻译**，理解大意，不纠结字词
2. **第二步：对照原文**，逐句精读，标注重点条文
3. **第三步：结合教材**，参考规划教材的释义和按语
4. **第四步：联系临床**，把条文和病案对应起来
:::
