# 中药方剂

中药和方剂是两门紧密相连的课——**中药学教你单味药的功效，方剂学教你如何把多味药组合成方**。

临床上几乎不用单味药，方剂才是治病的"武器"。

## 🎯 学习顺序建议

!!! tip "推荐学习顺序"
    1. **先学中药学** → 搞懂单味药的性味归经
    2. **再学方剂学** → 理解药物如何通过配伍形成"团队作战"
    3. **最后学中成药应用** → 把方剂学知识应用到实际购药用药中
    
    **千万不要跳过中药学直接学方剂学！** 否则你背方歌全是死记硬背，不知道为什么用这些药。
