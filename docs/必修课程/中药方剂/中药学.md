# 中药学

> 这门课不是让你背"薄荷性凉味辛"——而是教你**用药物的偏性，来纠正人体的偏性**。
> 学完这门课，你应该能回答：**为什么生姜能治感冒？为什么大黄能"泻下"？为什么同一味药，生用和制用完全不同？**

---

## 🎯 这门课到底在学什么？

很多人学中药学的方法完全是错的：**拿着《中药学》教材从第一页背到最后一页**，背了半个月，合上书还是不知道什么病用什么药。

先给你一个**宏观框架**，知道你在学什么：

```
中药学 = 理解药物的"性格"，而不是死记硬背

核心问题1：这味药有什么"偏性"？（四气五味、升降浮沉、归经）
核心问题2：这味药能治什么病？（功效与主治）
核心问题3：这些药怎么搭配？（配伍禁忌、组方原则）
核心问题4：这味药怎么用才安全？（用量、煎法、禁忌）

学每一味药时，都要问自己：
它的"性格"是什么？→ 它能纠正人体什么"偏性"？
```

**这门课和中医基础学的关系**：
- 中医基础学教你**人体怎么生病**（病机）
- 中药学教你**药物怎么治病**（药性）
- 两门课合起来，你才能"辨证用药"

---

## 📖 保姆级学习路线

!!! tip "学习顺序（非常重要）"
    不要按教材章节死磕！建议按这个顺序：

    **第一阶段（建立直觉）**
    1. 先学「中药的起源和炮制」→ 理解"药为什么要炮制"
    2. 再学「四气五味」→ 这是中药学的"底层逻辑"，必须搞透
    
    **第二阶段（掌握理论）**
    3. 学「升降浮沉 + 归经」→ 理解药物在人体里"怎么走"
    4. 学「配伍禁忌」→ 十八反、十九畏必须背熟
    
    **第三阶段（按功效分类学药）**
    5. 从「解表药」开始，一类一类学
    6. 每类药先学"共性"，再学"个性"（每味药的独特之处）
    
    **第四阶段（纵向串联）**
    7. 把"功效相似"的药放在一起对比（比如麻黄 vs 桂枝）
    8. 学「用药禁忌」和「用量」→ 这是临床安全的关键

## 🌡️ 第一部分：四气五味（中药学的底层逻辑）

### 什么是"四气"？

**四气 = 药物的寒、热、温、凉四种性质**

> 生活例子🌰：
> - 你冬天手冻僵了，妈妈让你喝**生姜红糖水**——生姜是"温性"，能驱寒
> - 你夏天中暑了，中医让你喝**绿豆汤**——绿豆是"凉性"，能清热
> - 你吃火锅上火了，牙龈肿痛——这是"热证"，要用"寒凉药"来治
> - 你平时手脚冰凉、怕冷——这是"寒证"，要用"温热药"来治

**临床意义**：
- 寒凉药 → 治热证（发热、口渴、咽喉肿痛、舌红苔黄）
- 温热药 → 治寒证（怕冷、手脚冰凉、腹痛喜暖、舌淡苔白）

!!! danger "⚠️ 自学者最容易犯的错误"
    **"我上火了，赶紧喝菊花茶！"**  
    错！你得先搞清楚是"实火"还是"虚火"：
    - 实火（真的有热）：菊花茶、金银花、黄连——可以用
    - 虚火（阴虚火旺）：你需要的不是"清热"，而是"滋阴"（比如麦冬、石斛）
    
    用反了，寒凉药会伤你的阳气，越喝越虚！

??? question "📝 自测习题（做完再对答案）"
    1. 患者发热、口渴、咽喉肿痛、舌红苔黄——应该用什么性质的药物？
    2. 患者平时手脚冰凉、怕冷、腹痛喜暖——应该用什么性质的药物？
    3. 为什么阳虚的人不能长期喝菊花茶？
    
    ??? success "答案"
        1. 寒凉药（清热药）
        2. 温热药（温里药）
        3. 菊花是凉性的，长期喝会损伤阳气，加重阳虚症状

### 什么是"五味"？

**五味 = 辛、甘、酸、苦、咸五种味道，每种味道对应不同的作用**

> 生活例子🌰：
> - **辛味**（辛辣）：辣椒、生姜、葱白 → 能"发散"，能"行气" → 所以感冒初期用生姜发汗
> - **甘味**（甜味）：甘草、大枣、蜂蜜 → 能"补益"，能"缓急" → 所以身体虚了用甘草、大枣补气
> - **酸味**（酸涩）：乌梅、五味子 → 能"收敛"，能"固涩" → 所以出汗太多、拉肚子用乌梅敛汗止泻
> - **苦味**（苦寒）：黄连、黄芩 → 能"泄降"，能"燥湿" → 所以上火了用黄连清热
> - **咸味**（咸寒）：海藻、昆布 → 能"软坚"，能"散结" → 所以甲状腺结节用海藻、昆布软化结节

**临床意义**：五味不是"味道好不好的问题"，而是**药物的作用方向**！

| 五味 | 作用方向 | 代表药物 | 能治什么问题 |
|------|---------|---------|------------|
| 辛 | 发散、行气、活血 | 麻黄、桂枝、生姜 | 感冒、气滞、血瘀 |
| 甘 | 补益、缓急、和中 | 甘草、大枣、人参 | 气虚、腹痛、调和药性 |
| 酸 | 收敛、固涩 | 乌梅、五味子、山茱萸 | 自汗、盗汗、久泻 |
| 苦 | 泄降、燥湿、坚阴 | 黄连、黄芩、黄柏 | 火热证、湿热证 |
| 咸 | 软坚、散结、泻下 | 海藻、芒硝、牡蛎 | 瘰疬、便秘、肿块 |

!!! tip "记忆口诀"
    辛散酸收甘补缓，苦燥咸软寒能清。  
    （辛味能散，酸味能收，甘味能补能缓，苦味能燥湿，咸味能软坚散结）

??? question "📝 自测习题"
    1. 为什么感冒初期要用"辛味"药（比如生姜、麻黄）？
    2. 为什么出汗太多的人要用"酸味"药（比如五味子）？
    3. 甘草为什么叫"国老"？（提示：想想甘味的作用）
    
    ??? success "答案"
        1. 辛味能"发散"，能把体内的风寒发散出来，所以感冒初期用辛味药发汗解表
        2. 酸味能"收敛固涩"，能把过度外散的津液收住，所以治自汗、盗汗
        3. 甘草味甘，能"调和诸药"——就像古代的"国老"（宰相），能协调各方关系，所以很多方子里都有甘草

## 📈 第二部分：升降浮沉 + 归经

### 升降浮沉：药物在人体里的"方向"

**升降浮沉 = 药物作用于人体的四种方向趋势**

> 生活例子🌰：
> - **升浮药**（向上向外）：柴胡、升麻 → 能把"下陷"的东西提上来 → 所以脱肛、子宫脱垂用升麻
> - **沉降药**（向下向内）：大黄、石决明 → 能把"上逆"的东西降下来 → 所以头痛、目赤肿痛用石决明（潜阳）
> - **浮药**（向外）：桂枝、生姜 → 能发汗解表
> - **沉药**（向内）：龙骨、牡蛎 → 能重镇安神

**临床意义**：
- 病位在表（感冒）→ 用"浮"药（发汗解表）
- 病位在里（便秘）→ 用"沉"药（泻下通便）
- 病势上逆（呕吐、咳喘）→ 用"降"药（降逆止呕）
- 病势下陷（脱肛、久泻）→ 用"升"药（升阳举陷）

!!! danger "⚠️ 重要提醒"
    药性有"升降浮沉"，人体病势也有"升降浮沉"——**用药就是用药物的趋势，来纠正人体的病势**！
    
    比如：
    - 胃气上逆（呕吐）→ 用"降逆"药（半夏、生姜）
    - 中气下陷（脱肛）→ 用"升提"药（黄芪、升麻、柴胡）

---

### 归经：药物"归"到哪条经络、哪个脏腑

**归经 = 药物对某个脏腑、某条经络有特殊的选择性作用**

> 生活例子🌰：
> - 麻黄、杏仁都能治咳嗽，但：
>   - 麻黄归**肺经** → 主要治"风寒束肺"的咳嗽（怕冷、无汗）
>   - 杏仁也归**肺经**，但还能**润肠通便** → 所以归大肠经
> - 同样是"清热药"：
>   - 黄连归**心、胃、大肠经** → 主要清心火、胃火
>   - 黄芩归**肺、胆、大肠经** → 主要清肺火
>   - 黄柏归**肾、膀胱经** → 主要清下焦湿热

**临床意义**：归经告诉你，**同样的功效，作用部位不同**！

| 药物 | 归经 | 主治重点 |
|------|------|---------|
| 麻黄 | 肺、膀胱经 | 风寒感冒、喘咳 |
| 桂枝 | 心、肺、膀胱经 | 风寒感冒、寒凝血滞 |
| 柴胡 | 肝、胆经 | 少阳证（寒热往来）、肝郁气滞 |
| 石膏 | 肺、胃经 | 气分实热（高热、口渴） |

!!! tip "记忆方法"
    归经不用死背——**看这味药主治什么病，就能反推它归什么经**！
    
    比如：  
    - 柴胡主治"少阳证"（寒热往来）→ 归肝胆经  
    - 菊花主治"目赤肿痛"→ 归肝经（肝开窍于目）  
    - 丹参主治"月经不调"→ 归心、肝经（心主血、肝藏血）

## 💊 第三部分：按功效分类学药（核心内容）

!!! warning "学习方法提醒"
    这一部分**不要一味死背**！每类药先学"共性"，再学"个性"。  
    **共性是这一类药的共同特点，个性是每味药的独特之处**。  
    学每味药时，都要问：**它和同类药相比，独特之处在哪里？**

---

### 第一章：解表药（治感冒的药）

**共性**：都能"发散表邪"，治感冒初期（恶寒发热、头痛身痛）

#### 辛温解表药（治风寒感冒）

| 药物 | 独特功效 | 生活例子/临床意义 |
|------|---------|------------------|
| 麻黄 | 发汗、平喘、利水 | 感冒怕冷+喘咳→用麻黄；水肿初起→也能用麻黄利水 |
| 桂枝 | 发汗解肌、温通经脉 | 感冒怕冷+四肢冰冷→用桂枝；痛经（寒凝血滞）→也能用桂枝 |
| 生姜 | 发汗解表、温中止呕 | 感冒初期、恶心呕吐→生姜红糖水；晕车→含片生姜 |
| 防风 | 祛风解表、胜湿止痛 | "风药中之润剂"→不燥烈，适合表虚感冒 |

**麻黄 vs 桂枝 对比**（考试常考！）：

| 对比点 | 麻黄 | 桂枝 |
|-------|------|------|
| 发汗力度 | 强（峻汗） | 温和（解肌） |
| 主治 | 风寒表实（无汗） | 风寒表虚（有汗） |
| 额外功效 | 平喘、利水 | 温通经脉、助阳化气 |

> 生活例子🌰：
> - 你感冒了，**怕冷、发抖、一点汗都没有** → 用麻黄汤（麻黄+桂枝+杏仁+甘草）
> - 你感冒了，**有点怕冷、微微有汗、怕风** → 用桂枝汤（桂枝+白芍+生姜+大枣+甘草）

??? question "📝 自测习题"
    1. 风寒感冒"无汗"和"有汗"，用药有什么区别？
    2. 为什么麻黄能治"水肿"？（提示：想想肺的生理功能）
    3. 桂枝为什么能治"痛经"？
    
    ??? success "答案"
        1. 无汗→用麻黄（峻汗）；有汗→用桂枝（解肌，温和发汗）
        2. 肺主皮毛，麻黄归肺经，能开宣肺气、"提壶揭盖"，所以能利水消肿（宣肺利水）
        3. 桂枝能"温通经脉"，痛经很多是因为"寒凝血滞"，桂枝的温性可以散寒通络、止痛

---

#### 辛凉解表药（治风热感冒）

| 药物 | 独特功效 | 生活例子/临床意义 |
|------|---------|------------------|
| 薄荷 | 疏散风热、清利头目 | 感冒发热+头痛目赤→薄荷茶；咽痛→薄荷利咽 |
| 菊花 | 疏散风热、平肝明目 | 风热感冒+眼睛干涩→菊花茶；高血压头晕→菊花平肝 |
| 桑叶 | 疏散风热、清肺润燥 | 秋燥感冒（干咳少痰）→桑叶；肝热目赤→桑叶 |
| 葛根 | 解肌退热、透疹、升阳 | 感冒发热+项背强痛→葛根；麻疹不透→葛根透疹 |

> 生活例子🌰：
> - 你感冒了，**发热重、怕冷轻、喉咙痛、舌红** → 这是风热感冒 → 用银翘散（金银花+连翘+薄荷+牛蒡子...）
> - 你长期对着电脑，**眼睛干涩、头晕** → 这是"肝阳上亢" → 用菊花茶平肝明目

### 第二章：清热药（治"上火"的药）

**共性**：都能"清热泻火"，治各种"热证"

!!! warning "⚠️ 重要提醒"
    清热药分很多类，**不同类的清热药，作用部位完全不同**！  
    用错了，不但治不好病，还会伤胃！

| 分类 | 作用部位 | 代表药物 | 主治 |
|------|---------|---------|------|
| 清热泻火药 | 气分实热（全身高热） | 石膏、知母 | 高热、口渴、汗出 |
| 清热燥湿药 | 湿热证 | 黄连、黄芩、黄柏 | 湿热泄泻、黄疸 |
| 清热解毒药 | 热毒证（疮疡肿毒） | 金银花、连翘、板蓝根 | 痈肿疮毒、咽喉肿痛 |
| 清热凉血药 | 血分实热（出血、发斑） | 生地、丹皮、赤芍 | 吐血、衄血、斑疹 |
| 清虚热药 | 阴虚发热（午后潮热） | 青蒿、地骨皮 | 骨蒸潮热、盗汗 |

**黄连 vs 黄芩 vs 黄柏**（三黄，考试常考！）：

| 药物 | 归经 | 主治重点 |
|------|------|---------|
| 黄连 | 心、胃、大肠 | 清心火（心烦不寐）、胃火（呕吐）、大肠湿热（痢疾） |
| 黄芩 | 肺、胆、大肠 | 清肺火（咳嗽痰黄）、少阳证（寒热往来） |
| 黄柏 | 肾、膀胱 | 清下焦湿热（带下、淋证）、退虚热 |

> 生活例子🌰：
> - 你上火了，**心烦、失眠、口舌生疮** → 这是"心火" → 用黄连
> - 你感冒了，**咳嗽、黄痰、咽喉痛** → 这是"肺热" → 用黄芩
> - 你小便黄赤、尿道灼痛 → 这是"下焦湿热" → 用黄柏

??? question "📝 自测习题"
    1. "三黄"分别清哪个脏腑的热？
    2. 为什么阴虚发热（午后潮热）不能用石膏、黄连这些"清热泻火药"？
    3. 金银花和连翘为什么叫"疮家圣药"？
    
    ??? success "答案"
        1. 黄连清心胃火，黄芩清肺胆火，黄柏清下焦湿热
        2. 阴虚发热是"虚热"，不是"实热"——阴虚需要"滋阴"，用寒凉药会伤阳气；应该用青蒿、地骨皮这些"清虚热药"
        3. 金银花和连翘都能"清热解毒"，既能散上焦风热，又能解血分热毒，所以对于痈肿疮毒效果很好，故有此称

### 第三章：泻下药（治便秘的药）

**共性**：能引起腹泻或润滑肠道，促进排便

| 分类 | 作用特点 | 代表药物 | 注意 |
|------|---------|---------|------|
| 攻下药 | 泻下力强，用于实热便秘 | 大黄、芒硝 | 孕妇禁用！ |
| 润下药 | 润肠通便，作用温和 | 火麻仁、郁李仁 | 适合老人、虚人便秘 |
| 峻下逐水药 | 泻下力极强，能逐水饮 | 甘遂、大戟、芫花 | 毒性大，慎用！ |

**大黄**（中药里的"将军"）：

> 生活例子🌰：
> - 你便秘好几天了，肚子胀、口臭、舌红苔黄厚 → 这是"实热便秘" → 用大黄（大黄能泻下攻积、清热泻火）
> - 你不小心扭到了，局部红肿热痛 → 大黄还能"活血祛瘀" → 内服或外敷都可以
> 
> **重要**：大黄的用法——  
> - 想要"泻下"→ 后下（煮的时间短）  
> - 想要"清热泻火"→ 同煎（煮的时间长）

??? question "📝 自测习题"
    1. 老人便秘为什么不能用大黄，而要用火麻仁？
    2. 大黄"后下"和"同煎"有什么区别？
    
    ??? success "答案"
        1. 老人便秘多是"虚秘"（气虚或血虚），大黄是"攻下药"，泻下力太强，会损伤正气；火麻仁是"润下药"，能润肠通便，不伤正气
        2. 后下→大黄蒽醌类成分溶出多，泻下力强；同煎→蒽醌类被破坏，泻下力减弱，但清热泻火作用保留

## ⚠️ 第四部分：配伍禁忌（必须背熟！）

### 十八反

**"十八反" = 18对不能一起用的药**

> 歌诀（必须背熟！）：
> 
> **本草明言十八反，半蒌贝蔹及攻乌**  
> （半夏、瓜蒌、贝母、白蔹、白及 → 不能和乌头类一起用）
> 
> **藻戟遂芫俱战草**  
> （海藻、大戟、甘遂、芫花 → 不能和甘草一起用）
> 
> **诸参辛芍叛藜芦**  
> （人参、丹参、玄参、沙参、苦参、细辛、芍药 → 不能和藜芦一起用）

**临床意义**：违反十八反，可能导致中毒或严重不良反应！

### 十九畏

**"十九畏" = 19对不能一起用的药（和十八反不同！）**

> 歌诀：
> 
> **硫黄原是火中精，朴硝一见便相争**  
> **水银莫与砒霜见，狼毒最怕密陀僧**  
> **巴豆性烈最为上，偏与牵牛不顺情**  
> **丁香莫与郁金见，牙硝难合荆三棱**  
> **川乌草乌不顺犀，人参最怕五灵脂**  
> **官桂善能调冷气，若逢石脂便相欺**

!!! danger "⚠️ 重要提醒"
    **十八反和十九畏是两条不同的禁忌规则**，都要背熟！  
    考试必考，临床用药安全也靠这个！

## 📚 第五部分：学习方法总结

### 如何高效学中药学？

!!! tip "推荐学习步骤"
    1. **先理解"四气五味、升降浮沉、归经"** → 这是底层逻辑，必须搞透
    2. **按功效分类学药** → 一类一类来，不要乱
    3. **每类药先学"共性"，再学"个性"** → 对比记忆，效率更高
    4. **把相似功效的药放在一起对比** → 比如麻黄 vs 桂枝，黄连 vs 黄芩 vs 黄柏
    5. **结合方剂学一起学** → 单味药的功效，在方子里才能体现真实用途
    6. **背十八反、十九畏** → 每天背一遍，直到烂熟于心

### 常见学习误区

| 误区 | 为什么错 | 正确做法 |
|------|---------|---------|
| 一味死背"性味归经" | 背了不理解，很快就忘 | 先理解"为什么"，再背"是什么" |
| 不学炮制，直接学药性 | 炮制改变药性，不学炮制学不懂药性 | 先学"炮制目的"，再学单味药 |
| 只学单味药，不学配伍 | 临床上几乎不用单味药 | 学完单味药，马上学方剂学 |
| 不背十八反、十九畏 | 这是临床安全的底线 | 每天背一遍，直到烂熟 |

## 📝 自测习题

??? question "1. 黄芩、黄连、黄柏都能清热燥湿，如何区分使用？"
    **答案：** 三黄各有侧重——
    - **黄芩**：善清**上焦肺热**，主治肺热咳嗽、少阳证（寒热往来）
    - **黄连**：善清**中焦胃热**，主治胃热呕吐、心烦不寐
    - **黄柏**：善清**下焦湿热**，主治带下黄稠、淋证、脚气
    
    **记忆口诀：** 黄芩治肺，黄连治心胃，黄柏治下焦。

??? question "2. 人参、党参、黄芪都能补气，如何区分？"
    **答案：**
    - **人参**：大补元气，救脱要药，适用于元气虚脱（大汗淋漓、脉微欲绝）
    - **党参**：补中益气，作用温和，适用于日常气虚（乏力、食欲不振）
    - **黄芪**：补气升阳、固表止汗、利水消肿，适用于表虚自汗、水肿、脱肛
    
    **生活例子：** 大病后用人参，日常乏力用党参，容易感冒出汗用黄芪。

??? question "3. 麻黄和桂枝都能发汗解表，有什么区别？"
    **答案：**
    - **麻黄**：发汗力强，兼能**宣肺平喘、利水消肿**，适用于恶寒重发热轻的无汗表证，以及咳喘、水肿
    - **桂枝**：发汗力缓，兼能**温通经脉、助阳化气**，适用于有汗表证（中风），以及寒凝血滞疼痛、痰饮蓄水
    
    **临床意义：** 麻黄汤用麻黄无桂枝，桂枝汤用桂枝无麻黄——一个有汗，一个无汗，不能弄混！

??? question "4. 附子、肉桂、干姜都是温里药，如何区分？"
    **答案：**
    - **附子**：回阳救逆第一品，主治**亡阳证**（四肢厥冷、脉微欲绝）、肾阳虚（畏寒肢冷、阳痿）
    - **肉桂**：补火助阳、引火归元，主治**命门火衰**（畏寒肢冷、腰膝酸软）、虚阳上浮（面红虚热）
    - **干姜**：温中散寒、回阳通脉，主治**脾胃虚寒**（腹痛吐泻）、亡阳证辅助用药
    
    **记忆：** 附子救逆，肉桂助阳，干姜温中。

??? question "5. 柴胡和升麻都能升举阳气，有什么区别？"
    **答案：**
    - **柴胡**：疏肝解郁、和解退热，主治**少阳证**（寒热往来）、肝郁气滞（胸胁胀痛、月经不调）、气虚下陷（脱肛、子宫脱垂）
    - **升麻**：发表透疹、清热解毒、升举阳气，主治**麻疹不透**、咽喉肿痛、气虚下陷
    
    **配伍：** 补中益气汤用柴胡+升麻，二者同用，升提之力更强。

??? question "6. 中药材的'道地性'是什么意思？举例说明。"
    **答案：** 道地性是指**特定产地的药材，质量最优、疗效最好**。
    
    **例子：**
    - 当归：甘肃岷县（岷当归）最优
    - 黄连：四川（川连）最优
    - 附子：四川江油（川附子）最优
    - 地黄：河南怀庆（怀地黄）最优
    - 枸杞：宁夏中宁（宁夏枸杞）最优
    
    **临床意义：** 开处方时注明道地药材（如"川连"而非"黄连"），疗效更佳。

??? question "7. 十八反、十九畏的具体内容是什么？为什么必须背下来？"
    **答案：**
    
    **十八反：**
    - 乌头反半夏、瓜蒌、贝母、白蔹、白及
    - 甘草反海藻、大戟、甘遂、芫花
    - 藜芦反人参、丹参、玄参、沙参、苦参、细辛、芍药
    
    **十九畏：**
    - 硫黄畏朴硝，水银畏砒霜，狼毒畏密陀僧
    - 巴豆畏牵牛，丁香畏郁金，牙硝畏三棱
    - 川乌/草乌畏犀角，人参畏五灵脂，官桂畏赤石脂
    
    **为什么必须背：** 这是临床安全的底线。违反可能导致中毒、甚至死亡。执业医师考试必考，临床上万一开错方，是医疗事故。

??? question "8. 生姜、干姜、炮姜有什么区别？"
    **答案：**
    - **生姜**：辛温，发汗解表、温中止呕（止呕圣药），适用于风寒感冒、胃寒呕吐
    - **干姜**：辛热，温中散寒、回阳通脉，适用于脾胃虚寒、亡阳证
    - **炮姜**：苦温，温经止血、温中止痛，适用于虚寒性出血（便血、崩漏）
    
    **记忆：** 生姜发汗止呕，干姜温中回阳，炮姜温经止血。
