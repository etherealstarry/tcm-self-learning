## 📖 学习建议

:::tip 针灸推拿学习要点
1. **经络腧穴学**：对着人体模型或自己身体找穴位，反复摸认
2. **针灸治疗学**：重点掌握常见病的主穴、配穴规律
3. **推拿学**：手法要练！每天练 15 分钟基本手法（按、揉、推、拿）
4. **多临床**：针灸是手艺活，针感、手感只能在实践中获得
:::
