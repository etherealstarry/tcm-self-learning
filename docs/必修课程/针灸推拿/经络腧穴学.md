# 经络腧穴学 学习指南

> 经络腧穴学是针灸推拿的**基础课**——不知道经络走向和腧穴定位，后面的针灸治疗学和推拿学都学不好。
> 这门课的特点是**"要背的要死"**——400+ 个穴位，每个都要知道位置和主治。

---

## 为什么这门课特别重要？

- **执业医师考试**占分约5-8%
- **针灸治疗学和推拿学的基础**——不知道穴位在哪，怎么扎？怎么推？
- **临床必备**——每个针灸科医生都要"倒背如流"十四经脉和常用穴位

---

## 核心理论：经络系统

### 经络的组成（必背）

```
经络系统
├── 经脉
│   ├── 正经（十二经脉）
│   │   ├── 手三阴经（肺、心包、心）
│   │   ├── 手三阳经（大肠、三焦、小肠）
│   │   ├── 足三阳经（胃、胆、膀胱）
│   │   └── 足三阴经（脾、肝、肾）
│   ├── 奇经八脉（督脉、任脉、冲脉、带脉等）
│   └── 经别、经筋、皮部
└── 络脉
    ├── 别络（15条）
    ├── 浮络
    └── 孙络
```

!!! tip "十二经脉的走向规律（必背）"
    - **手三阴经**：从胸走手（胸 → 手）
    - **手三阳经**：从手走头（手 → 头）
    - **足三阳经**：从头走足（头 → 足）
    - **足三阴经**：从足走胸（足 → 胸）

!!! tip "十二经脉的流注顺序（必背）"
    ```
    肺经 → 大肠经 → 胃经 → 脾经 → 心经 → 小肠经
    ↓                                        ↑
    肝经 ← 胆经 ← 膀胱经 ← 肾经 ← 心包经 ← 三焦经
    ```

## 重点经脉详解

### 1. 手太阴肺经（LU）

**走向：** 胸 → 手（从中焦到拇指端）

**主治：** 肺病（咳嗽、气喘、胸痛）、咽喉病、经脉循行部位病

**常用穴位：**

| 穴位 | 定位 | 主治 | 操作 |
|------|------|------|------|
| **中府** | 胸前壁外上方，前正中线旁开6寸 | 咳嗽、气喘、胸痛 | 向外斜刺0.5-0.8寸 |
| **尺泽** | 肘横纹中，肱二头肌腱桡侧凹陷处 | 咳嗽、气喘、咯血、胸满 | 直刺0.8-1.2寸 |
| **列缺** | 桡骨茎突上方，腕横纹上1.5寸 | 头痛、项强、咳嗽、气喘 | 向上斜刺0.3-0.5寸 |
| **太渊** | 腕掌侧横纹桡侧，桡动脉搏动处 | 咳嗽、气喘、无脉症 | 避开动脉，直刺0.3-0.5寸 |
| **鱼际** | 第一掌骨中点桡侧，赤白肉际处 | 咳嗽、咯血、咽喉肿痛 | 直刺0.5-0.8寸 |
| **少商** | 拇指桡侧指甲角旁约0.1寸 | 咽喉肿痛、鼻衄、发热 | 浅刺0.1寸，或三棱针点刺出血 |

??? question "自测：患者咳嗽，咽喉肿痛，头痛，项强。选哪条经的穴位？首选哪个穴位？"
    **答案：** 手太阴肺经，首选列缺。
    
    **解析：** 咳嗽 + 咽喉肿痛 = 肺病 → 手太阴肺经；头痛、项强 = 列缺的主治（头项寻列缺）。

---

### 2. 手阳明大肠经（LI）

**走向：** 手 → 头（从食指端到鼻翼旁）

**主治：** 头面五官病（头痛、牙痛、咽喉肿痛）、肠病（便秘、腹泻）

**常用穴位：**

| 穴位 | 定位 | 主治 | 操作 |
|------|------|------|------|
| **合谷** | 手背，第1、2掌骨间，第2掌骨桡侧中点 | 头痛、牙痛、面瘫、腹痛、便秘 | 直刺0.5-1寸 |
| **曲池** | 肘横纹外侧端，屈肘时肘横纹桡侧端凹陷处 | 热病、高血压、皮肤病、腹痛 | 直刺1-1.5寸 |
| **肩髃** | 三角肌上部，臂外展时肩峰前下方凹陷处 | 肩周炎、上肢瘫痪 | 直刺1-1.5寸 |
| **迎香** | 鼻翼外缘中点旁，鼻唇沟中 | 鼻塞、鼻衄、面瘫 | 向内上方斜刺0.3-0.5寸 |

!!! tip "四总穴歌（必背）"
    ```
    肚腹三里留，腰背委中求，
    头项寻列缺，面口合谷收。
    ```
    
    **解释：**
    - 肚腹病 → 找足三里（胃经）
    - 腰背痛 → 找委中（膀胱经）
    - 头项病 → 找列缺（肺经）
    - 面口病 → 找合谷（大肠经）

---

### 3. 足阳明胃经（ST）

**走向：** 头 → 足（从鼻翼旁到第二趾端）

**主治：** 胃肠病（胃痛、呕吐、腹胀、腹泻）、头面病（头痛、牙痛、面瘫）

**常用穴位：**

| 穴位 | 定位 | 主治 | 操作 |
|------|------|------|------|
| **地仓** | 口角旁约0.4寸 | 面瘫、流涎 | 向颊车方向斜刺0.5-1寸 |
| **颊车** | 下颌角前上方一横指，咬肌中 | 面瘫、牙痛、腮腺炎 | 直刺0.3-0.5寸 |
| **下关** | 颧弓下缘中央与下颌切迹之间凹陷处 | 牙痛、面瘫、耳鸣 | 直刺0.5-1寸 |
| **天枢** | 脐中旁开2寸 | 泄泻、痢疾、便秘、痛经 | 直刺1-1.5寸 |
| **足三里** | 犊鼻穴下3寸，胫骨前嵴外一横指 | 胃痛、呕吐、腹胀、腹泻、便秘、失眠 | 直刺1-2寸 |
| **丰隆** | 外踝尖上8寸，胫骨前嵴外二横指 | 痰多、头痛、眩晕、癫狂 | 直刺1-1.5寸 |

---

### 4. 足太阴脾经（SP）

**走向：** 足 → 胸（从拇趾端到腋下）

**主治：** 脾胃病（腹胀、腹泻、便秘）、妇科病（月经不调、带下）

**常用穴位：**

| 穴位 | 定位 | 主治 | 操作 |
|------|------|------|------|
| **隐白** | 拇趾内侧趾甲角旁约0.1寸 | 崩漏、腹胀、便血 | 浅刺0.1寸 |
| **三阴交** | 内踝尖上3寸，胫骨内侧缘后方 | 月经不调、带下、遗精、失眠、腹胀 | 直刺1-1.5寸 |
| **阴陵泉** | 胫骨内侧髁后下方凹陷处 | 水肿、小便不利、腹胀、泄泻 | 直刺1-2寸 |
| **血海** | 髌底内侧端上2寸，股四头肌内侧头的隆起处 | 月经不调、丹毒、湿疹、瘙痒 | 直刺1-1.5寸 |

!!! tip "三阴交——妇科要穴"
    三阴交是**足三阴经（脾、肝、肾）的交会穴**，所以能调理三经的病。
    
    **主治：** 脾胃病（脾经）、妇科病（肝经、肾经）、泌尿生殖病（肾经）。
    
    **记忆：** 妇科病第一穴 = 三阴交。

## 穴位定位方法（必背）

### 1. 骨度分寸法（最常用）

| 部位 | 起止点 | 骨度分寸 |
|------|--------|---------|
| 头部 | 前发际 → 后发际 | 12寸 |
| 胸腹部 | 胸骨上窝 → 胸剑联合 | 9寸 |
| 胸腹部 | 胸剑联合 → 脐中 | 8寸 |
| 胸腹部 | 脐中 → 耻骨联合上缘 | 5寸 |
| 上肢 | 腋前纹头 → 肘横纹 | 9寸 |
| 上肢 | 肘横纹 → 腕横纹 | 12寸 |
| 下肢 | 耻骨联合上缘 → 股骨内上髁 | 18寸 |
| 下肢 | 胫骨内侧髁 → 内踝尖 | 13寸 |
| 下肢 | 股骨大转子 → 膝中 | 19寸 |
| 下肢 | 膝中 → 外踝尖 | 16寸 |

### 2. 体表标志法

利用身体的固定标志（如五官、乳头、肚脐、骨关节）来定位穴位。

**举例：**
- 肚脐 → 神阙穴
- 乳头 → 第四肋间隙（男性）
- 肩胛骨下角 → 第七胸椎棘突

### 3. 手指同身寸法

| 方法 | 规定 | 适用 |
|------|------|------|
| **拇指同身寸** | 拇指指间关节宽为1寸 | 全身各部 |
| **中指同身寸** | 中指中节屈曲时内侧两端纹头之间为1寸 | 四肢部 |
| **横指同身寸（一夫法）** | 食指、中指、无名指、小指四指并拢，中节横纹宽为3寸 | 四肢部、腹部 |

## 常见学习误区

!!! warning "误区1：只背穴位名字，不练定位"
    知道"足三里"在哪，但找不到——这是**无效学习**。
    
    **正确做法：** 每个穴位都要在**自己身上找**，摸到骨性标志，再定位穴位。

!!! warning "误区2：不背骨度分寸"
    骨度分寸是穴位定位的**基础**，不背骨度分寸，穴位定位就不准。
    
    **正确做法：** 先把"骨度分寸表"背熟，再学穴位定位。

!!! warning "误区3：忽略穴位的主治"
    穴位的主治是**考试和临床的核心**，不能只背定位、不背主治。
    
    **正确做法：** 每个穴位都要掌握"定位 + 主治 + 操作"，三者缺一不可。

## 自测习题

??? question "1. 患者头痛，项强，咳嗽，咽喉肿痛。首选哪个穴位？属于哪条经？"
    **答案：** 列缺，手太阴肺经。
    
    **解析：** 头项病 → 列缺（四总穴歌："头项寻列缺"）；咳嗽、咽喉肿痛 → 肺病 → 手太阴肺经。

??? question "2. 患者面瘫，鼻衄。首选哪个穴位？属于哪条经？"
    **答案：** 合谷，手阳明大肠经。
    
    **解析：** 面口病 → 合谷（四总穴歌："面口合谷收"）；鼻衄 → 大肠经"挟鼻孔"。

??? question "3. 患者月经不调，带下，失眠，腹胀。首选哪个穴位？为什么？"
    **答案：** 三阴交。
    
    **解析：** 三阴交是足三阴经（脾、肝、肾）的交会穴，所以能同时调理脾胃（腹胀）、妇科（月经不调、带下）、安神（失眠）。

??? question "4. 患者胃痛，呕吐，腹胀，腹泻。首选哪个穴位？属于哪条经？"
    **答案：** 足三里，足阳明胃经。
    
    **解析：** 肚腹病 → 足三里（四总穴歌："肚腹三里留"）；足三里是胃的下合穴，主治胃肠病。
