## 📖 学习建议

:::tip 内科学习要点
1. **以证为本**：每个病都要掌握常见证型、治法、代表方
2. **病证结合**：先辨病，再辨证，不可偏废
3. **多跟诊**：theory is gray, life is green——临床经验不可替代
4. **建立病案库**：把遇到的典型病例记录下来，定期复习
:::
