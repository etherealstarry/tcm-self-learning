# 中医外科学 学习指南

> 中医外科学主要研究**体表疾病**和**外科感染**，包括疮疡、皮肤病、肛肠病、乳房病等。
> 这门课的特点是**"看得见、摸得着"**——很多病你亲眼看到，记忆更深刻。

---

## 为什么学中医外科学？

- **执业医师考试**占分不少（约10%）
- **临床实用性强**：皮肤科、肛肠科、乳腺科都是中医院常见科室
- **辨证思路独特**：外科病重视"**消、托、补**"三法

---

## 核心理论：外科病的病因病机

外科病的本质是**"邪毒壅聚"**——热毒、湿毒、痰毒等邪气壅聚于肌肤腠理，气血凝滞，经络阻塞。

> 💡 **生活例子**：
> - 夏天长了个"火疖子"（like 毛囊炎）→ 红肿热痛 → 这是**热毒壅聚**
> - 脚气感染化脓 → 脚部红肿、流黄水 → 这是**湿毒壅聚**
> - 乳腺增生形成肿块 → 乳房胀痛、肿块随情绪波动 → 这是**痰毒壅聚+肝气郁结**

### 外科病的共同病机

```
外邪侵袭（热毒、湿毒） + 脏腑失调（脾胃湿热、肝郁气滞）
               ↓
         气血凝滞，经络阻塞
               ↓
         肿胀、疼痛、化脓
```

> ⚠️ **临床意义**：外科病的**核心病机**是"气血凝滞"！
> - 初期：气血凝滞 → 肿胀疼痛 → 用**消法**（活血化瘀、清热解毒）
> - 成脓期：气血化脓 → 肿块变软、有波动感 → 用**托法**（透脓外出）
> - 溃后期：气血亏虚 → 创面不敛、肉芽生长慢 → 用**补法**（补益气血）

---

## 外科病的三大治法（必背）

这是中医外科学的**灵魂**，所有病证都围绕这三大法。

| 治法 | 适用阶段 | 代表方/药 |
|------|---------|----------|
| **消法** | 初期，肿疡未成脓 | 清热解毒、活血化瘀（仙方活命饮） |
| **托法** | 成脓期，正气不足，脓成不溃 | 透脓散、托里消毒散 |
| **补法** | 溃后期，气血亏虚，创面不敛 | 八珍汤、十全大补汤 |

!!! tip "记忆口诀"
    初期用消（消掉它），成脓用托（托出来），溃后用补（补起来）。

## 重点病证详解

### 1. 疮疡（外科感染）

疮疡是**一切体表化脓性疾病**的总称，相当于西医的"软组织感染"。

#### 辨证分型（必背）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **热毒蕴结** | 红肿热痛明显，高热，舌红苔黄 | 仙方活命饮 |
| **火毒炽盛** | 红肿范围大，高热不退，苔黄腻 | 五味消毒饮 |
| **阴虚火炽** | 溃后不愈，低热，盗汗，舌红少苔 | 清骨散 |
| **气血两虚** | 溃后不敛，面色萎黄，舌淡 | 十全大补汤 |

> 💡 **生活例子**：
> - 脸上长了个大火疖子，红肿疼痛，按上去更痛 → 这就是"热毒蕴结"
> - 疖子没处理好，周围皮肤也红肿了，还发烧 → 这是"火毒炽盛"，要赶紧去医院
> - 伤口拖了很久不好，还经常低热、盗汗 → 可能是"阴虚火炽"，身体抵抗力差了

> ⚠️ **红旗警告**：如果疮疡红肿范围迅速扩大、伴有高热寒战 → 可能是**败血症**的前兆！必须立即就医，不能只靠中药。

??? question "自测：患者痈肿初起，红肿热痛，发热38.5℃，舌红苔黄，脉数。用什么法？什么方？"
    **答案：** 消法，仙方活命饮。
    
    **解析：** 初起、红肿热痛、热象明显 = 热毒蕴结 → 消法清热解毒。

---

### 2. 皮肤病（中医皮肤科）

中医皮肤科的特点是**从血分论治**——很多皮肤病本质是"血热、血瘀、血虚风燥"。

#### 常见皮肤病辨证

| 病名 | 特点 | 核心病机 | 代表方 |
|------|------|---------|--------|
| **湿疹** | 多形性皮疹，渗出倾向，瘙痒 | 湿热蕴肤 | 龙胆泻肝汤（急性期）、除湿胃苓汤（亚急性） |
| **荨麻疹** | 风团，此起彼伏，瘙痒剧烈 | 风热犯表/血虚风燥 | 消风散（风热）、当归饮子（血虚） |
| **银屑病** | 红斑鳞屑，刮除鳞屑见点状出血 | 血热毒蕴 | 犀角地黄汤 + 凉血五花汤 |
| **痤疮** | 面部粉刺、丘疹、脓疱 | 肺胃热盛 | 枇杷清肺饮、栀子金花丸 |

> 💡 **生活例子**：
> - 湿疹：吃了海鲜后全身起红疹、流水、剧烈瘙痒 → 这是"湿热蕴肤"型湿疹
> - 荨麻疹：突然起风团，一会儿这里起、一会儿那里消 → 像"风"一样善行数变，所以是"风邪"引起的
> - 银屑病：头皮、四肢伸出红斑，上面有厚厚的银白色鳞屑，刮掉后有点状出血 → 这是"血热毒蕴"
> - 痤疮：青春期满脸痘痘，吃辣、熬夜后更严重 → 这是"肺胃热盛"

> ⚠️ **红旗警告**：
> - 皮肤病伴有**高热、关节痛、全身不适** → 可能是严重疾病（如药疹、红斑狼疮），必须去医院检查！
> - 银屑病如果全身发红、大量脱屑、伴有高热 → 可能是**红皮病型银屑病**，有生命危险！

!!! tip "皮肤病的共同辨证思路"
    1. 急性期 → 多属**风热、湿热** → 清热利湿、祛风止痒
    2. 慢性期 → 多属**血虚风燥** → 养血祛风、润燥止痒
    3. 顽固性 → 多属**血瘀** → 活血化瘀

??? question "自测：患者湿疹反复发作，皮损暗红，粗糙肥厚，舌淡苔白，脉弦细。证型？"
    **答案：** 血虚风燥证。
    
    **解析：** 慢性湿疹 + 皮损暗红粗糙 + 舌淡苔白/脉弦细 = 血虚风燥。

### 3. 肛肠病（痔疮、肛裂、肛瘘）

肛肠病是中医外科的**优势病种**，很多中医院有专门的肛肠科。

#### 痔疮的分型与治疗

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **风热肠燥** | 便血鲜红，肛门瘙痒，舌红苔薄黄 | 凉血地黄汤 |
| **湿热下注** | 便血色暗红，肛门灼热，苔黄腻 | 止痛如神汤 |
| **气滞血瘀** | 肛门肿痛，痔核紫暗，舌暗有瘀斑 | 活血散瘀汤 |
| **脾虚气陷** | 痔核脱出不还纳，乏力，舌淡 | 补中益气汤 |

> 💡 **生活例子**：
> - 大便时滴鲜血，量不多，不痛 → 这是"风热肠燥"型痔疮（内痔常见）
> - 痔疮脱出，要用手推回去，还经常拉肚子、乏力 → 这是"脾虚气陷"，需要补气升提
> - 肛门剧痛，痔核紫暗 → 这是"气滞血瘀"，可能是血栓性外痔

> ⚠️ **红旗警告**：便血不只是痔疮！如果便血伴有**大便习惯改变、体重下降、贫血** → 必须做肠镜排除**结直肠癌**！

---

### 4. 乳房病（乳痈、乳癖）

#### 乳痈（急性乳腺炎）

- **病因**：乳汁淤积 + 热毒侵袭
- **分期治疗**：
  - 初起（红肿热痛）→ 疏肝清胃、通乳消肿 → 瓜蒌牛蒡汤
  - 成脓期（波动感）→ 切开排脓 + 托里消毒散
  - 溃后期 → 补益气血 → 八珍汤

#### 乳癖（乳腺增生）

- **核心病机**：肝郁气滞、痰瘀互结
- **代表方**：逍遥散 + 鹿角霜、浙贝母、牡蛎（软坚散结）

> 💡 **生活例子**：
> - 每次来月经前乳房胀痛，月经后缓解 → 这是典型的乳腺增生表现
> - 摸到乳房有"肿块"，边界不清、可以推动 → 这是"痰瘀互结"，需要活血化瘀、软坚散结
> - 工作压力大、情绪不好时乳房胀痛加重 → 这是"肝郁气滞"，要疏肝理气

> ⚠️ **红旗警告**：如果乳房肿块**边界不清、固定不动、伴有乳头凹陷或血性溢液** → 必须做乳腺超声或钼靶检查，排除**乳腺癌**！

## 外科外治法（特色内容）

中医外科的**外治法**是特色，很多病单用外治就能见效。

### 外治法的分类

| 方法 | 适用 | 常用药物/方剂 |
|------|------|-------------|
| **敷贴法** | 肿疡初起、溃疡 | 金黄散（消肿）、生肌散（生肌） |
| **熏洗法** | 皮肤病、肛门病 | 苦参汤（湿疹）、五倍子汤（痔疮） |
| **切开法** | 成脓期 | 手术切开排脓 |
| **挂线法** | 肛瘘 | 挂线疗法（避免肛门失禁） |

> 💡 **生活例子**：
> - 皮肤长了个红包、还没化脓 → 可以敷**金黄散**，帮助消肿止痛
> - 痔疮犯了、肛门瘙痒 → 用**五倍子汤**熏洗，能清热燥湿、止痒
> - 脓肿已经变软、有波动感 → 必须**切开排脓**，光靠吃药好不了

> ⚠️ **红旗警告**：如果身上有红肿热痛的包块，不要自己随便切开！一定要让医生判断是否已经化脓，盲目切开可能导致感染扩散！

!!! tip "外治法的选择原则"
    - 初起 → 敷贴（金黄散、玉露散）
    - 成脓 → 切开（十字切开、对口切开）
    - 溃后 → 祛腐生肌（九一丹、生肌散）

## 常见学习误区

!!! warning "误区1：只学内治，不学外治"
    中医外科的**外治法**是特色，执业医师考试也会考外治法的适应症和用药。
    
    **正确做法：** 每个病证都要掌握"内治+外治"两种方法。

!!! warning "误区2：皮肤病只会"清热""
    皮肤病不全是"热毒"，慢性湿疹是"血虚风燥"，银屑病稳定期是"血瘀"。
    
    **正确做法：** 辨证要分**急性期/慢性期**，不能一概而论。

!!! warning "误区3：忽略"消托补"的辨证要点"
    "消托补"三法是外科病的**总纲**，但很多人只会背，不会用。
    
    **正确做法：** 每个病证都要能判断"现在处于消/托/补哪个阶段"。

## 自测习题

??? question "1. 疮疡初起，红肿热痛，发热，舌红苔黄，脉数。治法？用方？"
    **答案：** 消法，仙方活命饮。
    
    **解析：** 初起 + 红肿热痛 + 热象明显 = 热毒蕴结 → 消法清热解毒、活血化瘀。

??? question "2. 湿疹慢性期，皮损暗红粗糙，舌淡苔白，脉弦细。证型？用方？"
    **答案：** 血虚风燥证，当归饮子。
    
    **解析：** 慢性湿疹 + 皮损暗红粗糙 + 舌淡苔白/脉弦细 = 血虚风燥 → 养血祛风、润燥止痒。

??? question "3. 痔疮脱出不还纳，乏力，面色萎黄，舌淡苔白，脉弱。证型？用方？"
    **答案：** 脾虚气陷证，补中益气汤。
    
    **解析：** 脱出不还纳 + 乏力 + 舌淡/脉弱 = 脾虚气陷 → 补中益气、升阳举陷。

??? question "4. 乳痈初起，乳房红肿热痛，恶寒发热，舌红苔薄黄，脉浮数。证型？用方？"
    **答案：** 肝郁胃热证，瓜蒌牛蒡汤。
    
    **解析：** 乳痈初起 + 红肿热痛 + 恶寒发热 = 肝郁胃热、乳汁淤积 → 疏肝清胃、通乳消肿。
