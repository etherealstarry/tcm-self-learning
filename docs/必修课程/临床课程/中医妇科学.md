# 中医妇科学 学习指南

> 中医妇科学主要研究**经、带、胎、产**四大类疾病。
> 这门课的特点是**和肝、脾、肾三脏关系特别密切**——"女子以肝为先天"。

---

## 为什么学中医妇科学？

- **执业医师考试**占分约10%
- **临床需求大**：妇科病发病率高，中医院妇科门诊量大
- **中医优势明显**：月经不调、不孕症、更年期综合征等，中医治疗效果好

---

## 核心理论：妇科病的病因病机

妇科病的本质是**脏腑功能失调**（尤其是肝、脾、肾），导致**气血失调**，进而影响**冲任二脉**。

> 💡 **生活例子**：
> - 工作压力大、经常熬夜 → **肝郁气滞** → 月经紊乱、胸胁胀痛
> - 减肥过度、营养不良 → **脾虚气血不足** → 月经量少、色淡
> - 多次流产、早产 → **肾虚冲任损伤** → 不孕、习惯性流产

### 妇科病的核心病机链条

```
肝（疏泄失常） + 脾（生化不足） + 肾（天癸亏虚）
               ↓
         气血失调，冲任损伤
               ↓
       经、带、胎、产诸病
```

> 💡 **临床意义**：妇科病的**核心病机**是"冲任损伤"！
> - 冲脉 = "血海" → 调节月经
> - 任脉 = "阴脉之海" → 主胞胎
> - 冲任损伤 → 月经病、带下病、不孕症

!!! tip "记忆口诀"
    妇科病，肝为先（肝郁气滞 → 月经不调）；
    脾为源（脾虚 → 气血不足 → 月经量少）；
    肾为本（肾虚 → 天癸不足 → 闭经、不孕）。

## 重点病证详解

### 1. 月经病（最核心）

月经病是妇科的**重中之重**，占考试和临床的大头。

#### 月经先期（周期 < 21天）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **气虚** | 月经提前，量多色淡，乏力，舌淡 | 补中益气汤 |
| **血热** | 月经提前，量多色红，口渴，舌红苔黄 | 清经散（实热）、两地汤（虚热） |

> 💡 **生活例子**：
> - 月经每次都提前7天以上，量多吃辣后更甚 → 这是"血热"型月经先期
> - 月经提前、量多但颜色淡、累了就加重 → 这是"气虚"型，需要补气摄血

> ⚠️ **红旗警告**：月经提前且量非常多（1小时湿透卫生巾）→ 可能是**功血**或子宫肌瘤，必须去医院检查！

#### 月经后期（周期 > 35天）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **血虚** | 月经延后，量少色淡，头晕心悸，舌淡 | 大补元煎 |
| **血寒** | 月经延后，量少色暗，小腹冷痛，舌淡苔白 | 温经汤 |
| **气滞** | 月经延后，量少色暗有块，胸胁胀痛 | 乌药汤 |

> 💡 **生活例子**：
> - 减肥过度、营养不良导致月经推迟 → 这是"血虚"型月经后期
> - 冬天穿得少、爱吃冷饮，月经推迟、小腹冷痛 → 这是"血寒"型
> - 心情不好、压力大时月经推迟 → 这是"气滞"型，需要疏肝理气

> ⚠️ **红旗警告**：月经突然停闭超过3个月（排除怀孕）→ 可能是**多囊卵巢综合征**或**卵巢早衰**，必须检查激素六项！

#### 月经先后无定期（周期紊乱）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **肝郁** | 月经周期紊乱，量多少不定，胸胁胀痛 | 逍遥散 |
| **肾虚** | 月经周期紊乱，量少色淡，腰酸，舌淡 | 固阴煎 |

#### 月经过多

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **气虚** | 量多色淡，乏力，舌淡 | 安冲汤 |
| **血热** | 量多色红，口渴，舌红苔黄 | 保阴煎 |
| **血瘀** | 量多色暗有块，腹痛拒按 | 桃红四物汤 |

> 💡 **生活例子**：
> - 来月经时像"开闸放水"，1小时湿透卫生巾 → 这是"气虚"或"血热"型月经过多
> - 月经量少得可怜，只用护垫就行 → 这是"血虚"或"肾虚"型月经过少
> - 月经有黑色血块、腹痛拒按 → 这是"血瘀"型，需要活血化瘀

> ⚠️ **红旗警告**：月经过多导致**贫血**（头晕、心慌、面色苍白）→ 必须去医院检查，排除子宫肌瘤、内膜病变！

#### 月经过少

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **血虚** | 量少色淡，头晕心悸，舌淡 | 滋血汤 |
| **肾虚** | 量少色暗，腰酸，舌淡 | 归肾丸 |
| **血瘀** | 量少色暗有块，腹痛拒按 | 桃红四物汤 |

> 💡 **生活例子**：
> - 月经量少、色淡，节食减肥后更明显 → 这是"血虚"型，需要补血养血
> - 月经量少、色暗有血块，受凉后加重 → 这是"血瘀"型，需要活血化瘀

> ⚠️ **红旗警告**：月经过少可能是**宫腔粘连**或**卵巢早衰**的信号！如果伴有潮热盗汗、不孕 → 必须检查激素六项和宫腔镜！

??? question "自测：患者月经提前，量多色淡，乏力，气短，舌淡苔白，脉弱。证型？用方？"
    **答案：** 气虚证，补中益气汤。
    
    **解析：** 月经提前（先期）+ 量多色淡 + 乏力气短 + 舌淡/脉弱 = 气虚 → 补气摄血。

### 2. 带下病

带下病是**带下量、色、质、气味异常**的病证。

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **脾虚** | 带下量多，色白质稀，无臭，乏力 | 完带汤 |
| **肾虚** | 带下量多，清冷如水，腰酸，舌淡 | 内补丸 |
| **湿热下注** | 带下量多，色黄质稠，臭秽，阴痒 | 止带方 |
| **热毒蕴结** | 带下量多，色黄绿如脓，臭秽，发热 | 五味消毒饮 |

> 💡 **生活例子**：
> - 白带多、像豆腐渣一样、外阴瘙痒 → 可能是**霉菌性阴道炎**（中医属"湿热下注"）
> - 白带黄稠、臭秽、伴有腹痛 → 可能是**盆腔炎**（中医属"湿毒"）
> - 白带清冷如水、腰酸怕冷 → 这是"肾虚"型带下，需要温补肾阳

> ⚠️ **红旗警告**：带下伴有**不规则阴道出血、下腹痛、发热** → 可能是**盆腔炎、宫颈癌**！必须去医院做妇科检查、TCT、HPV检测！

!!! tip "带下病的辨证要点"
    - 带下**色白、质稀** → 虚证（脾虚、肾虚）
    - 带下**色黄、质稠** → 湿热
    - 带下**如脓、臭秽** → 热毒

---

### 3. 妊娠病

妊娠病是**妊娠期间**发生的疾病，治疗时要注意**治病与安胎兼顾**。

#### 恶阻（妊娠呕吐）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **脾胃虚弱** | 恶心呕吐，食欲不振，乏力 | 香砂六君子汤 |
| **肝胃不和** | 恶心呕吐，胸胁胀痛，口苦 | 苏叶黄连汤 |

#### 胎动不安（先兆流产）

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **肾虚** | 腰酸腹痛，阴道少量出血，色淡 | 寿胎丸 |
| **气血虚弱** | 腰酸腹痛，阴道出血，色淡质稀，乏力 | 胎元饮 |
| **血热** | 腰酸腹痛，阴道出血，色红质稠，舌红 | 保阴煎 |
| **血瘀** | 腰酸腹痛，阴道出血，色暗有块 | 桂枝茯苓丸 |

> 💡 **生活例子**：
> - 怀孕早期阴道流血、腰酸腹痛 → 这是**胎动不安**（先兆流产），要赶紧卧床休息
> - 怀孕早期恶心呕吐严重，吃啥吐啥 → 这是"恶阻"（妊娠呕吐），严重时会脱水
> - 怀孕期间阴道少量出血、色淡、腰酸 → 这是"肾虚"型胎动不安，需要补肾安胎

> ⚠️ **红旗警告**：妊娠期**阴道出血 + 腹痛** → 必须立即去医院检查，排除**宫外孕、先兆流产**！不要自己吃药！

### 4. 产后病

产后病的核心是**"多虚多瘀"**——产后气血亏虚，同时瘀血内阻。

#### 产后发热

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **感染邪毒** | 高热，恶寒，恶露臭秽 | 五味消毒饮 + 失笑散 |
| **血瘀** | 低热，恶露不下或下而不畅，腹痛 | 生化汤 |
| **血虚** | 低热，恶露量少色淡，乏力 | 八珍汤 |

#### 产后腹痛

| 证型 | 特点 | 代表方 |
|------|------|--------|
| **血虚** | 腹痛隐隐，喜按，恶露量少色淡 | 肠宁汤 |
| **血瘀** | 腹痛拒按，恶露不下或下而不畅 | 生化汤 |

> 💡 **生活例子**：
> - 产后低热、恶露量少色淡、乏力 → 这是"血虚"型产后发热，需要补血养血
> - 产后小腹疼痛、恶露有血块 → 这是"血瘀"型产后腹痛，需要活血化瘀
> - 产后高热、恶露臭秽 → 这是"感染邪毒"，**必须立即就医**（可能是产褥感染）

> ⚠️ **红旗警告**：产后**高热、恶露臭秽、下腹剧痛** → 可能是**产褥感染**（败血症前兆）！必须立即去医院，不能只靠中药！

## 妇科病的"必背清单"

### 1. 月经病的辨证公式

```
经期异常（先期/后期/先后无定期） + 经量异常（过多/过少） + 经色经质 + 伴随症状 + 舌脉 = 证型
```

### 2. 带下病的辨证公式

```
带下量 + 带下色 + 带下质 + 气味 + 伴随症状 + 舌脉 = 证型
```

### 3. 妊娠病的用药禁忌

!!! warning "妊娠禁忌药"
    以下药物**妊娠期禁用或慎用**：
    
    - **禁用**：麝香、水蛭、虻虫、三棱、莪术等（破血逐瘀力强）
    - **慎用**：桃仁、红花、大黄、枳实等（攻下、破气力强）
    
    **记忆口诀：** 妊娠期用药要"**稳**"，破血、攻下、逐水药要**慎**。

## 常见学习误区

!!! warning "误区1：月经病的证型"记混""
    月经先期/后期/过多/过少，每个都有"气虚、血热、血瘀"等相似证型，容易记混。
    
    **正确做法：** 制作"对比表格"，把相似证型放在一起对比记忆。

!!! warning "误区2：妊娠病忘记"安胎""
    妊娠病的治疗原则是**治病与安胎兼顾**，不能只治病、不顾胎。
    
    **正确做法：** 每个妊娠病的方剂，都要知道"安胎药"有哪些（如桑寄生、续断、杜仲、阿胶）。

!!! warning "误区3：产后病的"多虚多瘀"理解不深"
    产后病的治疗要**扶正与祛瘀兼顾**，不能只补虚、也不能只攻瘀。
    
    **正确做法：** 每个产后病的方剂，都要分析"补虚药"和"祛瘀药"的比例。

## 自测习题

??? question "1. 患者月经延后，量少色淡，头晕心悸，失眠多梦，舌淡苔白，脉细。证型？用方？"
    **答案：** 血虚证，大补元煎。
    
    **解析：** 月经延后 + 量少色淡 + 头晕心悸 + 舌淡/脉细 = 血虚 → 补血养血。

??? question "2. 患者带下量多，色白质稀，无臭，乏力，舌淡苔白，脉缓弱。证型？用方？"
    **答案：** 脾虚证，完带汤。
    
    **解析：** 带下量多 + 色白质稀 + 无臭 + 乏力 + 舌淡/脉缓弱 = 脾虚 → 健脾益气、升阳除湿。

??? question "3. 患者妊娠期间，腰酸腹痛，阴道少量出血，色淡，头晕耳鸣，舌淡苔白，脉沉细。证型？用方？"
    **答案：** 肾虚证，寿胎丸。
    
    **解析：** 妊娠期 + 腰酸腹痛 + 阴道出血色淡 + 头晕耳鸣 + 舌淡/脉沉细 = 肾虚 → 补肾安胎、固冲止血。

??? question "4. 患者产后低热，恶露不下，小腹疼痛拒按，舌质紫暗，脉弦涩。证型？用方？"
    **答案：** 血瘀证，生化汤。
    
    **解析：** 产后 + 低热 + 恶露不下 + 腹痛拒按 + 舌质紫暗/脉弦涩 = 血瘀 → 活血化瘀、温经止痛。
