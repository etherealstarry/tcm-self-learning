# 好书推荐 —— 实习阶段（大五）

!!! tip "实习阶段，读什么书？"
    大五实习，**时间紧、任务重**。
    
    - 需要**随身查**的手册（实习时用）
    - 需要**复习备考**的用书（执业医师考试）
    - 需要**整理医案**的方法书
    
    本页推荐**实习阶段**的好书。

---

## 💡 保姆级学习建议（实习阶段）

> 💡 **生活例子**：
> - 实习就像"上战场"——以前是"纸上谈兵"，现在是"真刀真枪"
> - 病历书写就像"写作文"——要有条理、有逻辑，不能乱写
> - 跟师抄方就像"学徒制"——看师傅怎么"出手"，比自己看书强10倍

> ⚠️ **红旗警告**：实习阶段最重要的是"临床思维"！技术可以后面学，但临床思维必须实习时建立。如果实习只管床不思考 = 白实习！

> 💡 **临床意义**：
> - 实习是"理论到实践"的桥梁——学完5年，终于能"真刀真枪"看病了
> - 跟师能学到"书里没有"的经验——很多名老中医的独门绝技，书里根本找不到
> - 病历书写是"基本功"——写不好 = 被带教老师骂 + 影响毕业成绩

## 📖 实习阶段推荐书目

### 1. 《中医临床手册》—— 多版本
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **适合人群**：大五实习生，随身查
    - **内容**：常见病辨证论治，简洁明了
    - **怎么用**：实习时随身带，遇到不懂的病，马上查
    - **优点**：小巧，内容全，实用性强
    - **缺点**：不够深入，只能做参考

    !!! quote "精彩片段"
        "胃痛：寒邪客胃 → 良附丸；饮食伤胃 → 保和丸；肝气犯胃 → 柴胡疏肝散……"

### 2. 《中医内科学》—— 教材（第10版）
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **适合人群**：大五实习生，复习备考用
    - **内容**：所有内科病的辨证论治
    - **怎么用**：实习期间，遇到什么病，就复习对应章节
    - **优点**：权威，系统，考试重点
    - **缺点**：较厚，不便携带

    !!! warning "实习期间怎么用教材？"
        别把教材扔了！
        
        实习时遇到**不懂的病**，马上翻教材对应章节。
        这样：**临床 + 理论**结合，进步最快。

### 3. 《名老中医医案集》—— 佚名（多版）
!!! success "推荐指数：⭐⭐⭐⭐"
    - **适合人群**：大五实习生，学辨证思路
    - **内容**：多位名老中医的典型医案
    - **怎么用**：每天睡前读1-2个医案，坚持一学期
    - **优点**：真实医案，思路清晰
    - **缺点**：部分医案较深，需要一定基础

### 4. 《中医病历书写规范》—— 国家中医药管理局
!!! success "推荐指数：⭐⭐⭐⭐"
    - **适合人群**：大五实习生，写病历用
    - **内容**：中医病历书写规范、格式、示例
    - **怎么用**：写病历前，先读一遍，别被带教老师骂
    - **优点**：权威，必须掌握
    - **缺点**：较枯燥

    !!! danger "病历书写，很重要！"
        实习时，**病历书写**是基本功。
        
        写不好 = 被带教老师骂 + 影响毕业成绩。
        
        必须认真学。

### 5. 《执业医师资格考试指导》—— 国家中医药管理局
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **适合人群**：大五实习生，备考执业医师
    - **内容**：考试大纲、真题、模拟题
    - **怎么用**：实习期间，每天复习1-2章
    - **优点**：备考必备
    - **缺点**：较厚，需要坚持

## 🎯 实习阶段阅读计划

### 实习第1-3个月（适应期）
!!! example "你的阅读任务"
    - **《中医临床手册》**：随身带，随时查
    - **《中医病历书写规范》**：精读，掌握病历书写
    - **教材《中医内科学》**：遇到什么病，就复习对应章节

### 实习第4-6个月（提高期）
!!! example "你的阅读任务"
    - **《名老中医医案集》**：每天睡前读1-2个医案
    - **《执业医师资格考试指导》**：开始复习，每天1-2章
    - **整理医案**：把跟师抄的方子，整理成医案

### 实习第7-12个月（冲刺期）
!!! example "你的阅读任务"
    - **《执业医师资格考试指导》**：刷题，模拟考试
    - **教材复习**：系统复习14门考试科目
    - **整理笔记**：把实习期间的心得，整理成笔记

## 📝 实习期间，怎么整理医案？

### 方法：按病种整理
!!! success "推荐格式"
    ```markdown
    ## 病种：胃痛
    
    ### 医案1：脾胃虚寒（跟师抄方）
    - 老师：XXX
    - 日期：202X年X月X日
    - 患者：男，45岁
    - 主诉：胃脘隐痛3个月
    - 辨证：脾胃虚寒
    - 处方：黄芪建中汤加味
    - 我的心得：......
    
    ### 医案2：肝气犯胃（实习管床）
    - 患者：女，32岁
    - 主诉：胃脘胀痛，连及两胁
    - 辨证：肝气犯胃
    - 处方：柴胡疏肝散
    - 我的心得：......
    ```
    
    !!! tip "整理医案的好处"
        - 复习时，一看就懂（因为是自己整理的）
        - 执业医师考试，医案题能拿高分
        - 未来临床，这些医案是你的"弹药库"

## 💡 给你的建议

!!! tip "给实习阶段自学者的建议"
    1. **教材别扔**：实习时遇到不懂的病，马上翻教材
    2. **随身带手册**：《中医临床手册》随身带，随时查
    3. **整理医案**：把跟师抄的方子、自己管床的病人，整理成医案
    4. **备考要早**：别等实习结束才开始备考执业医师，那就晚了
    5. **多问、多动手**：实习时，别怕丢脸，多问带教老师；别怕累，多动手

!!! danger "实习阶段最常见的误区"
    - **误区1**：实习摸鱼，不认真管床 → 毕业了还不会看病
    - **误区2**：只顾实习，不备考 → 执业医师考试没过，拿不到资格证
    - **误区3**：不整理医案 → 实习结束，什么都没留下
