## 📖 如何选书？

:::tip 选书四原则
1. **教材优先**：规划教材是根本，先读教材再读扩展
2. **注家选名家**：读经典要选好注本（刘渡舟、邓铁涛等名家注本）
3. **医案找名家**：蒲辅周、岳美中、赵锡武等名家医案最有价值
4. **不贪多**：好书很多，但时间有限，精读 10 本 > 泛读 100 本
:::

## 💡 读书方法推荐

### SQ3R 读书法（适合教材类）

```
S (Survey，浏览）：先浏览目录、小标题、图表，建立整体框架
Q (Question，提问）：针对每节内容提出问题
R1 (Read，阅读）：带着问题去阅读
R2 (Recite，复述）：读完后合上书，复述核心内容
R3 (Review，复习）：定期回顾，巩固记忆
```

### 医案读书法（适合医案类）

```
第一步：先读病例（症状、辨证、治法、方药）
第二步：自己先辨证、拟方
第三步：再看名家的辨证思路和用方
第四步：对比自己的思路和名家的差异
第五步：记录心得体会
```
