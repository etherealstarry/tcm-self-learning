# 好书推荐 —— 执业医师考试

!!! tip "备考执业医师，读什么书？"
    执业医师考试**通过率约30-40%**，不是那么容易过的。
    
    必须**系统复习**，不能靠运气。
    
    本页推荐**备考执业医师**的好书。

## 📖 执业医师考试推荐书目

### 1. 《执业医师资格考试指导》—— 国家中医药管理局
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **适合人群**：所有备考者（必备）
    - **内容**：考试大纲、知识点汇总、真题
    - **怎么用**：系统复习，按章节读
    - **优点**：权威，考点全
    - **缺点**：较厚，需要坚持

    !!! quote "精彩片段"
        "中医执业医师资格考试，分为实践技能考试和医学综合笔试两部分……"

### 2. 《执业医师资格考试真题集》—— 国家中医药管理局
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **适合人群**：所有备考者（必备）
    - **内容**：历年真题 + 答案解析
    - **怎么用**：刷题，每天20-30题
    - **优点**：真题最权威
    - **缺点**：部分答案可能有争议

    !!! tip "刷题方法"
        - 第一遍：按章节刷（学完一章，刷一章的题）
        - 第二遍：按年份刷（做完整套真题）
        - 第三遍：只刷错题

### 3. 《执业医师资格考试模拟题集》—— 多家出版社
!!! success "推荐指数：⭐⭐⭐⭐"
    - **适合人群**：备考中后期（刷完真题后）
    - **内容**：模拟题 + 答案解析
    - **怎么用**：模拟考试，每周1次
    - **优点**：接近真题难度
    - **缺点**：质量参差不齐，选口碑好的版本

### 4. 《中医临床手册》—— 多版本
!!! success "推荐指数：⭐⭐⭐⭐"
    - **适合人群**：实习期间随身查
    - **内容**：常见病辨证论治，简洁明了
    - **怎么用**：实习时随身带，遇到不懂的病，马上查
    - **优点**：小巧，内容全
    - **缺点**：不够深入

## 🎯 备考执业医师，怎么安排阅读？

### 备考第1-3个月（系统复习）
!!! example "你的阅读任务"
    - **《执业医师资格考试指导》**：系统复习，按章节读

    - **目标**：把所有考试科目过一遍

### 备考第4-6个月（刷题阶段）
!!! example "你的阅读任务"
    - **《执业医师资格考试真题集》**：按章节刷题
    - **整理错题**：把错题整理成册，重点复习
    - **目标**：刷题 + 查漏补缺

### 备考第7-9个月（模拟考试）
!!! example "你的阅读任务"
    - **《执业医师资格考试模拟题集》**：模拟考试，每周1次
    - **复习错题**：重点复习之前整理的错题
    - **目标**：适应考试节奏，提高答题速度

### 备考第10-12个月（冲刺阶段）
!!! example "你的阅读任务"
    - **《执业医师资格考试真题集》**：只刷错题
    - **复习重点**：重点复习高频考点
    - **调整心态**：别紧张，正常发挥

## 💡 给你的建议

!!! tip "给备考者的建议"
    1. **早准备**：别等实习结束才开始备考，那就晚了
    2. **系统复习**：别只刷题，不复习教材——基础不牢，地动山摇
    3. **整理错题**：错题是你的"提分点"，必须重点复习
    4. **模拟考试**：适应考试节奏，提高答题速度
    5. **调整心态**：别紧张，正常发挥

!!! danger "备考最常见的误区"
    - **误区1**：只刷题，不复习教材 → 基础不牢，遇到变形题就懵
    - **误区2**：不整理错题 → 同一个坑，掉进去两次
    - **误区3**：临时抱佛脚 → 执业医师考试不是那么容易过的，必须系统复习
