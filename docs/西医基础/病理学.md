# 病理学 学习指南

> 病理学是研究**疾病发生、发展规律**的学科——生理学告诉你"人体正常是什么样"，病理学告诉你"人体病了是什么样"。
> 这门课的特点是**"形态变化 + 功能变化"**，要联系临床。

---

## 为什么这门课特别重要？

- **执业医师考试**占分约8-10%
- **诊断学、内科学的基础**——不懂病理，怎么诊断？怎么治疗？
- **临床必备**——病理诊断是"金标准"（如肿瘤的诊断）

---

## 核心理论：疾病的基本病理过程

### 疾病的基本病理过程（必背）

| 过程 | 解释 | 举例 |
|------|------|------|
| **适应** | 细胞、组织对环境改变的适应 | 萎缩、肥大、增生、化生 |
| **损伤** | 细胞、组织的损伤 | 变性、坏死、凋亡 |
| **修复** | 损伤后的修复 | 再生、纤维化、创伤愈合 |
| **炎症** | 机体对损伤的防御反应 | 急性炎症、慢性炎症 |
| **肿瘤** | 细胞的异常增生 | 良性、恶性 |

---

## 重点内容详解

### 1. 细胞、组织的适应和损伤

#### 适应（必背）

| 类型 | 定义 | 举例 |
|------|------|------|
| **萎缩** | 发育正常的组织、器官体积缩小 | 废用性萎缩（骨折后肌肉萎缩）、压迫性萎缩（肾积水） |
| **肥大** | 细胞、组织、器官体积增大 | 生理性肥大（妊娠子宫）、病理性肥大（高血压左心室肥大） |
| **增生** | 细胞数目增多 | 生理性增生（青春期乳腺）、病理性增生（雌激素过多致子宫内膜增生） |
| **化生** | 一种成熟细胞被另一种成熟细胞替代 | 鳞状上皮化生（吸烟致支气管纤毛柱状上皮→鳞状上皮）、肠上皮化生（慢性胃炎致胃黏膜→肠黏膜） |

#### 损伤（必背）

**变性（可逆）：**

| 类型 | 特点 | 举例 |
|------|------|------|
| **细胞水肿** | 细胞内Na⁺、水增多 | 缺氧、感染致肝细胞水肿 |
| **脂肪变性** | 细胞内脂滴增多 | 心肌炎、肝脂肪变性（酒精肝） |
| **玻璃样变性** | 细胞内、间质内蛋白质沉积 | 高血压肾小球入球小动脉玻璃样变 |
| **淀粉样变性** | 淀粉样蛋白沉积 | 阿尔茨海默病、多发性骨髓瘤 |

**坏死（不可逆）：**

| 类型 | 特点 | 举例 |
|------|------|------|
| **凝固性坏死** | 组织凝固，轮廓保留 | 心肌梗死、肾梗死 |
| **液化性坏死** | 组织液化，形成囊腔 | 脑软化、脓肿 |
| **纤维素样坏死** | 结缔组织、血管壁坏死 | 风湿病、结节性动脉炎 |
| **干酪样坏死** | 坏死组织呈干酪样 | 结核病（特征性） |
| **脂肪坏死** | 脂肪细胞坏死 | 急性胰腺炎（酶解性）、外伤（创伤性） |
| **坏疽** | 坏死组织继发腐败菌感染 | 干性坏疽（四肢末端）、湿性坏疽（肠、肺）、气性坏疽（深部肌肉，产气荚膜梭菌） |

**凋亡（程序性细胞死亡）：**

- 形态：细胞皱缩、核碎裂、凋亡小体形成
- 机制：Caspase家族激活
- 意义：生理（胚胎发育、衰老）、病理（病毒感染、肿瘤）

---

### 2. 损伤的修复

#### 再生（必背）

| 类型 | 再生能力 | 举例 |
|------|---------|------|
| **不稳定细胞** | 强 | 表皮、黏膜、造血细胞 |
| **稳定细胞** | 较强（平时不增殖，损伤后增殖） | 肝、肾、平滑肌 |
| **永久性细胞** | 无 | 神经元、骨骼肌、心肌 |

#### 纤维化和创伤愈合（重点掌握）

**肉芽组织（重点掌握）：**

- 成分：新生毛细血管 + 成纤维细胞 + 炎细胞
- 功能：抗感染、填补缺损、机化坏死组织
- 结局：成熟为瘢痕组织（纤维组织）

**创伤愈合的类型：**

| 类型 | 特点 | 举例 |
|------|------|------|
| **一期愈合** | 创缘整齐、对合好、愈合快、瘢痕少 | 手术切口 |
| **二期愈合** | 创缘不整齐、对合差、愈合慢、瘢痕多 | 感染伤口、创面大 |

### 3. 炎症

#### 炎症的基本病理变化（必背）

```
变质（组织损伤）
    ↓
渗出（血管反应：血流变慢、血管通透性↑、白细胞游出）
    ↓
增生（细胞增殖：巨噬细胞、成纤维细胞、血管内皮细胞）
```

#### 急性炎症（重点掌握）

**血管反应（重点掌握）：**

1. **细动脉短暂收缩**（几秒到几分钟）
2. **细动脉扩张、血流加速**（红、热）
3. **血管通透性↑**（血浆渗出 → 水肿）
4. **白细胞游出**（附壁、游出、趋化、吞噬）

**白细胞的作用（重点掌握）：**

| 细胞 | 作用 | 举例 |
|------|------|------|
| **中性粒细胞** | 吞噬细菌、坏死组织 | 化脓菌感染（脓肿） |
| **单核细胞/巨噬细胞** | 吞噬大颗粒、抗原提呈 | 病毒感染、结核 |
| **淋巴细胞** | 特异性免疫（T细胞杀伤、B细胞产生抗体） | 病毒感染、自身免疫病 |
| **嗜酸性粒细胞** | 抗寄生虫、抗过敏 | 寄生虫感染、哮喘 |

**炎症介质（重点掌握）：**

| 介质 | 来源 | 作用 |
|------|------|------|
| **组胺** | 肥大细胞、嗜碱性粒细胞 | 血管扩张、通透性↑ |
| **5-羟色胺（5-HT）** | 血小板、肠嗜铬细胞 | 血管扩张、通透性↑ |
| **前列腺素（PG）** | 细胞膜磷脂（环氧化酶途径） | 血管扩张、致痛、致热 |
| **白三烯（LT）** | 细胞膜磷脂（脂氧化酶途径） | 血管通透性↑、白细胞趋化 |
| **缓激肽** | 血浆激肽原（激肽释放酶作用） | 血管通透性↑、致痛 |

#### 慢性炎症（重点掌握）

**慢性炎症的特点：**

- 浸润细胞：单核细胞、淋巴细胞、浆细胞
- 组织破坏：由炎细胞、修复细胞引起
- 修复：血管新生、纤维化

**肉芽肿性炎（重点掌握）：**

- 定义：巨噬细胞及其衍生细胞（上皮样细胞、多核巨细胞）增生形成的结节状病灶
- 举例：结核病（结核结节）、伤寒（伤寒肉芽肿）、风湿病（风湿小体）

### 4. 肿瘤

#### 肿瘤的特性（重点掌握）

**良、恶性肿瘤的区别（必背）：**

| 特征 | 良性 | 恶性 |
|------|------|------|
| **分化程度** | 高（异型性小） | 低（异型性大） |
| **生长速度** | 慢 | 快 |
| **生长方式** | 膨胀性、外生性 | 浸润性、外生性 |
| **转移** | 无 | 有（淋巴、血行、种植） |
| **复发** | 少 | 多 |
| **对机体影响** | 小（压迫、阻塞） | 大（破坏、出血、感染、恶病质） |

#### 肿瘤的命名和分类（重点掌握）

**命名原则：**

- 良性：组织来源 + "瘤"（如纤维瘤、脂肪瘤）
- 恶性：
  - 上皮组织来源："癌"（如鳞状细胞癌、腺癌）
  - 间叶组织来源："肉瘤"（如纤维肉瘤、骨肉瘤）
  - 混合型："癌肉瘤"

#### 常见肿瘤举例（重点掌握）

| 肿瘤 | 性质 | 好发部位 | 特点 |
|------|------|---------|------|
| **乳头状瘤** | 良性 | 皮肤、黏膜 | 外生性生长，乳头状 |
| **腺瘤** | 良性 | 腺体器官 | 腺管状、囊状 |
| **鳞状细胞癌** | 恶性 | 皮肤、黏膜 | 角化珠形成 |
| **腺癌** | 恶性 | 腺体器官 | 腺管状、实体状 |
| **纤维肉瘤** | 恶性 | 软组织 | 梭形细胞，鱼骨样排列 |

## 常见学习误区

!!! warning "误区1：只背形态，不联系功能"
    知道"坏死"是什么样，但不知道"坏死了会怎样"——这是**无效学习**。
    
    **正确做法：** 每个病理变化都要联系**功能变化**和**临床表现**。

!!! warning "误区2：不背"病因""
    病理变化是"结果"，病因是"原因"——不知道病因，怎么预防？
    
    **正确做法：** 每个疾病都要掌握"病因 → 病机 → 病理变化 → 临床表现 → 结局"。

!!! warning "误区3：忽略"良恶性肿瘤的区别""
    良恶性肿瘤的鉴别是**考试重点**，也是**临床重点**。
    
    **正确做法：** 良恶性肿瘤的区别要**背熟**，每个特征都要能举例。

## 自测习题

??? question "1. 患者长期吸烟，支气管黏膜活检发现纤毛柱状上皮变为鳞状上皮。这是什么变化？"
    **答案：** 鳞状上皮化生。
    
    **解析：** 化生是一种成熟细胞被另一种成熟细胞替代。吸烟致支气管纤毛柱状上皮→鳞状上皮（鳞状上皮化生），是**适应性变化**，但继续发展可能癌变。

??? question "2. 患者心肌梗死，梗死灶呈灰黄色、干燥、坚实，轮廓保留。这是什么类型坏死？"
    **答案：** 凝固性坏死。
    
    **解析：** 凝固性坏死的特点：组织凝固，轮廓保留。常见于心肌梗死、肾梗死。液化性坏死（组织液化）常见于脑软化、脓肿。

??? question "3. 患者结核菌素试验阳性，肺活检发现上皮样细胞、朗汉斯巨细胞、淋巴细胞、纤维母细胞构成的结节。这是什么炎症？"
    **答案：** 肉芽肿性炎（结核结节）。
    
    **解析：** 肉芽肿性炎是慢性炎症的特殊类型，特征是巨噬细胞及其衍生细胞增生形成的结节状病灶。结核病（结核结节）、伤寒（伤寒肉芽肿）、风湿病（风湿小体）都是肉芽肿性炎。

??? question "4. 患者肿块生长快，边界不清，固定，溃烂，出血。良恶性？判断依据？"
    **答案：** 恶性。判断依据：生长快、边界不清（浸润性生长）、固定（侵犯周围组织）、溃烂出血（破坏组织）。
    
    **解析：** 良恶性肿瘤的区别：良性（生长慢、边界清、膨胀性生长、无转移、复发少）；恶性（生长快、边界不清、浸润性生长、有转移、复发多）。

## 📝 自测习题

??? question "1. 简述动脉粥样硬化的病理变化过程（从脂纹到复合病变）。"
    **答案：** 动脉粥样硬化的发展过程：
    - **脂纹期**：巨噬细胞吞噬 Ox-LDL → 泡沫细胞 → 脂纹（可逆）
    - **纤维斑块期**：平滑肌细胞增生 + 胶原纤维沉积 → 纤维帽形成
    - **粥样斑块期**：纤维帽下的脂质池扩大，形成黄色粥样物
    - **复合病变期**：斑块内出血、斑块破裂、血栓形成、钙化、动脉瘤形成
    
    **临床意义：** 斑块破裂 → 血小板聚集 → 血栓形成 → 心肌梗死/脑梗死。

??? question "2. 炎症的基本病理变化有哪些？"
    **答案：** 炎症的 **局部基本病理变化**：
    - **变质**：组织细胞变性、坏死（由致炎因子直接引起）
    - **渗出**（核心环节）：血流动力学改变 → 血管通透性↑ → 液体和白细胞渗出 → **炎性介质释放**（组胺、前列腺素、细胞因子）
    - **增生**：成纤维细胞、血管内皮细胞、实质细胞增生（修复）
    
    **记忆：** 变质是"破坏"，渗出是"斗争"，增生是"修复"。

??? question "3. 良性高血压的分期和各期特点是什么？"
    **答案：**
    - **功能紊乱期**（早期）：全身细小动脉痉挛（功能性收缩），血压波动，可逆
    - **动脉病变期**：细小动脉玻璃样变（管壁增厚、管腔狭窄），血压持续升高，不可逆
    - **内脏病变期**：心脏（左心室肥大）、肾脏（原发性颗粒性固缩肾）、脑（脑出血）、视网膜病变
    
    **临床意义：** 控制血压可逆转功能紊乱期，但动脉病变期已不可逆。

??? question "4. 良性和恶性肿瘤的区别是什么？"
    **答案：**
    
    | 区别点 | 良性肿瘤 | 恶性肿瘤 |
    |--------|---------|---------|
    | 分化程度 | 高，异型性小 | 低，异型性大 |
    | 生长速度 | 缓慢 | 迅速 |
    | 生长方式 | 膨胀性、有包膜 | 浸润性、无包膜 |
    | 转移 | 无 | 有（淋巴道、血道、种植） |
    | 复发 | 很少 | 易复发 |
    | 对机体影响 | 局部压迫 | 破坏组织、恶病质、死亡 |
    
    **记忆：** 良性="乖"；恶性="坏"。

??? question "5. 血栓形成的条件（Virchow 三要素）是什么？"
    **答案：** 血栓形成需要 **三个条件**（Virchow 三要素）：
    - **心血管内皮损伤**（最重要）：启动内凝血系统，血小板黏附聚集
    - **血流状态改变**：血流缓慢（静脉血栓）、涡流（动脉血栓）
    - **血液凝固性增高**：高凝状态（如DIC、妊娠、恶性肿瘤）
    
    **临床意义：** 长期卧床 → 下肢静脉血流缓慢 → 深静脉血栓形成 → 脱落 → 肺动脉栓塞（猝死）。

??? question "6. 休克的分期和各期特点是什么？"
    **答案：**
    - **休克早期（代偿期）**：微循环痉挛期，血压正常或略降，面色苍白、四肢湿冷，脉搏细速 → **可逆转**
    - **休克期（失代偿期）**：微循环淤滞期，血压明显下降，尿量↓，意识障碍 → **积极抢救**
    - **休克晚期（DIC期）**：微循环衰竭期，顽固性低血压，出血倾向（DIC），多器官衰竭 → **预后极差**
    
    **临床意义：** 早期发现并纠正休克（补充血容量），可防止进入不可逆期。

??? question "7. 肝硬化时，门脉高压症的临床表现有哪些？"
    **答案：** 门脉高压症 → **四大临床表现**：
    - **脾肿大**：脾静脉回流受阻 → 淤血性脾肿大
    - **胃肠淤血**：消化不良（食欲不振、腹胀、腹泻）
    - **腹水**：门静脉压力↑ + 白蛋白↓ + 醛固酮灭活↓ → 腹水形成
    - **侧支循环形成**（最重要）：食管下段静脉曲张（破裂→大出血）、直肠静脉曲张（痔）、腹壁静脉曲张（海蛇头）
    
    **临床意义：** 食管静脉曲张破裂是肝硬化患者**猝死**的主要原因之一。

??? question "8. 慢性支气管炎、肺气肿、慢性肺心病的发展过程是什么？"
    **答案：** 这是 **一个疾病连续发展的过程**：
    - **慢支**（反复咳嗽、咳痰）→ 长期炎症 → 支气管壁破坏
    - **肺气肿**（呼吸困难、桶状胸）→ 终末细支气管远端弹性减退 → 过度膨胀
    - **慢性肺心病**（右心衰竭）→ 长期缺氧 + 肺动脉高压 → 右心室肥大、衰竭
    
    **记忆：** 慢支 → 肺气肿 → 肺心病 = "肺病三联征"。
