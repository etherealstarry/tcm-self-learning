# ⏰ 考研时间规划指南

> 考研是"持久战"——需要长期坚持，不能"三天打鱼，两天晒网"。本章提供**保姆级**的考研时间规划指导。

---

## 🎯 考研时间线（以2026年12月考研为例）

### 完整时间线

| 时间 | 事件 | 说明 |
|------|------|------|
| 2025年3-6月 | 打基础 | 把教材过一遍 |
| 2025年7-8月 | 强化 | 刷真题，做错题本 |
| 2025年9-11月 | 冲刺 | 做套卷，模拟考试 |
| 2025年12月 | 考前 | 复习错题，调整心态 |
| 2025年12月底 | 考研初试 | 全国统一考试 |
| 2026年2-3月 | 出成绩 + 复试 | 准备复试 |
| 2026年4-5月 | 录取 | 等录取通知书 |

> **❗ 重要提醒**：考研是"持久战"，需要**长期坚持**。
> 不能"三天打鱼，两天晒网"。

💡 **生活例子**：
考研就像"马拉松"——距离长（备考时间长），需要合理分配体力（时间规划），才能跑完全程。

## 📅 每日时间规划（保姆级）

### 在校考生（大三下学期、大四上学期）

| 时间 | 任务 |
|------|------|
| 6:30-7:00 | 起床，洗漱，吃早餐 |
| 7:00-8:00 | 背单词（英语） |
| 8:00-12:00 | 上课（如果有课）/ 复习（如果没课） |
| 12:00-13:00 | 午餐 + 午休 |
| 13:00-17:00 | 上课（如果有课）/ 复习（如果没课） |
| 17:00-18:00 | 晚餐 |
| 18:00-22:00 | 复习（黄金时间！） |
| 22:00-23:00 | 洗漱，准备睡觉 |
| 23:00 | 睡觉 |

> **❗ 重要提醒**：晚上18:00-22:00是"黄金时间"，要充分利用。

---

### 在职考生（毕业工作后考研）

| 时间 | 任务 |
|------|------|
| 6:30-7:00 | 起床，洗漱，吃早餐 |
| 7:00-8:00 | 背单词（英语） |
| 8:00-17:00 | 上班 |
| 17:00-18:00 | 晚餐 |
| 18:00-22:00 | 复习（黄金时间！） |
| 22:00-23:00 | 洗漱，准备睡觉 |
| 23:00 | 睡觉 |

> **❗ 重要提醒**：在职考生时间紧，要**利用碎片时间**（通勤时间、午休时间）。

💡 **生活例子**：
在职考研就像"兼职"——白天上班，晚上复习，时间紧，要高效利用。

### 全职考生（毕业未工作，全职考研）

| 时间 | 任务 |
|------|------|
| 6:30-7:00 | 起床，洗漱，吃早餐 |
| 7:00-8:00 | 背单词（英语） |
| 8:00-11:30 | 复习（上午时段，模拟考研时间） |
| 11:30-13:00 | 午餐 + 午休 |
| 13:00-17:00 | 复习（下午时段，模拟考研时间） |
| 17:00-18:00 | 晚餐 |
| 18:00-22:00 | 复习（晚上时段） |
| 22:00-23:00 | 洗漱，准备睡觉 |
| 23:00 | 睡觉 |

> **❗ 重要提醒**：全职考生时间充裕，但容易"假努力"（坐在书桌前，但心不在焉）。
> 要**高效学习**，而不是"磨时间"。

## ⚠️ 临床意义（红旗警告）

⚠️ **时间规划**要合理，不要"假努力"。

⚠️ **劳逸结合**，每周至少休息半天。

⚠️ **不要熬夜**，保持良好睡眠。

⚠️ **不要给自己太大压力**，调整好心态。

💡 **生活例子**：
考研时间规划就像"长跑"——既要合理分配体力（时间规划），又要劳逸结合（休息），才能跑完全程。

## 📝 自测习题

??? question "考研时间规划中，最重要的是？"
    A. 每天复习时间越长越好
    B. 合理分配时间，劳逸结合
    C. 只复习中医综合，其他不管
    D. 只复习英语和政治，中医综合不管
    E. 熬夜复习，争分夺秒
    
    ??? success "答案"
        正确答案：B
        
        **解析：**
        - **合理分配时间，劳逸结合**：最重要，不能"假努力"，也不能" burnout"
        - A选项（每天复习时间越长越好）：错误，效率比时间更重要
        - C选项（只复习中医综合，其他不管）：错误，每科都要复习
        - D选项（只复习英语和政治，中医综合不管）：错误，中医综合分值最高，最重要
        - E选项（熬夜复习，争分夺秒）：错误，熬夜伤身体，效率也低

    A. 早上6:00-8:00
    B. 上午8:00-12:00
    C. 下午14:00-17:00
