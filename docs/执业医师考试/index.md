## 🎯 不同基础，怎么备考？

### 类型A：基础好（在校成绩前20%）
!!! success "备考策略"
    - **备考时间**：6个月（每天4-6小时）
    - **复习节奏**：快速过一遍教材 → 刷题 → 模拟考试
    - **重点**：刷题 + 模拟考试（适应考试节奏）
    
    **时间安排**：
    - 第1-2个月：快速过一遍教材（每天2-3章）
    - 第3-4个月：刷真题（每天50-100题）
    - 第5-6个月：模拟考试 + 查漏补缺（每周1次模拟考）

### 类型B：基础中等（在校成绩中等）
!!! success "备考策略"
    - **备考时间**：9-12个月（每天3-4小时）
    - **复习节奏**：系统复习教材 → 刷题 → 模拟考试
    - **重点**：系统复习教材（别只顾刷题）
    
    **时间安排**：
    - 第1-6个月：系统复习教材（按[备考规划](执业医师考试/备考规划.md)）
    - 第7-9个月：刷真题（每天30-50题）
    - 第10-12个月：模拟考试 + 查漏补缺（每周1次模拟考）

### 类型C：基础差（在校成绩后20%，或毕业多年）
!!! success "备考策略"
    - **备考时间**：12-18个月（每天2-3小时）
    - **复习节奏**：从头学 → 系统复习 → 刷题 → 模拟考试
    - **重点**：从头学（别指望短时间突击）
    
    **时间安排**：
    - 第1-6个月：从头学教材（按[零基础规划](学习规划/零基础入门规划.md)）
    - 第7-12个月：系统复习教材（按[备考规划](执业医师考试/备考规划.md)）
    - 第13-18个月：刷真题 + 模拟考试

## 📝 备考三阶段

### 第一阶段：系统复习（6个月）
!!! example "任务"
    - 按[备考规划](执业医师考试/备考规划.md)，系统复习14门考试科目
    - 配合教材（第10版）+ [各科目复习指南](执业医师考试/各科目复习指南.md)
    - 每章学完，做**章节练习题**（20-30题）
    
    !!! tip "第一阶段重点"
        - **理解 > 背诵**：理解了才能灵活运用
        - **教材是根本**：别只看辅导书，不读教材
        - **做笔记**：用Obsidian整理知识网络

### 第二阶段：刷题（3个月）
!!! example "任务"
    - 刷[历年真题](执业医师考试/历年真题.md)（按年份刷）
    - 刷模拟题（每天50-100题）
    - **整理错题**（用Anki）
    
    !!! tip "第二阶段重点"
        - **错题必须整理**：错题是你的"提分点"
        - **定期复习错题**：用Anki管理错题
        - **刷题速度**：提高答题速度（考试时间紧）

### 第三阶段：模拟考试（3个月）
!!! example "任务"
    - 每周1次**全真模拟考试**（按考试时间：上午2小时，下午2小时）
    - 查漏补缺（重点复习错题 + 高频考点）
    - 调整心态（别紧张，正常发挥）
    
    !!! tip "第三阶段重点"
        - **适应考试节奏**：考试时间紧，必须提高答题速度
        - **查漏补缺**：重点复习错题 + 高频考点
        - **调整心态**：别紧张，正常发挥

## 💡 备考建议（避坑指南）

!!! danger "误区1：只刷题，不复习教材"
    **错误做法**：只看真题，不系统复习教材。
    
    **后果**：考试题型会变，只刷真题 = 碰运气。
    
    **正确做法**：先系统复习教材，再刷题。

!!! danger "误区2：不整理错题"
    **错误做法**：刷完题，对完答案，就不管了。
    
    **后果**：同一个坑，掉进去两次。
    
    **正确做法**：错题必须整理，并且**定期复习**（用Anki）。

!!! danger "误区3：临时抱佛脚"
    **错误做法**：考前3个月才开始复习。
    
    **后果**：时间不够，复习不系统，通过率低。
    
    **正确做法**：提前**12个月**开始备考（基础差的，提前18个月）。

!!! danger "误区4：忽视西医部分"
    **错误做法**：只复习中医部分，不复习西医部分。
    
    **后果**：西医部分占60分，忽视 = 少60分。
    
    **正确做法**：西医部分也要复习（但不用追求高分，拿40-50分即可）。

!!! danger "误区5：不模拟考试"
    **错误做法**：只刷题，不模拟考试。
    
    **后果**：考试时节奏掌握不好，时间不够。
    
    **正确做法**：考前3个月，每周1次全真模拟考试。
