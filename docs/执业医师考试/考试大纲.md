# 执业医师考试大纲

!!! danger "重要提醒"
    执业医师资格考试**通过率约30-40%**，不是那么容易过的。
    
    必须**系统复习**，不能靠运气。
    
    本页提供**考试大纲**，帮你明确考试范围。

---

## 📋 考试结构

### 考试形式
| 部分 | 形式 | 时间 | 分值 |
|------|------|------|------|
| 实践技能考试 | 实操 + 面试 | 约30分钟/人 | 100分（60分合格） |
| 医学综合笔试 | 计算机化考试（单选） | 上午2小时 + 下午2小时 | 600分（360分合格） |

!!! warning "必须两部分都过"
    实践技能考试**不过** → 不能参加笔试。
    笔试**不过** → 明年重来（技能成绩保留1年）。

### 笔试科目及分值
| 科目 | 分值 | 题型 | 备注 |
|------|------|------|------|
| 中医基础理论 | 50分 | A1/A2/B1 | 基础，必须拿高分 |
| 中医诊断学 | 50分 | A1/A2/B1 | 基础，必须拿高分 |
| 中药学 | 50分 | A1/A2/B1 | 记忆量大 |
| 方剂学 | 50分 | A1/A2/B1 | 记忆量大 |
| 中医内科学 | 150分 | A1/A2/A3/A4 | **重中之重**，占一半分值 |
| 中医外科学 | 50分 | A1/A2/A3/A4 | 重点 |
| 中医妇科学 | 50分 | A1/A2/A3/A4 | 重点 |
| 中医儿科学 | 50分 | A1/A2/A3/A4 | 重点 |
| 针灸学 | 50分 | A1/A2/B1 | 重点 |
| 西医诊断学 | 30分 | A1/A2/B1 | 西医部分，不能忽视 |
| 西医内科学 | 30分 | A1/A2/A3/A4 | 西医部分，不能忽视 |
| 卫生法规 | 10分 | A1/B1 | 背一下就行 |
| 医学伦理 | 10分 | A1/B1 | 背一下就行 |

!!! success "分值分析"
    - **中医内科学**占150分（四分之一！）→ 必须重点复习
    - **基础科目**（中基、中诊、中药、方剂）占200分 → 必须拿高分（简单）
    - **西医科目**（诊断、内科学）占60分 → 不能忽视，但不用追求高分

## 📚 各科目考试大纲

### 1. 中医基础理论（50分）

#### 考试内容
!!! example "考试范围"
    - 绪论：中医学的学科属性、理论体系的形成与发展
    - 中医学的哲学基础：阴阳学说、五行学说
    - 藏象学说：五脏、六腑、奇恒之腑
    - 气血津液：气、血、津液的关系
    - 体质学说：9种体质
    - 病因学说：六淫、七情、饮食劳逸、痰饮瘀血
    - 发病学说：发病原理、发病类型
    - 病机学说：邪正盛衰、阴阳失调、气血津液失常
    - 防治原则：治未病、治则（扶正祛邪、调整阴阳……）

#### 复习重点
!!! tip "复习建议"
    - **阴阳学说**：理解阴阳的关系（对立制约、互根互用……）
    - **五行学说**：理解五行的相生相克（但别纠结"为什么肝属木"）
    - **藏象学说**：**重点中的重点**！必须理解每个脏腑的功能
    - **气血津液**：理解气、血、津液的关系
    - **病因学说**：**重点**！理解六淫、七情……

#### 备考策略
!!! success "备考心法"
    - 这一科**很简单**，必须拿**45+分**
    - 复习方法：理解 > 背诵
    - 刷题：章节练习题 + 历年真题

---

### 2. 中医诊断学（50分）

#### 考试内容
!!! example "考试范围"
    - 望诊：全身望诊、局部望诊、望排泄物、望小儿指纹
    - 闻诊：听声音、嗅气味
    - 问诊：一般项目、主诉、现病史、既往史、个人史、家族史
    - 切诊：脉诊、按诊
    - 八纲辨证：阴阳、表里、寒热、虚实
    - 气血津液辨证：气病、血病、津液病辨证
    - 脏腑辨证：五脏六腑辨证

#### 复习重点
!!! tip "复习建议"
    - **望诊**：重点学**望神**、**望色**、**望舌**
    - **问诊**：**重点**！必须背**十问歌**
    - **脉诊**：理解28种病脉（但只考常见脉）
    - **八纲辨证**：**基础**！必须理解**寒热、虚实、表里、阴阳**
    - **脏腑辨证**：**重点中的重点**！必须掌握五脏六腑的辨证

#### 备考策略
!!! success "备考心法"
    - 这一科**很简单**，必须拿**45+分**
    - 复习方法：理解 + 背诵（十问歌、脏腑辨证要点）
    - 刷题：章节练习题 + 历年真题

    - 泻下药：攻下药、润下药、峻下逐水药
    - 祛风湿药：祛风寒湿药、祛风湿热药、祛风湿强筋骨药
    - 化湿药
    - 利水渗湿药
    - 温里药
    - 理气药
    - 消食药
    - 驱虫药
    - 止血药
    - 活血化瘀药
    - 化痰止咳平喘药
    - 安神药
    - 平肝息风药
    - 开窍药
    - 补虚药：补气药、补阳药、补血药、补阴药
    - 收涩药
    - 涌吐药
    - 解毒杀虫燥湿止痒药
    - 拔毒化腐生肌药

#### 复习重点
!!! tip "复习建议"
    - **解表药**：麻黄、桂枝、紫苏、生姜、香薷、荆芥、防风、羌活、白芷、细辛……
    - **清热药**：石膏、知母、栀子、夏枯草、黄芩、黄连、黄柏、龙胆草……
    - **补虚药**：人参、黄芪、白术、甘草、当归、熟地、白芍、何首乌……
    
    !!! warning "中药学，记忆量大"
        400+味中药，必须**理解 + 背诵**。
        
        推荐方法：
        1. 理解药性（四气五味、归经）
        2. 用Anki背诵（见[记忆工具指南](学习工具/记忆工具.md)）
        3. 配合《药性赋》背诵

#### 备考策略
!!! success "备考心法"
    - 这一科**记忆量大**，争取拿**40+分**
    - 复习方法：理解 + 背诵（Anki）
    - 刷题：章节练习题 + 历年真题

### 5. 中医内科学（150分）—— 重中之重！

#### 考试内容
!!! example "考试范围"
    - 肺系病证：感冒、咳嗽、哮病、喘证、肺胀、肺痈、肺痨……
    - 心系病证：心悸、胸痹、不寐、癫狂、痫病……
    - 脾胃系病证：胃痛、痞满、呕吐、噎膈、呃逆、腹痛、泄泻、便秘……
    - 肝胆系病证：胁痛、黄疸、积聚、臌胀、头痛、眩晕、中风……
    - 肾系病证：水肿、淋证、癃闭、腰痛……
    - 气血津液病证：郁证、血证、痰饮、消渴、自汗盗汗……
    - 肢体经络病证：痹证、痿证、痉证、颤证……

#### 复习重点
!!! tip "复习建议"
    - **每个病**，必须掌握：
        1. 诊断要点
        2. 辨证要点
        3. 治疗原则
        4. **分证论治**（哪个证型用哪个方？）→ **最重要！**
    
    !!! warning "中医内科学，是重中之重！"
        占150分（四分之一！），必须**重点复习**。
        
        推荐方法：
        1. 每个病，把**分证论治**整理成表格
        2. 用Anki背诵（见[记忆工具指南](学习工具/记忆工具.md)）
        3. 刷题：章节练习题 + 历年真题

#### 备考策略
!!! success "备考心法"
    - 这一科**占150分**，必须拿**120+分**
    - 复习方法：理解 + 背诵（分证论治）
    - 刷题：章节练习题 + 历年真题 + 模拟题

### 9. 针灸学（50分）

#### 考试内容
!!! example "考试范围"
    - 经络腧穴学：十二正经、奇经八脉、常用腧穴
    - 针灸治疗学：各科疾病的针灸辨证论治

#### 复习重点
!!! tip "复习建议"
    - **经络走向**：十二正经的走向，要记住
    - **常用腧穴**：360+个穴位，重点记**常用穴**（100+个）
    - **针灸治疗**：每个病，主穴 + 配穴是什么？
    
    !!! warning "针灸学，记忆量大"
        经络走向 + 腧穴定位 + 针灸处方，都要记。

#### 备考策略
!!! success "备考心法"
    - 这一科，争取拿**40+分**
    - 复习方法：理解 + 背诵（经络、腧穴、处方）
    - 刷题：章节练习题 + 历年真题

### 10-11. 西医诊断学、西医内科学（各30分）

#### 考试内容
!!! example "考试范围"
    - **西医诊断学**：症状诊断、体格检查、辅助检查
    - **西医内科学**：常见病（冠心病、高血压、糖尿病……）的诊断和治疗

#### 复习重点
!!! tip "复习建议"
    - **西医诊断学**：重点学**体格检查**（心肺听诊、腹部触诊……）
    - **西医内科学**：重点学**常见病**的诊断标准
    
    !!! warning "西医部分，不能忽视"
        占60分，忽视 = 少60分。
        
        但不用追求高分，拿**40-50分**即可。

#### 备考策略
!!! success "备考心法"
    - 这两科，争取每科拿**20+分**
    - 复习方法：理解（不用死记硬背）
    - 刷题：章节练习题 + 历年真题
