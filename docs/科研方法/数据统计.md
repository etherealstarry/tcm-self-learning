# 📊 数据统计

> 数据统计是科研的"分析工具"——数据收集好了，要靠统计方法来分析。本章提供**保姆级**的数据统计指导。

---

## 🎯 数据统计概况

### 为什么需要数据统计？

**原因**：
- 科研数据都是**杂乱无章**的
- 需要统计方法来**分析规律**
- 需要统计方法来**验证假设**

**常用统计软件**：
| 软件 | 优点 | 缺点 |
|------|------|------|
| SPSS | 界面友好，易学 | 功能相对有限 |
| R语言 | 功能强大，免费 | 学习曲线陡 |
| SAS | 功能强大，医药行业金标准 | 昂贵，难学 |
| Stata | 计量经济学常用 | 功能相对有限 |

> **建议**：初学者用**SPSS**，进阶用**R语言**。

💡 **生活例子**：
数据统计就像"做菜"——有了食材（数据），还要会做菜（统计方法），才能做出美味佳肴（分析结果）。

## 📋 统计方法选择（保姆级）

### 计量资料（连续变量）

| 方法 | 用途 | 例子 |
|------|------|------|
| t检验 | 两组比较 | 治疗组 vs 对照组（疼痛VAS评分） |
| 方差分析（ANOVA） | 多组比较 | 治疗组1 vs 治疗组2 vs 对照组 |
| 配对t检验 | 自身前后比较 | 治疗前 vs 治疗后 |
| 相关分析 | 两个变量相关性 | 年龄 vs 疼痛VAS评分 |
| 回归分析 | 预测因变量 | 用年龄、性别预测疼痛VAS评分 |

---

### 计数资料（分类变量）

| 方法 | 用途 | 例子 |
|------|------|------|
| 卡方检验 | 两组比较 | 治疗组 vs 对照组（有效率） |
| Fisher精确检验 | 小样本卡方检验 | 样本量<40时 |
| Logistic回归 | 预测二分类因变量 | 用年龄、性别预测是否有效 |

---

### 等级资料（有序分类变量）

| 方法 | 用途 | 例子 |
|------|------|------|
| 秩和检验 | 两组比较 | 治疗组 vs 对照组（疗效等级） |
| 单向有序Logistic回归 | 预测有序因变量 | 用年龄、性别预测疗效等级 |

> **❗ 重要提醒**：**方法选错，结果就错**。
> 一定要根据数据类型选择合适的统计方法。

💡 **生活例子**：
统计方法选择就像"选工具"——拧螺丝要用螺丝刀，锤钉子要用锤子，工具选错了，活就干不好。

## 📊 SPSS操作（保姆级）

### 数据录入

**步骤**：
1. 打开SPSS，进入"数据视图"
3. 定义变量（"变量视图"）
4. 录入数据

**变量定义**：
| 变量名 | 类型 | 标签 |
|---------|------|------|
| ID | 数值 | 病例编号 |
| group | 数值 | 分组（1=治疗组，2=对照组） |
| pain_pre | 数值 | 治疗前疼痛VAS评分 |
| pain_post | 数值 | 治疗后疼痛VAS评分 |

---

### 计量资料分析（t检验）

**步骤**：
1. **分析** → **比较均值** → **独立样本t检验**
2. 将`group`放入"分组变量"，将`pain_post`放入"检验变量"
3. 定义组（1=治疗组，2=对照组）
4. 点击"确定"

**结果解读**：
- **Levene检验**：检验方差齐性（P>0.05 = 方差齐）
- **t检验结果**：P<0.05 = 有统计学差异

---

### 计数资料分析（卡方检验）

**步骤**：
1. **分析** → **描述统计** → **交叉表**
2. 将`group`放入"行"，将`effect`放入"列"
3. 点击"统计"，勾选"卡方"
4. 点击"确定"

**结果解读**：
- **卡方值**：越大越好
- **P值**：P<0.05 = 有统计学差异

## 📈 R语言操作（保姆级）

### 安装R和RStudio

**步骤**：
1. 下载R（https://www.r-project.org/）
2. 下载RStudio（https://www.rstudio.com/）
3. 安装R，再安装RStudio

---

### 数据录入

**代码**：
```r
# 创建数据框
data <- data.frame(
  ID = 1:20,
  group = rep(c(1, 2), each = 10),
  pain_pre = rnorm(20, mean = 60, sd = 10),
  pain_post = rnorm(20, mean = 40, sd = 10)
)

# 查看数据
View(data)
```

---

### 计量资料分析（t检验）

**代码**：
```r
# 独立样本t检验
t.test(pain_post ~ group, data = data)

# 配对t检验
t.test(data$pain_pre, data$pain_post, paired = TRUE)
```

---

### 计数资料分析（卡方检验）

**代码**：
```r
# 创建列联表
table <- table(data$group, data$effect)

# 卡方检验
chisq.test(table)
```

## ⚠️ 临床意义（红旗警告）

⚠️ **统计方法用错**，会导致研究结果错误。

⚠️ **P值不是万能的**，还要看效应量（effect size）。

⚠️ **统计显著性 ≠ 临床显著性**。
   - 统计显著性：P<0.05
   - 临床显著性：疗效是否足够大，是否有临床意义

⚠️ **数据造假**是严重的科研不端行为。

💡 **生活例子**：
统计方法用错就像"用螺丝刀锤钉子"——工具选错了，活就干不好，甚至可能搞破坏。

## 📝 自测习题

??? question "下列哪种情况应该用t检验？"
    A. 两组有效率比较
    B. 两组疼痛VAS评分比较
    C. 两组疗效等级比较
    D. 两个变量相关性分析
    E. 预测因变量
    
    ??? success "答案"
        正确答案：B
        
        **解析：**
        - **t检验**：用于两组计量资料（连续变量）比较
        - A选项（两组有效率比较）：应该用卡方检验（计数资料）
        - C选项（两组疗效等级比较）：应该用秩和检验（等级资料）
        - D选项（两个变量相关性分析）：应该用相关分析
        - E选项（预测因变量）：应该用回归分析
        
        **相关知识点：**
        - [统计方法选择](../科研方法/数据统计.md)
        - [SPSS操作](../科研方法/数据统计.md)

??? question "P<0.05表示？"
    A. 有临床显著性
    B. 有统计显著性
    C. 结果一定正确
    D. 结果一定有意义
    E. 以上都不对
    
    ??? success "答案"
        正确答案：B
        
        **解析：**
        - **P<0.05**：表示有统计显著性（结果不太可能是偶然的）
        - A选项（有临床显著性）：不一定，还要看效应量
        - C选项（结果一定正确）：不一定，统计显著性 ≠ 结果正确
        - D选项（结果一定有意义）：不一定，还要看临床意义
