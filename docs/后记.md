## 🌿 写在本指南之后

当这本指南的框架逐渐成型，回过头看，这条中医学习之路，道阻且长，行则将至。

## 💭 为什么要写这本指南？

这个问题的答案，要追溯到我开始学习中医的那一天。

那时候的我，面对着：

- 一本本厚重的教材，不知道从何读起
- 老师上课讲得快，笔记记不全，课后不知道怎么复习
- 想找优质的网课资源，却淹没在信息洪流中
- 读《黄帝内经》，每个字都认识，连在一起却不懂
- 面对执业医师资格考试，不知道怎么规划复习

我相信，每一个中医学子，都曾经历过这样的迷茫时刻。

**这本指南，就是想为后来的你，做一盏灯。**

## 🤝 如何参与贡献？

本指南采用 MIT 协议开源，欢迎每一位中医学子参与贡献！

### 你可以贡献什么？

- 🐛 **发现错误**：教材版本更新了、某个知识点写错了、链接失效了……
- ✍️ **补充内容**：你的课程笔记、学习方法、跟诊心得……
- 🔗 **推荐资源**：优质的网课、参考书目、数据库使用方法……
- 💡 **提出建议**：对网站结构、内容排版的改进建议……

### 如何提交贡献？

1. **Fork 本仓库**
2. **创建你的分支** (`git checkout -b feature/AmazingFeature`)
3. **提交你的修改** (`git commit -m 'Add some AmazingFeature'`)
4. **推送到分支** (`git push origin feature/AmazingFeature`)
5. **提交 Pull Request**

> 具体贡献规范，参见 [CONTRIBUTING.md](CONTRIBUTING.md)（待创建）

## 📜 关于内容的准确性

本指南尽力确保内容的准确性，但中医之学，博大精深，且各家学说并存，难免有疏漏之处。

- 如果发现有**事实性错误**（比如某个中药的功效写错了），请直接提 Issue 或 PR 修正
- 如果涉及**学术观点争议**（比如某个方剂的君臣佐使配伍有不同见解），我们会在文中标注"各家观点"，并尽量呈现不同流派的说法
- 本指南**不能替代教材和老师的授课**，请务必以教材和课堂内容为准
