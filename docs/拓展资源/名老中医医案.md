# 名老中医医案

!!! tip "为什么要读医案？"
    读医案是中医学习最重要的**第二课堂**。
    
    - 教材教你"规范"，医案教你"灵活"
    - 教材给你"标准答案"，医案给你"辨证思路"
    - 教材是"死"的，医案是"活"的
    
    很多名老中医的临床经验，教材里根本没有，只有从医案里学。

---

## 📖 怎么读医案？

!!! example "读医案的正确姿势"
    ### 第一步：先自己辨证
    看到病案，先盖住答案，**自己想**：
    - 这个病人是什么证？
    - 如果是你，会开什么方？
    
    ### 第二步：对比名医思路
    再看名医的辨证和处方，**对比差异**：
    - 哪里我想错了？
    - 名医的思路高明在哪里？
    
    ### 第三步：总结规律
    读完10个类似病案后，**总结规律**：
    - 这个病，名医常用什么方？
    - 什么情况下加减什么药？

    !!! warning "别只看方子"
        只抄方子不思考 = 买椟还珠。
        
        方子是"果"，辨证思路才是"因"。

## 🔍 蒲辅周医案精选（学习示例）

### 医案一：感冒（风寒束表）
!!! quote "原案"
    **患者**：男，32岁
    
    **症状**：恶寒发热，无汗，头痛，四肢酸痛，鼻塞流清涕，舌苔薄白，脉浮紧。
    
    **辨证**：风寒束表，卫阳被遏。
    
    **治法**：辛温解表，宣肺散寒。
    
    **处方**：麻黄汤加味。
    
    麻黄6g，桂枝9g，杏仁9g，甘草3g，防风6g，荆芥6g
    
    水煎服，嘱覆被取微汗。
    
    一剂而愈。

!!! success "蒲老思路解析"
    - **为什么用麻黄汤**？—— 恶寒+无汗+脉浮紧 = 太阳伤寒表实证，正合麻黄汤
    - **为什么加防风、荆芥**？—— 增强疏风解表之力，防风"风药中之润剂"，荆芥"风药中之血药"
    - **为什么强调"微汗"**？—— 汗出太多会伤阳气，微微汗出即可祛邪
    
    !!! tip "自学要点"
        这个案子很简单，但很**典型**。
        
        自学时，要能**背下来**这个辨证思路：
        
        恶寒+无汗+脉浮紧 → 太阳伤寒表实证 → 麻黄汤
        
        以后遇到类似病人，你就能**条件反射**地想到麻黄汤。

## 🔍 刘渡舟医案精选（学习示例）

### 医案二：柴胡汤证（少阳病）
!!! quote "原案"
    **患者**：女，28岁
    
    **症状**：往来寒热，胸胁苦满，心烦喜呕，口苦咽干，目眩，舌苔薄白，脉弦。
    
    **辨证**：少阳病，柴胡汤证。
    
    **治法**：和解少阳。
    
    **处方**：小柴胡汤原方。
    
    柴胡12g，黄芩9g，人参6g，半夏9g，甘草6g，生姜9g，大枣4枚
    
    三剂，水煎服。
    
    服药后，寒热退，胸胁舒，呕止。

!!! success "刘老思路解析"
    - **为什么是小柴胡汤**？—— 往来寒热+胸胁苦满+心烦喜呕+口苦咽干 = **少阳病四大症**，100% 符合小柴胡汤证
    - **为什么用人参**？—— 少阳病"血弱气尽，腠理开，邪气因入"，正气已虚，用人参扶正祛邪
    - **为什么不加不减**？—— 证典型，无需加减，**方证对应**即可
    
    !!! tip "自学要点"
        这个案子教会我们：**方证对应**的重要性。
        
        当病人的症状**完全符合**某个方的适应证时，不要乱加减，原方即可。
        
        很多初学者喜欢"炫技"，动不动就加减十几味药，反而效果不好。

## 🔍 邓铁涛医案精选（学习示例）

### 医案三：脾胃虚寒（胃痛）
!!! quote "原案"
    **患者**：男，45岁
    
    **症状**：胃脘隐痛，喜温喜按，纳差，乏力，大便溏薄，舌淡胖，苔白，脉沉细。
    
    **辨证**：脾胃虚寒。
    
    **治法**：温中健脾。
    
    **处方**：黄芪建中汤加味。
    
    黄芪30g，桂枝9g，白芍18g，炙甘草6g，生姜9g，大枣4枚，饴糖30g（烊化），党参15g，白术12g
    
    七剂，水煎服。
    
    二诊：胃痛减，纳增，原方续进七剂而愈。

!!! success "邓老思路解析"
    - **为什么用黄芪建中汤**？—— 胃痛+喜温喜按+纳差+乏力+舌淡胖 = **脾胃虚寒**，黄芪建中汤温中健脾，比小建中汤益气更强
    - **为什么重用黄芪**？—— 邓老善用人参、黄芪补气，这里黄芪用30g，补气力强
    - **为什么加党参、白术**？—— 增强健脾益气之力，四君子汤之意
    
    !!! tip "自学要点"
        这个案子展示了**脏腑辨证**的思路：
        
        胃痛+喜温喜按 → 病位在脾 → 舌淡胖+脉沉细 → 病性为虚寒 → 脾胃虚寒证
        
        自学时，要**先定病位，再定病性**，这是脏腑辨证的核心。

## 📝 怎么整理医案笔记？

!!! example "推荐格式"
    ```markdown
    ## 医案来源：XXX医案
    ## 患者：男/女，XX岁
    ## 主诉：......
    ## 症状：......
    ## 辨证：......
    ## 治法：......
    ## 处方：......
    ## 我的思考：......
    ## 名医高明之处：......
    ## 可借鉴之处：......
    ```
    
    重点是**"我的思考"**和**"可借鉴之处"**这两部分。
    
    只有写出来，才是真的懂了。
