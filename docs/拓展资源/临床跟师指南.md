# 临床跟师指南

!!! tip "为什么要跟师？"
    中医是**师傅带徒弟**传承下来的。
    
    - 教材是"共性"，跟师学的是"个性"
    - 很多名老中医的**独门绝技**，书里根本找不到
    - 跟师能学到**辨证思路**、**用药心得**、**医患沟通**……
    
    一句话：**跟师 = 抄近路**。

---

## 🎯 跟师能学到什么？

!!! example "跟师的收获"
    ### 1. 辨证思路
    同一个病，不同老师的辨证角度可能完全不同。
    
    比如**胃痛**：
    - 老师A：从肝论治（肝气犯胃）
    - 老师B：从脾论治（脾胃虚寒）
    - 老师C：从瘀论治（久病入络）
    
    跟师，就是学会**从多个角度看病**。
    
    ### 2. 用药心得
    教材里的方子是"标准版"，临床要**灵活加减**。
    
    比如**补中益气汤**，老师可能：
    - 加积壳 → 升清降浊
    - 加丹参 → 益气活血
    - 去当归 → 患者便溏
    
    这些**加减规律**，只有跟师才能学到。
    
    ### 3. 医患沟通
    名医的**气场**、**沟通方式**，是影响疗效的重要因素。
    
    跟师，也是学**怎么做一个好医生**。

## 🔍 怎么找到跟师机会？

!!! example "找跟师机会的方法"
    ### 方法1：主动联系本校老师
    **最适合**：大一～大三
    
    步骤：
    1. 先去听这个老师的课，觉得讲得好
    2. 课后主动找老师，说："老师，我想跟您抄方，可以吗？"
    3. 老师一般会答应——中医老师都愿意带学生
    
    !!! tip "怎么让老师愿意带你？"
        - **态度诚恳**：别嬉皮笑脸
        - **主动做事**：帮忙整理病历、抄方，别光看不动手
        - **有准备**：跟师前，先复习相关章节，不然听不懂
    
    ### 方法2：申请附属医院实习
    **最适合**：大四、大五
    
    步骤：
    1. 联系附属医院的科室主任
    2. 说明来意：想见习，不拿津贴，纯学习
    3. 一般都会接收
    
    ### 方法3：参加名老中医传承班
    **最适合**：大三～大五
    
    很多中医院校有**名老中医传承班**，专门跟师学习。
    
    关注学校教务处通知。

## 📝 跟师时怎么学习？

!!! example "跟师学习法"
    ### 第一步：抄方（最基础）
    把老师的处方**一字不差**地抄下来。
    
    包括：
    - 病人主诉
    - 老师辨证
    - 处方（药名、剂量）
    - 老师口头讲解（如果有）
    
    !!! warning "抄方注意事项"
        - **字迹工整**：别事后自己都看不懂
        - **写日期**：方便以后整理
        - **标注特殊之处**：比如老师特意加了某味药，为什么？
    
    ### 第二步：整理医案（每周一次）
    每周把抄的方子**整理成医案**。
    
    格式：
    ```markdown
    ## 日期：202X年X月X日
    ## 老师：XXX
    ## 患者：男/女，XX岁
    ## 主诉：......
    ## 辨证：......
    ## 处方：......
    ## 我的疑问：......
    ## 老师解答：......
    ```
    
    ### 第三步：复盘（每月一次）
    每月把整理的医案**复盘一遍**。
    
    问自己：
    - 这个月跟的老师，最常用什么方？
    - 什么情况下会加减某味药？
    - 有没有什么**独门绝技**？
    
    ### 第四步：应用（实习阶段）
    实习时，**试着用老师的思路**给自己管床的病人开方。
    
    当然要经过老师审核，别自己乱开。
    
    但只有**亲自用过**，才是真的学会了。

## 💡 跟师注意事项

!!! warning "跟师的规矩"
    ### 1. 守时
    老师出诊，你迟到 = 不尊重。
    
    ### 2. 勤快
    别光坐着看，要**主动做事**：
    - 帮忙整理病历
    - 帮忙叫号
    - 帮忙打扫诊室
    
    ### 3. 谦虚
    别在老师面前**炫耀**自己懂多少。
    
    跟师就是来学习的，不是来展示的。
    
    ### 4. 保密
    老师的**独门经验**，别到处乱说。
    
    这是对老师的尊重，也是**职业道德**。

## 🌠 跟师案例分享

### 案例：跟师学"调肝法"
!!! quote "学生分享"
    我跟的是一位擅长**从肝论治**的老中医。
    
    刚开始不懂：为什么**胃痛**也调肝？为什么**月经不调**也调肝？
    
    跟了半年才明白：老师认为**百病生于气**，肝主疏泄，情志因素在现代疾病中占比很高。
    
    所以，老师的很多方子里，都有**柴胡、白芍、郁金**这些疏肝药。
    
    现在我自己临床，也学会了**从肝论治**，效果很好。

## 🎯 给你的任务

!!! task "跟师任务"
    ### 任务1：本学期内联系一位老师（大一、大二）
    主动找一位你喜欢的老师，申请跟师抄方。
    
    **别怕被拒绝**——中医老师一般都愿意带学生。
    
    ### 任务2：坚持跟师1学期（大二、大三）
    选定一位老师，**跟满1学期**。
    
    别跟了两次就放弃，那样学不到东西。
    
    ### 任务3：整理跟师医案（长期任务）
    把跟师抄的方子，**全部整理成医案**。
    
    这是你未来临床的**宝贵财富**。
