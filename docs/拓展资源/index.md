## 🌐 常用在线资源导航

### 视频课程平台
- **B站（哔哩哔哩）**：搜索"中医基础""黄帝内经"等关键词，有大量优质课程
- **中国大学MOOC**：各大中医药大学的在线课程
- **学堂在线**：清华大学发起的MOOC平台

### 古籍文献数据库
- **中国知网（CNKI）**：学术论文检索（需机构账号）
- **万方数据库**：学位论文、会议论文
- **维普资讯**：中文期刊全文数据库
- **PubMed**：国际医学文献数据库（英文）
- **中医古籍数据库**（待补充具体名称）

### 实用工具
- **中医通APP**：中药、方剂查询
- **大家中医APP**：经络穴位、方剂查询
- **杏林求真APP**：中医学习社区

## 🔍 如何高效利用拓展资源

:::tip 资源使用建议
1. **精选优于泛读**：不要贪多，选1-2个优质资源深入学习
2. **配合教材使用**：拓展资源是辅助，不能替代教材
3. **做笔记！**：看视频也要做笔记，否则看完就忘
4. **定期复习**：用Anki等工具定期回顾拓展知识点
:::
