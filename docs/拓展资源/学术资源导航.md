# 学术资源导航

!!! tip "为什么要用好学术资源？"
    中医不能只靠**老经验**，也要**现代研究**。
    
    - 了解**最新研究进展**：中药的现代药理、针灸的神经机制……
    - 提升**科研能力**：写论文、申课题，都需要查文献
    - 开阔**国际视野**：中医在全球的发展，用英文怎么表达？
    
    本页汇总**高质量学术资源**，帮你快速找到需要的文献。

## 📚 中文数据库

### 1. 中国知网（CNKI）
- **网址**：https://www.cnki.net
- **用途**：查中文学术论文、学位论文、会议论文
- **优点**：收录最全，更新最快
- **怎么用**：
    - 注册账号（学校一般有购买，免费使用）
    - 搜索时，用**主题词**，不用自然语言
    - 比如：搜"黄芪 心肌梗死"，别搜"黄芪治疗心肌梗死有效吗"

### 2. 万方数据库
- **网址**：https://www.wanfangdata.com.cn
- **用途**：查中文学术论文、学位论文
- **优点**：医药类文献收录较全
- **和CNKI的区别**：CNKI收录更全，万方医学类更强

### 3. 维普数据库
- **网址**：http://www.cqvip.com
- **用途**：查中文学术论文
- **优点**：自然科学类文献较强

### 4. 中医世家
- **网址**：http://www.zysj.com.cn
- **用途**：在线读中医古籍、现代中医著作
- **优点**：免费，古籍收录全
- **怎么用**：适合查古籍原文，比如《黄帝内经》某句话的原文

## 🌐 英文数据库

### 1. PubMed
- **网址**：https://pubmed.ncbi.nlm.nih.gov
- **用途**：查生物医学英文文献
- **优点**：全球最权威的生物医学数据库
- **怎么用**：
    - 搜索用英文关键词，比如："Astragalus membranaceus myocardial infarction"
    - 用**MeSH词**搜索更准确（比如：搜索"Heart Failure"而不是"Cardiac Failure"）

### 2. Cochrane Library
- **网址**：https://www.cochranelibrary.com
- **用途**：查系统评价（Systematic Review）
- **优点**：循证医学最高等级证据
- **怎么用**：想了解某个中医疗法的**证据强度**，先查Cochrane

### 3. Web of Science
- **网址**：https://www.webofscience.com
- **用途**：查高影响力英文文献，查引用情况
- **优点**：可以看某篇论文被引用了多少次，判断影响力

### 4. Google Scholar（谷歌学术）
- **网址**：https://scholar.google.com
- **用途**：免费查中英文学术文献
- **优点**：免费，收录范围广
- **缺点**：质量参差不齐，需要自己筛选

## 🔍 文献检索技巧

!!! example "怎么高效查文献？"
    ### 技巧1：用主题词（Mesh词）搜索
    PubMed 用 **MeSH词** 搜索更准确。
    
    比如：
    - 不用 "Heart Failure"，用 MeSH 词 "Heart Failure"
    - 不用 "Acupuncture"，用 MeSH 词 "Acupuncture Therapy"
    
    ### 技巧2：用布尔逻辑（AND、OR、NOT）
    - **AND**：缩小范围。比如："黄芪 AND 心肌梗死"
    - **OR**：扩大范围。比如："黄芪 OR 黄耆"
    - **NOT**：排除。比如："黄芪 NOT 食疗"
    
    ### 技巧3：用限定词（Filters）
    PubMed 可以限定：
    -  publication date（发表时间）
    -  Article type（文章类型：Review、Clinical Trial…）
    -  Species（物种：Human、Rat…）
    
    ### 技巧4：追踪引用文献
    找到一篇好文章，**看它的参考文献**（ backward search）
    再看**谁引用了它**（ forward search，Google Scholar 可以查）
    
    !!! tip "推荐查文献流程"
        1. 先查 **Cochrane Library**，了解系统评价
        2. 再查 **PubMed**，了解最新研究
        3. 中文文献查 **CNKI**
        4. 追踪参考文献，扩充文献库

## 🧰 文献管理工具

### 1. EndNote
- **优点**：功能强大，支持插入参考文献
- **缺点**：收费，贵
- **适合**：写毕业论文、申基金

### 2. Zotero
- **优点**：免费，好用，浏览器插件方便
- **缺点**：功能不如EndNote强大
- **适合**：日常文献管理

### 3. Mendeley
- **优点**：免费，有社交功能
- **缺点**：被Elsevier收购后，体验下降
- **适合**：初学者

!!! tip "推荐用 Zotero"
    免费、好用、插件丰富。
    
    学生党首选。
