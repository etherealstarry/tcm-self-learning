# 中医APP推荐

!!! tip "为什么要用中医APP？"
    中医学习需要**随时查阅**：
    
    - 突然想不起某个中药的功效 → 马上查
    - 遇到一个穴位定位不清楚 → 马上查
    - 碎片时间想刷题 → 马上打开
    
    中医APP就是你的**移动小助手**。

---

## 📱 必备APP（推荐安装）

### 1. 大家中医
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **功能**：查中药、查方剂、查穴位、查医案
    - **优点**：界面清爽，内容权威，完全免费
    - **缺点**：暂无
    - **适合人群**：全阶段
    
    !!! example "怎么用？"
        - **学中药时**：随时查性味归经、功效主治
        - **学方剂时**：随时查组成、功效、主治
        - **学针灸时**：随时查穴位定位、主治

### 2. 中医通
!!! success "推荐指数：⭐⭐⭐⭐⭐"
    - **功能**：刷题、背考点、执业医师考试题库
    - **优点**：题库全，适合考试
    - **缺点**：部分功能需付费
    - **适合人群**：大三及以上（准备考试）
    
    !!! example "怎么用？"
        - **碎片时间**：每天刷20题
        - **考前冲刺**：执业医师考试前，刷完题库

### 3. 针灸推拿
!!! success "推荐指数：⭐⭐⭐⭐"
    - **功能**：查穴位定位、针灸处方、推拿手法
    - **优点**：有3D穴位图，直观
    - **缺点**：部分穴位图不够精确
    - **适合人群**：学针灸推拿的学生
    
    !!! example "怎么用？"
        - **学经络腧穴时**：配合教材，看3D穴位图
        - **学针灸治疗时**：查针灸处方

### 4. CNKI 手机APP
!!! success "推荐指数：⭐⭐⭐⭐"
    - **功能**：查学术论文
    - **优点**：随时查文献
    - **缺点**：下载论文需付费（学校购买除外）
    - **适合人群**：大三及以上（写论文、做科研）
    
    !!! example "怎么用？"
        - **写论文时**：随时查文献
        - **做科研时**：查相关研究的进展

### 5. 中医古籍
!!! success "推荐指数：⭐⭐⭐"
    - **功能**：在线读中医古籍
    - **优点**：免费，古籍收录全
    - **缺点**：界面较老
    - **适合人群**：学中医经典的学生
    
    !!! example "怎么用？"
        - **学《黄帝内经》时**：随时查原文
        - **学《伤寒论》时**：随时查原文

## 🎯 不同阶段的APP使用策略

### 大一、大二（基础阶段）
!!! example "你的任务"
    - **安装大家中医**：随时查中药、方剂
    - **碎片时间**：用大家中医背歌诀（有背诵功能）
    
    !!! warning "别贪多"
        大一、大二还是以**教材为主**，APP是辅助工具。

### 大三、大四（临床入门）
!!! example "你的任务"
    - **安装中医通**：开始刷题，准备执业医师考试
    - **安装大家中医**：学临床课程时，随时查方子
    
    !!! tip "刷题技巧"
        每天刷20题，坚持一学期，执业医师考试轻松过。

### 大五（实习阶段）
!!! example "你的任务"
    - **安装CNKI**：写毕业论文，查文献
    - **安装大家中医**：实习时，随时查方子、查穴位

## 💡 使用APP的注意事项

!!! danger "误区1：只看APP，不背教材"
    APP是**查阅工具**，不是**学习工具**。
    
    中药的性味归经、方剂的组成功效，**必须背教材**，不能只靠APP查。

!!! danger "误区2：贪多，装一堆APP"
    装10个APP = 等于没装。
    
    选1-2个适合自己的，**深耕**。

!!! danger "误区3：盲目相信APP内容"
    APP内容也可能有错误。
    
    遇到疑问，**以教材、权威著作为准**。
