# 学习规划 —— 中医学生（本科/研究生）

!!! tip "这份规划是给你的"
    你是**中医专业学生**，正在中医药大学就读。
    
    这份规划帮你：
    - **配合学校课程**，深化理解
    - **避免常见坑**（比如：只背书，不临床）
    - **高效备考**（执业医师、考研）
    - **早临床、多临床**，毕业就能看病
    
    按这份规划走，5年下来你会比同龄人**强很多**。

## 📖 大一：打基础 {#大一打基础}

### 学年目标
- 理解**中医核心概念**（阴阳、五行、脏腑、气血津液……）
- 掌握**辨证论治**的基本思路
- 培养**中医思维**

### 上学期（第1学期）

=== "核心课程：中医基础学"
    **学校安排**：一般是第1学期
    
    **配合本网站**：
    1. 先听老师讲课（**教材是根本**）
    2. 课后读[《中医基础学》](必修课程/中医基础/中医基础学.md)对应章节
    3. 重点看**生活例子**和**临床意义**
    4. 做**自测题**，检验掌握程度
    
    **每周安排**：
    - 周一：听老师讲第X章
    - 周三：读本网站对应章节（深化理解）
    - 周五：做自测题 + 复习
    - 周日：复盘本周学习，标记不懂的地方
    
    !!! success "大一上学期结束，你能做到"
        - 理解阴阳、五行的核心概念
        - 能给自己做简单辨证（比如：你是阳虚还是阴虚？）
        - 能看懂中成药的说明书

=== "拓展学习：培养兴趣"
    **推荐书**：《中医入门》（印会河）
    
    **怎么读**：
    - 通读1遍（培养"中医感觉"）
    - 别强求懂所有内容
    
    **碎片时间**：
    - 背《药性赋》（部分内容）
    - 听中医基础视频（B站）

### 下学期（第2学期）

=== "核心课程：中医诊断学"
    **学校安排**：一般是第2学期
    
    **配合本网站**：
    1. 先听老师讲课（**教材是根本**）
    2. 课后读[《中医诊断学》](必修课程/中医基础/中医诊断学.md)对应章节
    3. 重点看**四诊操作**和**辨证思路**
    4. 做**自测题**，检验掌握程度
    
    **每周安排**：同上
    
    !!! success "大一结束，你能做到"
        - 掌握四诊的基本操作（望、闻、问、切）
        - 掌握八纲辨证、脏腑辨证的基本思路
        - 能给自己和家人做简单辨证

=== "拓展学习：早临床"
    **寒暑假**：
    - 去附属医院**见习**（哪怕只是看）
    - 观察医生怎么**问诊**、怎么**辨证**
    
    !!! tip "早临床的重要性"
        很多大一学生觉得"我还什么都不会，见习干嘛？"
        
        **错了！**
        
        早临床 = 早培养"中医感觉"。
        你看医生怎么问诊、怎么辨证，哪怕不懂，也会在脑子里留下印象。
        
        大三学临床时，你会突然明白："哦，原来当时那个医生是这么辨证的！"

## 📖 大二：学中药方剂 {#大二学中药方剂}

### 学年目标
- 认识**400+味中药**（功效、主治）
- 认识**300+首方剂**（组成、功效、主治）
- 开始**背歌诀**（《药性赋》、《汤头歌诀》）

### 上学期（第3学期）

=== "核心课程：中药学"
    **学校安排**：一般是第3学期
    
    **配合本网站**：
    1. 先听老师讲课（**教材是根本**）
    2. 课后读[《中药学》](必修课程/中药方剂/中药学.md)对应章节
    3. 重点记**功效**和**主治**
    4. 用**Anki**背（见[记忆工具指南](学习工具/记忆工具.md)）
    
    **每周安排**：
    - 周一、三、五：学新内容（各30-40分钟）
    - 周二、四、六：复习 + Anki 背中药
    - 周日：复盘
    
    !!! success "大二上学期结束，你能做到"
        - 认识200+味中药
        - 能看懂中医处方（大概）

=== "记忆工具：Anki"
    **安装Anki**：见[记忆工具指南](学习工具/记忆工具.md)
    
    **制作卡片**：
    - 一个中药 = 一张卡片
    - 正面：中药名 → 背面：功效、主治
    
    **每天复习**：
    - 新卡片：每天10-20张
    - 复习卡片：Anki自动安排

### 下学期（第4学期）

=== "核心课程：方剂学"
    **学校安排**：一般是第4学期
    
    **配合本网站**：
    1. 先听老师讲课（**教材是根本**）
    2. 课后读[《方剂学》](必修课程/中药方剂/方剂学.md)对应章节
    3. 重点记**组成**、**功效**、**主治**
    4. 用**Anki**背
    
    **每周安排**：同上
    
    !!! success "大二结束，你能做到"
        - 认识300+首方剂
        - 能看懂中医处方（组成、功效）
        - 能给自己推荐中成药（安全前提下）

=== "拓展学习：读医案"
    **推荐书**：《名老中医医案集》
    
    **怎么读**：
    - 每个医案先**自己辨证**
    - 再对比**名医思路**
    - 做笔记（见[病案研读方法](拓展资源/病案研读方法.md)）
    
    !!! warning "大二读医案，别贪多"
        能读懂30-50个医案，已经很厉害了。
        
        重点是**理解辨证思路**，不是背方子。

## 📖 大三：学临床 + 经典 {#大三学临床经典}

### 学年目标
- 掌握**常见病**的辨证论治
- 读完**中医四大经典**（至少选读）
- **跟师学习**，学临床经验

### 上学期（第5学期）

=== "核心课程：中医内科学"
    **学校安排**：一般是第5学期
    
    **配合本网站**：
    1. 先听老师讲课（**教材是根本**）
    2. 课后读[《中医内科学》](必修课程/临床课程/中医内科学.md)对应章节
    3. 重点看**辨证论治**
    4. 做**自测题**
    
    **每周安排**：
    - 周一、三、五：学新病（各40-50分钟）
    - 周二、四、六：复习 + 读医案
    - 周日：复盘
    
    !!! success "大三上学期结束，你能做到"
        - 掌握50+种常见病的辨证论治
        - 能给自己和家人做简单诊疗（养生层面）

=== "跟师学习：争取跟诊机会"
    **怎么找跟师机会**：见[临床跟师指南](拓展资源/临床跟师指南.md)
    
    **跟师学什么**：
    - 辨证思路
    - 用药心得
    - 医患沟通
    
    !!! tip "跟师的重要性"
        教材是"共性"，跟师学的是"个性"。
        
        很多名老中医的临床经验，教材里根本没有，只有跟师才能学到。

### 下学期（第6学期）

=== "核心课程：中医外科学、妇科学、儿科学"
    **学校安排**：一般是第6学期
    
    **配合本网站**：
    1. 先听老师讲课
    2. 课后读[《中医外科学》](必修课程/临床课程/中医外科学.md)、[《中医妇科学》](必修课程/临床课程/中医妇科学.md)、[《中医儿科学》](必修课程/临床课程/中医儿科学.md)
    3. 重点看**常见病**的辨证论治
    
    **每周安排**：同上

=== "中医经典：开始读四大经典"
    **推荐顺序**：
    1. 《黄帝内经》→ 先读（理论基础）
    2. 《伤寒论》→ 再读（临床基础）
    3. 《金匮要略》→ 选读
    4. 《温病条辨》→ 选读
    
    **配合本网站**：
    - [《黄帝内经研读指南》](必修课程/中医经典/黄帝内经研读指南.md)
    - [《伤寒论研读指南》](必修课程/中医经典/伤寒论研读指南.md)
    - [《金匮要略研读指南》](必修课程/中医经典/金匮要略研读指南.md)
    - [《温病条辨研读指南》](必修课程/中医经典/温病条辨研读指南.md)
    
    !!! warning "大三读经典，别强求全懂"
        选读重点篇目即可。
        
        读不懂？→ 配合白话解一起读。

## 📖 大四：实习前冲刺 {#大四实习前冲刺}

### 学年目标
- **临床见习**：多去附属医院见习
- **跟师学习**：坚持跟师，整理医案
- **备考执业医师**：开始复习（见[执业医师考试](执业医师考试/index.md)）

### 全年安排

=== "临床见习：多去附属医院"
    **怎么安排时间**：
    - 没课的时候，去附属医院**见习**
    - 看医生怎么**问诊**、怎么**辨证**、怎么**开方**
    
    !!! tip "见习时的正确姿势"
        1. **多看**：看医生怎么看病
        2. **多问**：不懂就问（别怕丢脸）
        3. **多记**：把看到的、听到的记下来
        
        别只顾着**抄方**——抄方是学徒做的事，你要学的是**思路**。

=== "跟师学习：坚持跟师"
    **每周至少1次**：
    - 跟师抄方
    - 整理医案（见[病案研读方法](拓展资源/病案研读方法.md)）
    
    **整理医案**：
    - 把跟师抄的方子，整理成医案
    - 这是你未来临床的**宝贵财富**

=== "备考执业医师：开始复习"
    **第4学期开始复习**：
    - 配合[《执业医师考试》](执业医师考试/index.md)板块
    - 系统复习14门考试科目
    
    !!! warning "别等大五才备考"
        大四就要开始复习！
        
        大五实习很忙，没时间系统复习。

## 📖 大五：实习 + 备考 {#大五实习备考}

### 学年目标
- **临床实习**：在附属医院各科轮转
- **通过执业医师资格考试**
- **准备考研**（如果考的话）

### 上学期（第9学期）

=== "临床实习：全職实习"
    **实习安排**：
    - 在附属医院各科轮转（内科、外科、妇科、儿科……）
    - 管床病人（在老师指导下）
    
    **实习时的正确姿势**：
    1. **多管床**：主动管病人，别怕累
    2. **多问老师**：不懂就问
    3. **多整理**：把管床病人的诊疗过程整理成医案
    
    !!! danger "实习最重要的不是"学技术""
        **而是学"临床思维"**！
        
        技术可以后面学，但临床思维必须**实习时建立**。

=== "备考执业医师：系统复习"
    **配合[《执业医师考试》](执业医师考试/index.md)板块**：
    - 系统复习14门考试科目
    - 刷题（每天20-30题）
    - 模拟考试（每周1次）

### 下学期（第10学期）

=== "临床实习：继续实习"
    **同上**

=== "备考执业医师：冲刺"
    **考前3个月**：
    - 刷题 + 整理错题
    - 模拟考试
    - 查漏补缺
    
    !!! success "大五结束，你能做到"
        - 通过**执业医师资格考试**
        - 有基本的**临床能力**（能独立看简单病）
        - 整理了一堆**医案**（未来临床的"弹药库"）

## 💡 给中医专业学生的建议

!!! tip "学习心法"
    1. **教材是根本**：别只看课外书，教材才是考试的重点
    2. **理解 > 背诵**：理解了才能灵活运用，死记硬背考试完就忘
    3. **早临床、多临床**：别等大五才实习，大三就要跟师、见习
    4. **跟师的重要性**：教材是"共性"，跟师学的是"个性"
    5. **别贪多**：把一门学精，胜过门门都懂一点

!!! danger "最常见的坑"
    - **坑1**：只背书，不临床 → 纸上谈兵
    - **坑2**：只临床，不背书 → 考试挂科
    - **坑3**：贪多，什么书都想读 → 最后哪本都没读完
    - **坑4**：不跟师 → 毕业了还不会看病（因为教材里没有临床经验）
