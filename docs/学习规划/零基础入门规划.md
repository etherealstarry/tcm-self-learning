# 学习规划 —— 零基础入门

!!! tip "这份规划是给你的"
    如果你**完全零基础**，不是中医专业，想自学中医。
    
    这份规划帮你：
    - 明确**每年学什么**
    - 明确**每周学多少**
    - 明确**怎么学、重点是什么**
    - 明确**学了怎么用**
    
    按这份规划走，2-3年你能做到：
    - 给自己和家人做**简单辨证**（阳虚还是阴虚？风寒还是风热？）
    - 看懂中成药的**说明书**（功效、主治）
    - 用中医思维**指导养生**

---

## 📅 总体时间规划（2-3年）

| 阶段 | 时间 | 核心任务 | 每天时间 |
|------|------|---------|-----------|
| [第1年：打基础](#第1年打基础) | 12个月 | 学完中医基础学、中医诊断学 | 1-2小时 |
| [第2年：学中药方剂](#第2年学中药方剂) | 12个月 | 学完中药学、方剂学 | 1-2小时 |
| [第3年：学经典+实践](#第3年学经典实践) | 12个月 | 读黄帝内经、读医案、实践 | 1-2小时 |

!!! warning "别贪多"
    零基础自学，**坚持 > 速度**。
    
    每天1-2小时，坚持3年 > 每天10小时，坚持1个月就放弃。

## 📖 第1年：打基础 {#第1年打基础}

### 学习目标
- 理解**中医核心概念**（阴阳、五行、脏腑、气血津液……）
- 学会**简单辨证**（阳虚 vs 阴虚，风寒 vs 风热）
- 看懂中成药的**说明书**

### 学习安排（12个月）

=== "第1-3个月：中医基础学（第1-4章）"
    **学习内容**：
    - 中医学的学科属性
    - 中医学理论体系的形成与发展
    - 中医学理论体系的特点（整体观念、辨证论治）
    - 阴阳学说
    
    **每周安排**：
    - 周一、三、五：学新内容（各30-40分钟）
    - 周二、四、六：复习 + 做自测题（各20-30分钟）
    - 周日：休息 or 补漏
    
    **学习方法**：
    1. 先读教材（或本网站的[《中医基础学》](必修课程/中医基础/中医基础学.md)）
    2. 重点看**生活例子**和**临床意义**
    3. 做**自测题**，检验掌握程度
    4. 不懂的地方，**标记下来**，后续重点学
    
    **自测标准**：
    - 自测题得分 **≥ 80分** → 过关，进入下一章
    - 自测题得分 **< 80分** → 回头重学，直到过关
    
    !!! example "第1个月具体计划"
        ```markdown
        ## 第1周：中医学的学科属性 + 理论体系形成与发展
        - 周一：读第1章（30分钟）
        - 周三：读第2章（30分钟）
        - 周五：复习第1-2章 + 做自测题（40分钟）
        - 周日：复盘本周学习，标记不懂的地方
        
        ## 第2周：整体观念
        - 周一：读第3章第1节（30分钟）
        - 周三：读第3章第2节（30分钟）
        - 周五：复习 + 做自测题（40分钟）
        - 周日：复盘
        
        ......
        ```

=== "第4-6个月：中医基础学（第5-8章）"
    **学习内容**：
    - 五行学说
    - 藏象学说
    - 气血津液
    
    **每周安排**：同上
    
    **学习重点**：
    - **五行学说**：理解相生相克，但别纠结"为什么肝属木"——先接受，后面会慢慢理解
    - **藏象学说**：**重点中的重点**！必须理解每个脏腑的功能
    - **气血津液**：理解气、血、津液的关系
    
    !!! warning "藏象学说，必须理解！"
        这一章学不好 = 后面全懵。
        
        必须做到：
        - 心主血脉、肺主气……每个脏腑功能都**背下来**
        - 五脏、六腑、奇恒之腑的区别 → 理解
        - 脏腑之间的关系 → 理解
        
        如果这章学不懂，**别往下学**！回头重学，直到懂了再往下。

=== "第7-9个月：中医基础学（第9-12章）"
    **学习内容**：
    - 经络学说
    - 体质学说
    - 病因学说
    - 发病学说
    
    **每周安排**：同上
    
    **学习重点**：
    - **经络学说**：不要求背所有经络走向，但**十二正经名称、走向**要记住
    - **体质学说**：理解9种体质的特点，能给自己辨证
    - **病因学说**：**重点**！理解六淫、七情、饮食劳逸……
    
    !!! tip "给自己辨证（实践！）"
        学完体质学说 + 病因学说后，**给自己辨证**：
        
        你是阳虚？阴虚？痰湿？气虚？
        
        不懂？→ 翻书，或百度搜"中医体质测试"。

=== "第10-12个月：中医诊断学"
    **学习内容**：
    - 四诊（望、闻、问、切）
    - 辨证（八纲辨证、脏腑辨证……）
    
    **每周安排**：同上
    
    **学习重点**：
    - **四诊**：重点学**望诊**和**问诊**（切诊需要实践，自学很难）
    - **辨证**：**八纲辨证**是基础，必须理解**寒热、虚实、表里、阴阳**
    
    !!! success "第1年结束，你能做到"
        - 感冒了，能分清楚是**风寒**还是**风热**
        - 家人问你"我这是什么体质"，你能说出个大概
        - 能看懂中成药的说明书（功效、主治）

## 📖 第2年：学中药方剂 {#第2年学中药方剂}

### 学习目标
- 认识**100味常用中药**（功效、主治）
- 认识**50首常用方剂**（组成、功效、主治）
- 看懂中医处方（医生开的方子，你能看懂大概）

### 学习安排（12个月）

=== "第1-4个月：中药学"
    **学习内容**：
    - 解表药
    - 清热药
    - 泻下药
    - 祛风湿药
    - 化湿药
    - 利水渗湿药
    - 温里药
    - 理气药
    - 消食药
    - 驱虫药
    - 止血药
    - 活血化瘀药
    - 化痰止咳平喘药
    - 安神药
    - 平肝息风药
    - 开窍药
    - 补虚药
    - 收涩药
    
    **每周安排**：
    - 周一、三、五：学新内容（各30-40分钟）
    - 周二、四、六：复习 + 用Anki背中药（各20-30分钟）
    - 周日：休息 or 补漏
    
    **学习方法**：
    1. 读教材（或本网站的[《中药学》](必修课程/中药方剂/中药学.md)）
    2. 重点记**功效**和**主治**
    3. 用**Anki**背（见[记忆工具指南](学习工具/记忆工具.md)）
    4. 每天背**3-5味中药**，别贪多
    
    !!! warning "中药学，别死记硬背！"
        理解了才能记住。
        
        比如：**黄芪** 为什么能"补气升阳"？
        → 因为黄芪色黄，味甘，入脾经，脾主肌肉，所以能补气。
        
        理解后，自然就记住了。

=== "第5-8个月：方剂学"
    **学习内容**：
    - 解表剂
    - 清热剂
    - 泻下剂
    - 和解剂
    - 温里剂
    - 表里双解剂
    - 补益剂
    - 安神剂
    - 开窍剂
    - 固涩剂
    - 理气剂
    - 理血剂
    - 治风剂
    - 治燥剂
    - 祛湿剂
    - 祛痰剂
    - 消食剂
    - 驱虫剂
    
    **每周安排**：同上
    
    **学习方法**：
    1. 读教材（或本网站的[《方剂学》](必修课程/中药方剂/方剂学.md)）
    2. 重点记**组成**、**功效**、**主治**
    3. 用**Anki**背
    4. 每天背**2-3首方剂**，别贪多
    
    !!! tip "方剂学，要理解方解"
        方解 = 为什么这个方子用这些药？
        
        比如：**补中益气汤**
        - 黄芪 → 君药，补中益气
        - 人参、白术、炙甘草 → 臣药，补气健脾
        - 当归 → 佐药，补血
        - 陈皮 → 佐药，理气
        - 升麻、柴胡 → 使药，升阳举陷
        
        理解了方解，才能灵活运用。

=== "第9-12个月：复习 + 实践"
    **学习内容**：
    - 复习中药学（重点药）
    - 复习方剂学（重点方）
    - 实践：给自己和家人**推荐中成药**（安全前提下）
    
    **每周安排**：
    - 周一、三、五：复习中药（各30-40分钟）
    - 周二、四、六：复习方剂 + 实践（各30-40分钟）
    - 周日：休息
    
    !!! success "第2年结束，你能做到"
        - 看到处方，能看懂**大概**（比如：这个方子是治感冒的，那个是治胃痛的）
        - 能给自己和家人**推荐中成药**（安全前提下）
        - 感冒了，能选对**感冒清热颗粒**还是**银翘解毒丸**

## 📖 第3年：学经典 + 实践 {#第3年学经典实践}

### 学习目标
- 理解中医**核心思想**（阴阳五行、脏腑经络）
- 学会**读医案**，理解名医辨证思路
- 有**中医思维**（遇到健康问题，会从阴阳、脏腑角度思考）

### 学习安排（12个月）

=== "第1-3个月：黄帝内经选读"
    **学习内容**：
    - 素问·上古天真论
    - 素问·四气调神大论
    - 素问·阴阳应象大论（选段）
    - 灵枢·经脉（选段）
    
    **每周安排**：
    - 周一、三、五：读《黄帝内经》（各30-40分钟）
    - 周二、四、六：复习 + 做笔记（各20-30分钟）
    - 周日：休息
    
    **学习方法**：
    1. 读[《黄帝内经研读指南》](必修课程/中医经典/黄帝内经研读指南.md)
    2. 配合**白话解**一起读（比如：《黄帝内经白话解》）
    3. 做笔记，用自己的话总结
    
    !!! warning "《黄帝内经》很难懂"
        别强求全部读懂。
        
        选读**重点篇目**即可。
        
        读不懂？→ 跳过，读白话解，懂个大概就行。

=== "第4-6个月：读医案"
    **学习内容**：
    - 读《名老中医医案集》
    - 每周读**2-3个医案**
    
    **每周安排**：
    - 周一、三、五：读医案（各30-40分钟）
    - 周二、四、六：整理医案笔记（各20-30分钟）
    - 周日：休息
    
    **学习方法**：
    1. 先**自己辨证**（盖住答案）
    2. 再对比**名医思路**
    3. 做笔记，写**我的思考**和**可借鉴之处**
    
    !!! tip "读医案，别只看方子"
        方子是"果"，辨证思路才是"因"。
        
        重点学**为什么这么辨**，**为什么这么治**。

=== "第7-12个月：实践 + 复习"
    **学习内容**：
    - 给自己和家人**简单辨证**（阳虚 vs 阴虚……）
    - 给自己和家人**推荐中成药**（安全前提下）
    - 复习前两年学的内容
    
    **每周安排**：
    - 周一、三、五：实践（给自己/家人辨证）（各30-40分钟）
    - 周二、四、六：复习（各20-30分钟）
    - 周日：休息
    
    !!! success "第3年结束，你能做到"
        - 有**中医思维**（遇到健康问题，会从阴阳、脏腑角度思考）
        - 能给自己和家人做**简单的健康指导**（养生层面）
        - 能看懂中医科普文章，并判断是否正确

## 💡 零基础自学，最重要的5件事

### 1. 别贪多
!!! tip "每天1-2小时，坚持3年 > 每天10小时，坚持1个月就放弃"
    零基础自学，**坚持 > 速度**。
    
    别想着"3个月学完中医"——那不可能。
    
    按这份规划走，2-3年你能打下坚实基础。

### 2. 理解 > 背诵
!!! tip "理解了才能记住，死记硬背考试完就忘"
    比如：**黄芪** 为什么能"补气升阳"？
    
    理解了（黄芪色黄→入脾经→脾主肌肉→补气），才能记住。
    
    死记硬背（黄芪→补气升阳），很快就忘。

### 3. 边学边用
!!! tip "学了就要用，不然等于没学"
    比如：
    - 学完**阴阳学说** → 给自己辨证：我是阳虚还是阴虚？
    - 学完**中药学** → 感冒了，选对中成药
    - 学完**医案** → 给家人试试辨证
    
    !!! warning "安全第一"
        别给自己乱开药！
        
        中成药也要谨慎，按说明书服用。

### 4. 定期复习
!!! tip "每周复盘，每月总复习"
    - **每周日**：复盘本周学习，标记不懂的地方
    - **每月末**：总复习本月学的内容，用思维导图梳理知识框架
    
    不复习 = 学完就忘，等于没学。

### 5. 别怕慢
!!! tip "慢 = 快，快 = 慢"
    中医理论体系独特，初期会有"玄学"感，这很正常。
    
    坚持学完**中医基础学**和**中医诊断学**后，你会突然"开窍"。
    
    别急，慢慢来。
