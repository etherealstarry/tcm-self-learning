# 文献管理工具 —— Zotero 使用指南

!!! tip "为什么要管理文献？"
    到了大三、大四，你要：
    
    - 写课程论文 → 需要引用文献
    - 做科研 → 需要读大量文献
    - 写毕业论文 → 需要管理几十篇甚至上百篇文献
    
    没有文献管理工具 = **手动插参考文献，累死**。
    
    Zotero 帮你**一键抓取文献、一键插入参考文献**。

---

## 📚 什么是 Zotero？

Zotero 是一款**免费开源**的文献管理软件。

!!! success "核心功能"
    - **一键抓取**：浏览器里看到论文，点一下就导入
    - **一键插入**：Word 里写论文，点一下就插入参考文献
    - **自动生成**：参考文献列表自动生成，格式随心换
    - **多端同步**：电脑、手机、平板都能用

---

## 🔍 Zotero 下载安装

### 官方网站
- **网址**：https://www.zotero.org
- **价格**：基础功能完全免费（存储300MB）；扩容需付费

### 安装步骤
1. 去官网下载 Zotero（对应你的系统：Windows/Mac/Linux）
2. 安装**浏览器插件**（Zotero Connector）—— 一键抓取文献用
3. 注册 Zotero 账号（用于多端同步）

!!! warning "存储空间不够怎么办？"
    - 方案A：付费扩容（ cheapest：$20/年，2GB）
    - 方案B：用**第三方存储**（比如：WebDAV 自己搭，或者用 Zotero 中文社区提供的存储）
    - 方案C：只存**文献条目**（不存PDF），PDF 自己管理

## 🎯 怎么用 Zotero 管理中中医文献？

### 第一步：一键抓取文献

!!! example "从 CNKI 抓取文献"
    1. 打开 CNKI，搜索"黄芪 心肌梗死"
    2. 点浏览器右上角的 **Zotero Connector 图标**
    3. 选择要导入的文献 → 确定
    4. 文献自动导入 Zotero
    
    !!! tip "抓取时选对字段"
        - **Author**：作者（注意：CNKI 的作者名可能有乱码，要手动修正）
        - **Year**：发表年份
        - **Journal**：期刊名
        - **DOI**：如果有，填上（方便别人引用你的论文）

### 第二步：整理文献（用标签、集合）

!!! example "用集合（Collection）分类"
    在 Zotero 左侧，创建集合：
    
    ```
    中医研究
    ├── 中药研究
    │   ├── 黄芪
    │   ├── 丹参
    │   └── ……
    ├── 针灸研究
    │   ├── 疼痛
    │   ├── 中风
    │   └── ……
    └── 临床研究
        ├── 冠心病
        ├── 糖尿病
        └── ……
    ```
    
    然后把文献**拖进对应集合**。

!!! example "用标签（Tag）细分"
    给文献加标签：
    - `#黄芪`
    - `#心肌梗死`
    - `#临床研究`
    - `#机制研究`
    
    然后，点击标签就能**筛选**所有相关文献。

### 第三步：一键插入参考文献（Word 插件）

!!! success "在 Word 里插入参考文献"
    1. 在 Word 里，光标放在要插入引用的位置
    2. 点 Word 菜单栏的 **Zotero** → **Add/Edit Citation**
    3. 搜索文献（作者、年份、标题都可以搜）
    4. 确定 → 引用自动插入
    
    5. 在文末，点 **Zotero** → **Add/Edit Bibliography**
    6. 参考文献列表自动生成！
    
    !!! tip "引用格式（Style）"
        - 中文论文：用 **GB/T 7714** 格式
        - 英文论文：用 **APA**、**Harvard** 等格式
        
        Zotero 里可以**随时切换**格式，不用手动改。

## 📝 Zotero 使用技巧

### 技巧1：抓取时手动修正元数据
!!! danger "CNKI 文献的常见问题"
    - **作者名乱码**：比如"张三"变成"Zhang San"（要手动改回来）
    - **期刊名缩写**：比如"中华中医药杂志"被缩写成"中华中医药"（要补全）
    - **发表日期缺失**：手动填上
    
    建议：**每次抓取后，都手动检查一遍**。

### 技巧2：用"相关文献"功能
!!! success "怎么用？"
    两篇文献相关 → 右键 → **Add Related Item**
    
    比如：
    - 文献A：黄芪治疗心肌梗死的临床研究
    - 文献B：黄芪治疗心肌梗死的机制研究
    
    把A和B关联起来 → 以后看A时，能快速跳到B。

### 技巧3：做笔记（Notes）
!!! example "在 Zotero 里做笔记"
    选中一篇文献 → 右侧 **Notes** → **Add Note**
    
    笔记内容：
    - 研究目的
    - 研究方法
    - 主要结果
    - 我的评价（优点、缺点、可借鉴之处）
    
    !!! tip "笔记同步"
        用 Zotero 做笔记 = **笔记和文献绑定**。
        
        以后看这篇文献，笔记就在旁边，不用到处找。

## 💡 给自学者的建议

!!! tip "Zotero 使用心法"
    1. **从大三开始用**：大一、大二文献不多，用手动管理也行
    2. **抓取后马上整理**：别等攒了100篇再整理，会疯掉
    3. **做笔记**：只存文献不读 = 没存
    4. **选对引用格式**：中文论文用 GB/T 7714，别用 APA

!!! danger "别犯这个错"
    很多人装了 Zotero，**只用来存文献，不读、不做笔记**。
    
    这等于**买椟还珠**。
    
    Zotero 是**管理工具**，不是**收藏工具**。
