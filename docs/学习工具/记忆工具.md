# 记忆工具 —— Anki 使用指南

!!! tip "为什么要用Anki？"
    中医要背的东西太多了：
    
    - 400+ 味中药
    - 300+ 首方剂
    - 361个经穴 + 经外奇穴
    - 无数个证候、病机……
    
    光靠死记硬背 = **效率低、忘得快**。
    
    Anki 用**间隔重复算法**，在你快要忘记的时候提醒你复习，效率翻倍。

---

## 📱 什么是 Anki？

Anki 是一款**基于间隔重复算法**的记忆软件。

!!! success "核心原理"
    - 你刚学完一个知识点 → 1天后复习
    - 复习后记住了 → 3天后再复习
    - 又记住了 → 7天后再复习
    - …… → 逐渐拉长间隔，直到永久记住
    
    这样，你只用复习**快要忘记**的知识点，不用重复已经记住的。

## 🎯 怎么用 Anki 背中医？

### 第一步：制作卡片（最关键！）

!!! example "卡片制作原则"
    **一张卡片 = 一个知识点**
    
    别把"中药学第一章"做成一个卡片——太长了，复习时根本记不住。
    
    **正确做法**：一个中药 = 一张卡片

#### 模板1：中药卡片
!!! quote "卡片示例"
    **正面**：黄芪属于哪一类？有什么功效？
    
    **背面**：
    - 分类：补气药
    - 功效：补气升阳，固表止汗，利水消肿，生津养血，托毒排脓
    - 主治：气虚乏力，食少便溏，中气下陷，久泻脱肛，表虚自汗，气虚水肿，血虚萎黄，痈疽难溃，久溃不敛
    - 用量：9-30g
    - 使用注意：表实邪盛、气滞湿阻、食积内停、阴虚阳亢、痈疽初起或溃后热毒尚盛者忌用

#### 模板2：方剂卡片
!!! quote "卡片示例"
    **正面**：补中益气汤的组成、功效、主治？
    
    **背面**：
    - 组成：黄芪18g，炙甘草9g，人参6g，当归3g，橘皮6g，升麻6g，柴胡6g，白术9g
    - 功效：补中益气，升阳举陷
    - 主治：脾胃气虚证，气虚下陷证，气虚发热证
    - 方解：黄芪补中益气为君；人参、白术、炙甘草补气健脾为臣；当归补血，陈皮理气为佐；升麻、柴胡升阳举陷为使

#### 模板3：穴位卡片
!!! quote "卡片示例"
    **正面**：合谷穴的定位、主治、操作？
    
    **背面**：
    - 定位：在手背，第1、2掌骨间，第2掌骨桡侧的中点处
    - 主治：头痛，目赤肿痛，鼻衄，齿痛，面肿，口眼歪斜，耳聋，痄腮，咽喉肿痛，热病无汗，多汗，腹痛，便秘，经闭，滞产
    - 操作：直刺0.5-1寸，可灸
    - 注意：孕妇禁刺

### 第二步：设置牌组（Deck）

!!! example "推荐牌组结构"
    ```
    中医学习
    ├── 中药学
    │   ├── 补气药
    │   ├── 补血药
    │   └── ……
    ├── 方剂学
    │   ├── 解表剂
    │   ├── 清热剂
    │   └── ……
    ├── 针灸学
    │   ├── 手太阴肺经
    │   ├── 手阳明大肠经
    │   └── ……
    └── 中医基础学
        ├── 阴阳学说
        ├── 五行学说
        └── ……
    ```

    !!! tip "牌组不要分太细"
        太细 = 管理麻烦。
        
        建议：最多分3级（中医学习 → 中药学 → 补气药）。

---

### 第三步：每天复习（坚持！）

!!! success "复习节奏"
    - **新卡片**：每天新增 10-20 张（别贪多！）
    - **复习卡片**：Anki 会自动安排，一般每天 20-40 张
    - **时间**：碎片时间（通勤、排队）就能复习
    
    !!! warning "关键是坚持"
        Anki 不是"用一次就见效"的工具。
        
        必须**每天复习**，坚持一个学期，才能看到效果。

## 📦 现成牌组推荐（不想自己做卡片？）

### 1. 中医世家 Anki 牌组
- **内容**：中药、方剂、穴位
- **获取方式**：搜索"中医世家 Anki"
- **优点**：现成的，直接导入就能用
- **缺点**：可能和你的教材版本不太匹配

### 2. 大家中医 APP 背诵功能
- **内容**：中药、方剂
- **获取方式**：下载大家中医 APP
- **优点**：手机端方便，随时背
- **缺点**：不是 Anki 格式，不能用间隔重复算法

### 3. 自己制作（推荐！）
- **优点**：和自己的教材完全匹配，记忆更深刻
- **缺点**：费时间（但"做卡片"的过程，本身就是记忆）

!!! tip "推荐做法"
    先下载现成牌组**应急**（比如考试前）。
    
    平时**自己制作卡片**——做卡片的过程，就是第一轮记忆。

## 💡 给自学者的建议

!!! tip "Anki 使用心法"
    1. **卡片要简短**：一张卡片 = 一个知识点
    2. **自己做卡片**：做卡片 = 第一轮记忆
    3. **每天坚持复习**：别贪多，每天20-40张即可
    4. **定期清理牌组**：有些卡片永远记不住，说明制作有问题，重新制作
    5. **别依赖现成牌组**：现成牌组是"二手知识"，自己做的才是"一手知识"

!!! danger "Anki 不是万能的"
    Anki 适合背**碎片化知识**（中药功效、方剂组成……）。
    
    但不适合背**系统性知识**（比如"阴阳学说"的整体框架）。
    
    系统性知识，要用**思维导图**来记。
