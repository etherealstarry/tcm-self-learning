# 思维导图工具 —— XMind 使用指南

!!! tip "为什么要画思维导图？"
    中医知识**体系庞大、联系复杂**：
    
    - 学完一章 → 脑子里是一团浆糊
    - 复习时 → 不知道重点在哪里
    - 考前突击 → 东西太多，背不过来
    
    思维导图帮你**把书读薄**：
    - 梳理知识框架
    - 突出重难点
    - 复习时一目了然

---

## 📊 什么是思维导图？

思维导图（Mind Map）是一种**放射性思考**的工具。

!!! success "核心特点"
    - **中心主题**：一张图只有一个核心
    - **分支结构**：从中心向外发散，层级清晰
    - **关键词**：每个节点只写关键词，不写长句
    - **颜色/图标**：区分重点、难点

## 🎯 怎么用思维导图学中醫？

### 用法1：梳理知识框架（预习用）

!!! example "示例：《中医基础学》绪论"
    **中心主题**：中医基础学 绪论
    
    **一级分支**：
    - 中医学的学科属性
    - 中医学理论体系的形成与发展
    - 中医学理论体系的特点
    
    **二级分支**（以"特点"为例）：
    - 整体观念
        - 人是一个有机整体
        - 人与自然环境的统一性
        - 人与社会环境的统一性
    - 辨证论治
        - 同病异治
        - 异病同治
    
    !!! tip "预习时画框架"
        预习新课时，先画一张**知识框架图**。
        
        这样听课时有"地图"，不会迷路。

### 用法2：整理复习提纲（复习用）

!!! example "示例：《方剂学》解表剂"
    **中心主题**：解表剂
    
    **一级分支**：
    - 辛温解表剂
    - 辛凉解表剂
    - 扶正解表剂
    
    **二级分支**（以"辛温解表剂"为例）：
    - 麻黄汤
        - 组成：麻黄、桂枝、杏仁、甘草
        - 功效：发汗解表，宣肺平喘
        - 主治：风寒表实证
    - 桂枝汤
        - 组成：桂枝、芍药、生姜、大枣、甘草
        - 功效：解肌发表，调和营卫
        - 主治：风寒表虚证
    
    !!! success "复习时看导图"
        考前复习，看导图 > 看书。
        
        导图是"骨架"，书是"血肉"。
        先记骨架，再填血肉。

### 用法3：对比相似知识点（理解用）

!!! example "示例：麻黄汤 vs 桂枝汤"
    **中心主题**：麻黄汤 vs 桂枝汤
    
    **左半部分**：麻黄汤
    - 病机：风寒表实
    - 症状：恶寒重，无汗，脉浮紧
    - 组成：麻黄、桂枝、杏仁、甘草
    
    **右半部分**：桂枝汤
    - 病机：风寒表虚
    - 症状：恶风，有汗，脉浮缓
    - 组成：桂枝、芍药、生姜、大枣、甘草
    
    !!! tip "对比记忆更深刻"
        相似的知识点，放一起对比 → 区别更明显，记忆更深刻。

## 📝 思维导图模板推荐

### 模板1：章节复习提纲
```
中心主题：第X章 XXX
├── 重点1
│   ├── 知识点1
│   └── 知识点2
├── 重点2
│   ├── 知识点1
│   └── 知识点2
└── 易考点
    ├── 考点1
    └── 考点2
```

### 模板2：方剂对比
```
中心主题：XXX汤 vs YYY汤
├── XXX汤
│   ├── 组成
│   ├── 功效
│   └── 主治
└── YYY汤
    ├── 组成
    ├── 功效
    └── 主治
```

### 模板3：病证辨证提纲
```
中心主题：胃痛 辨证
├── 实证
│   ├── 寒邪客胃
│   ├── 饮食伤胃
│   ├── 肝气犯胃
│   └── 瘀血停滞
└── 虚证
    ├── 脾胃虚寒
    └── 胃阴不足
```

## 🔧 XMind 使用技巧

### 技巧1：用图标标记重点
!!! success "推荐用法"
    - ⭐ = 重点（必考）
    - ❓ = 不懂（需要再学）
    - ❗ = 易错（考试易错点）
    
    这样复习时，**优先看⭐和❗**。

### 技巧2：用颜色区分模块
!!! example "颜色方案"
    - 红色 = 重点
    - 蓝色 = 理解性内容
    - 绿色 = 记忆性内容
    - 灰色 = 了解即可

### 技巧3：导出图片，随时看
!!! success "怎么用？"
    把导图导出成图片（PNG/JPG）→ 存手机里 → 碎片时间翻看。
    
    比如：等车时，拿出手机看一眼"方剂学解表剂"导图 → 复习效果杠杠的。

## 📊 思维导图 vs 其他工具

| 工具 | 优点 | 缺点 | 适合场景 |
|------|------|------|---------|
| XMind | 功能强大，模板丰富 | 高级功能收费 | 复习提纲、知识框架 |

!!! tip "推荐组合"
    - **电脑端**：XMind（画导图）
    - **手机端**：存图片（随时看）
    - **笔记端**：Obsidian（和笔记联动）

## 💡 给自学者的建议

!!! tip "思维导图使用心法"
    1. **别追求美观**：导图是给自己看的，不是给别人看的
    2. **关键词，不写长句**：一个节点 = 一个关键词
    3. **手绘 > 软件画**：手绘记忆更深刻（时间允许的话）
    4. **定期更新**：学完一章，更新一次导图
    5. **配合 Anki 使用**：导图梳理框架，Anki 记忆细节

!!! danger "别犯这个错"
    很多人画导图，**只顾"画"，不"用"**。
    
    画完就存电脑里吃灰 = 白画。
    
    导图要**打印出来/存手机里，随时看**。
