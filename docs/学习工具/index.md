## 🔧 核心工具详解

### 1. 文献管理：Zotero（强烈推荐 ⭐⭐⭐⭐⭐）

**为什么选 Zotero？**
- 免费、开源
- 浏览器插件一键抓取网页文献
- 支持中文文献元数据（CNKI、万方）
- 与 Word/WPS 无缝集成

**中医学习中的用法：**
```
1. 建立分类文件夹：
   - 中医基础
   - 中医经典
   - 临床各科
   - 毕业论文
2. 每篇文献打标签：#内经 #伤寒 #临床 等
3. 写笔记时直接插入引用
```

### 2. 记忆辅助：Anki（强烈推荐 ⭐⭐⭐⭐⭐）

**为什么用 Anki？**
- 基于艾宾浩斯遗忘曲线，科学复习
- 完全免费（安卓）/ iOS 收费
- 支持图片、音频、LaTeX 公式

**中医学习中的用法：**
```
牌组建议：
- 中药学：正面「功效」，背面「药名+归经+用法用量」
- 方剂学：正面「方名」，背面「组成+功效+主治」
- 经典条文：正面「条文编号」，背面「原文+白话翻译」
- 经络穴位：正面「穴位名」，背面「定位+主治+归经」
```

### 3. 笔记工具：Obsidian（推荐 ⭐⭐⭐⭐）

**为什么用 Obsidian？**
- 本地存储，数据完全掌控
- 双向链接，构建知识网络
- 支持 Markdown，写作体验好
- 有大量插件（思维导图、日历、Git 同步等）

**中医学习中的用法：**
```
文件夹结构建议：
- 00-Inbox（收件箱，临时笔记）
- 10-中医基础（中基、中诊、中药、方剂）
- 20-中医经典（内经、伤寒、金匮、温病）
- 30-临床课程（内、外、妇、儿）
- 40-西医基础（解剖、生理、病理、药理）
- 50-跟诊笔记（按老师分类）
- 90-MOC（地图页，汇总各主题）
```

## ⚙️ 工具配置教程

### Zotero 中医文献管理配置

1. **安装 Zotero**：到官网下载安装（https://www.zotero.org/）
2. **安装浏览器插件**：Zotero Connector
3. **配置 CNKI 抓取**：
   - 安装"茉莉花"插件（Jasminum）
   - 可以正确抓取 CNKI、万方的中文文献元数据
4. **创建分类**：
   - 右键「我的文库」→「新建分类」
   - 按课程或主题分类
5. **打标签**：选中文献 → 右侧栏「标签」→ 输入标签名

### Anki 中医牌组配置

1. **下载 Anki**：https://ankiweb.net/
2. **安装中文支持插件**（可选）：
   - 在 Anki 中：`工具` → `插件` → `获取插件`
   - 搜索中文相关插件
3. **创建牌组**：
   - `创建牌组` → 命名（如「中药学」）
4. **制作卡片**：
   - 正面：问题（如「功效：发汗解表、宣肺平喘」）
   - 背面：答案（如「麻黄」+ 图片 + 笔记）

## 💡 工具使用心得

:::tip 工具使用三原则
1. **工具是手段，不是目的**：不要沉迷于折腾工具，而忽略了学习内容本身
2. **越少越好**：工具太多反而增加认知负担，精选 2-3 个深度使用
3. **坚持记录**：工具的价值在于长期使用积累的数据
:::
