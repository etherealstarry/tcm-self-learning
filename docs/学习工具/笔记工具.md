# 笔记工具 —— Obsidian 使用指南

!!! tip "为什么要用笔记工具？"
    中医知识**零散、联系复杂**：
    
    - 学中药时 → 要联系方剂
    - 学方剂时 → 要联系中医基础（辨证）
    - 学临床时 → 要联系基础、经典
    
    用**双链笔记**（Obsidian），可以把所有知识**连成网络**，而不是孤立的笔记。

---

## 📓 什么是 Obsidian？

Obsidian 是一款**双链笔记**软件。

!!! success "核心特点"
    - **双链**：笔记之间可以互相链接，形成知识网络
    - **本地存储**：数据在你自己电脑里，安全
    - **免费**：基础功能完全免费
    - **插件丰富**：可以扩展功能

## 🎯 怎么用 Obsidian 学中医？

### 第一步：建立知识网络

!!! example "双链示例"
    **笔记A**：《中医基础学》→ 链接到 → **笔记B**：《黄芪》
    
    **笔记B**：《黄芪》→ 链接到 → **笔记C**：《补气药》
    
    **笔记C**：《补气药》→ 链接到 → **笔记D**：《脾胃学说》
    
    这样，所有和"补气"相关的笔记，都**连在一起**了。
    
    点击任何一个笔记里的链接，就能**跳转**到相关笔记。

### 第二步：用标签（Tag）分类

!!! example "标签使用示例"
    - 笔记《黄芪》→ 加标签 `#中药 #补气药`
    - 笔记《补中益气汤》→ 加标签 `#方剂 #补气剂`
    - 笔记《脾胃虚弱》→ 加标签 `#证候 #脾胃系`
    
    然后，点击标签 `#补气药`，就能看到**所有补气药**的笔记。

### 第三步：用图谱（Graph View）查看知识网络

!!! success "图谱的作用"
    Obsidian 可以生成**知识图谱**：
    - 每个笔记 = 一个节点
    - 每条链接 = 一条线
    
    你可以**直观地看到**：
    - 哪些笔记是"核心"（连线最多）
    - 哪些笔记是"孤岛"（没有链接）
    
    !!! tip "怎么用图谱？"
        定期查看图谱，**把"孤岛"连起来**。
        
        比如：笔记《黄芪》是孤岛 → 把它链接到《补气药》、《补中益气汤》。

## 📝 笔记模板推荐

### 模板1：中药笔记
!!! quote "笔记模板"
    ```markdown
    # 黄芪
    
    ## 基本信息
    - **药性**：甘，微温
    - **归经**：归脾、肺经
    - **功效**：补气升阳，固表止汗，利水消肿，生津养血，托毒排脓
    
    ## 临床应用
    - 脾胃气虚 → 补中益气汤
    - 表虚自汗 → 玉屏风散
    - 气血两虚 → 十全大补汤
    
    ## 鉴别用药
    - vs 人参：人参补气力强，黄芪补气升阳为主
    - vs 白术：白术健脾燥湿，黄芪补气固表
    
    ## 我的笔记
    ......
    
    #中药 #补气药
    ```

### 模板2：方剂笔记
!!! quote "笔记模板"
    ```markdown
    # 补中益气汤
    
    ## 组成
    黄芪18g，炙甘草9g，人参6g，当归3g，橘皮6g，升麻6g，柴胡6g，白术9g
    
    ## 功效
    补中益气，升阳举陷
    
    ## 主治
    - 脾胃气虚证
    - 气虚下陷证
    - 气虚发热证
    
    ## 方解
    - 黄芪 → 君，补中益气
    - 人参、白术、炙甘草 → 臣，补气健脾
    - 当归 → 佐，补血
    - 陈皮 → 佐，理气
    - 升麻、柴胡 → 使，升阳举陷
    
    ## 联系
    - [[黄芪]]（君药）
    - [[脾胃学说]]（理论基础）
    
    #方剂 #补气剂
    ```

### 模板3：医案笔记
!!! quote "笔记模板"
    ```markdown

    ## 患者

    ## 我的思考
    ......
    
    ## 蒲老思路
    ......
    
    #医案 #太阳病 #麻黄汤证
    ```

## 🔧 Obsidian 插件推荐

| 插件名 | 功能 | 推荐指数 |
|---------|------|---------|
| Calendar | 日历视图，方便写日记 | ⭐⭐⭐⭐⭐ |
| Templater | 笔记模板，一键生成 | ⭐⭐⭐⭐⭐ |
| Dataview | 把笔记当数据库，生成表格 | ⭐⭐⭐⭐ |
| Excalidraw | 在 Obsidian 里画图 | ⭐⭐⭐⭐ |
| Mind Map | 把笔记生成思维导图 | ⭐⭐⭐⭐ |

!!! warning "插件安装方法"
    1. 打开 Obsidian 设置
    2. 第三方插件 → 关闭"安全模式"
    3. 浏览社区插件 → 搜索插件名 → 安装
    4. 启用插件

## 💡 给自学者的建议

!!! tip "Obsidian 使用心法"
    1. **别追求完美**：笔记是给自己看的，不是给别人看的
    2. **先写起来**：别花太多时间"折腾"插件、主题
    3. **定期复习**：Obsidian 不是 Anki，没有间隔重复功能
    4. **配合 Anki 使用**：Obsidian 整理知识网络，Anki 记忆碎片知识

!!! danger "别犯这个错"
    很多人用 Obsidian，**只顾"折腾"插件、主题**，笔记没写几篇。
    
    记住：**笔记内容 > 工具本身**。
