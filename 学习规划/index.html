    学习规划¶

    为什么需要学习规划？

    中医学习体系庞大、内容繁多，没有规划 = 盲人摸象。

    本版块为不同基础、不同目标的学习者，提供详细的学习计划。

    • 每周学什么？
    • 每天学多久？
    • 重点是什么？
    • 怎么复习？

    让你不迷茫、不浪费时间。

    🎯 选择你的学习规划¶

    学习者类型 学习目标 预计时间 规划文档
    零基础入门 了解中医基础，能给自己和家人做简单辨证 2-3年（每天1-2小时） 开始学习 →
    中医学生 系统学习，通过执业医师考试，未来从事中医临床 5年（按学校进度） 开始学习 →
    在职自学 工作之余自学，掌握中医养生和简单辨证 3-5年（每天1-2小时） 开始学习 →
    执业医师备考 短期冲刺，通过执业医师资格考试 6-12个月（高强度） 开始备考 →
    考研备考 短期冲刺，通过中医综合考研 6-12个月（高强度） 开始备考 →

    别贪多

    先确定自己属于哪一类，专注这一条路径。

    别同时看好几条路径，最后哪条都没坚持下来。

    📋 通用学习法（适用于所有规划）¶

    第一步：制定学习计划（每周日）¶

    每周学习计划示例

    ## 第X周学习计划（202X年X月X日 ～ X月X日）

### 本周目标
- 学完《中医基础学》第X章
- 背诵XX个中药功效
- 做XX道练习题

### 每日安排
- 周一：学第X章第1节（30分钟）
- 周二：学第X章第2节（30分钟）
- 周三：复习第1-2节 + 做习题（30分钟）
- ......

### 本周自测
- 自测题得分：XX/100
- 不懂的地方：......

    第二步：按计划学习（每天）¶

    学习三步骤

    1. 学前预习（5分钟）：先看学习目标和知识框架
    2. 正式学习（30-60分钟）：读正文，重点看生活例子和临床意义
    3. 学后复习（10-15分钟）：做自测习题，检验效果

    第三步：每周复盘（每周日）¶

    复盘三问

    1. 本周计划完成了吗？ → 没完成，为什么？
    2. 自测题得分多少？ → 低于80分，回头重学
    3. 有什么不懂的地方？ → 记下来，下周重点学

    第四步：定期总复习（每月末）¶

    总复习方法

    • 知识框架：用思维导图梳理本月学的知识
    • 错题重做：把本月错题重新做一遍
    • 临床联系：尝试用本月学的知识，分析一个真实病例（或医案）

    🎓 学习方法推荐¶

    方法1：费曼学习法（Feynman Technique）¶

    怎么用？

    1. 学完一个知识点 → 想象你在教一个完全不懂的人
    2. 用大白话讲出来（或写下来）
    3. 讲不下去的地方 = 你没懂的地方 → 回头重学

    为什么有效？

    能把别人讲懂 = 真的懂了。

    讲不下去 = 还有盲区，需要补。

    方法2：间隔重复法（Spaced Repetition）¶

    怎么用？

    • 学完 → 1天后复习
    • 复习后记住了 → 3天后再复习
    • 又记住了 → 7天后再复习
    • …… → 逐渐拉长间隔

    工具推荐

    • Anki：自动安排复习时间
    • 详见 记忆工具指南

    方法3：主题阅读法（Syntopic Reading）¶

    怎么用？

    比如想学"胃痛"的治疗： 1. 找5-10个名老中医的医案/专著 2. 对比他们的辨证思路和用药特点 3. 总结出自己的"胃痛诊疗思路"

    为什么有效？

    一本书的观点可能是片面的。

    多本书对比 = 更全面的理解。

    📝 笔记方法推荐¶

    方法1：康奈尔笔记法（Cornell Note-taking System）¶

    笔记格式

    ## 页面顶部：标题（比如：脾胃虚寒证）

### 右侧（笔记区）：正式笔记
- 病因：饮食不节、劳累过度、久病体弱
- 病机：脾胃阳气虚衰，阴寒内盛
- 症状：胃脘隐痛，喜温喜按，纳差，乏力......
- 治法：温中健脾 → 黄芪建中汤

### 左侧（线索区）：关键词
- 病因
- 病机
- 症状
- 治法

### 页面底部：总结（用自己的话）
脾胃虚寒 = 脾胃阳气不足 → 寒从内生 → 温中健脾

    康奈尔笔记法的优点

    • 线索区：复习时遮住右侧，只看关键词回想 → 检验记忆效果
    • 总结区：用自己的话总结 = 深度理解

    方法2：双链笔记法（Obsidian）¶

    笔记格式

    # 脾胃虚寒证

## 基本信息
- 病因：饮食不节、劳累过度、久病体弱
- 病机：脾胃阳气虚衰，阴寒内盛

## 临床症状
- 胃脘隐痛，喜温喜按
- 纳差，乏力
- 大便溏薄
- 舌淡胖，苔白，脉沉细

## 治法方药
- 治法：温中健脾
- 方药：黄芪建中汤

    • 自动推荐：Obsidian 会推荐"你可能想看的笔记"

    💡 给自学者的建议¶

    学习心法

    1. 理解 > 背诵：理解了才能灵活运用，死记硬背考试完就忘
    2. 边学边用：学了就要用（给自己辨证、给家人辨证）
    3. 定期复习：每周复盘、每月总复习，别学完就忘
    4. 别贪多：选一条路径，坚持学完，胜过门门都懂一点
    5. 交流讨论：加几个中医学习群，和同龄人交流，进步更快

    自学最常见的误区

    • 误区1：只看不练 → 看懂了 ≠ 会用了
    • 误区2：只背不思考 → 背了很多，但不会用
    • 误区3：贪多不精 → 同时看好几本书，最后哪本都没读完
    • 误区4：不复习 → 学完就忘，等于没学
