    使用指南¶

    欢迎使用中医自学指南！本指南按照 CS自学指南（csdiy.wiki） 的保姆级标准制作。

    🎯 首先，确定你的学习目标¶

    在开始之前，请先明确你属于哪一类学习者：

    类型A：零基础自学中医爱好者¶

    • 目标：了解中医基础，能给自己和家人做简单辨证，会用常见中成药
    • 时间：每天1-2小时，坚持2-3年
    • 路径：零基础入门规划

    类型B：中医专业学生（本科/研究生）¶

    • 目标：系统学习，通过执业医师考试，未来从事中医临床
    • 时间：按学校教学安排，配合本指南深化理解
    • 路径：中医学生规划

    类型C：在职医务人员（西医转中医/中西医结合）¶

    • 目标：快速掌握中医临床技能，通过相关考试
    • 时间：每天2-3小时，坚持1-2年
    • 路径：在职自学规划

    类型D：备考执业医师/考研¶

    • 目标：短期冲刺，通过考试
    • 时间：集中3-6个月高强度复习
    • 路径：执业医师考试备考 | 考研指南

    📚 网站内容结构说明¶

    本网站的内容按照北京中医药大学的培养方案设计，分为以下板块：

    1. 必修课程（核心内容）¶

    • 中医基础：中医基础学、中医诊断学 → 学习重点
    • 中药方剂：中药学、方剂学 → 学习重点
    • 中医经典：黄帝内经、伤寒论、金匮要略、温病条辨 → 学习重点
    • 临床课程：中医内科学、外科学、妇科学、儿科学 → 学习重点
    • 针灸推拿：经络腧穴学、针灸治疗学、推拿学 → 学习重点
    • 西医基础：解剖学、生理学、病理学、药理学、诊断学、内科学 → 学习重点

    2. 拓展资源（深化理解）¶

    • 名老中医医案 → 学习临床思路
    • 临床跟师指南 → 如何跟师学习
    • 病案研读方法 → 如何读医案
    • 学术资源导航 → 论文、数据库使用
    • 中医APP推荐 → 实用工具

    3. 学习工具（提高效率）¶

    • 记忆工具（Anki） → 中药、方剂、穴位记忆
    • 笔记工具（Obsidian） → 知识管理
    • 文献管理工具（Zotero） → 论文写作
    • 思维导图工具 → 知识梳理

    4. 考试专区（应试必备）¶

    • 执业医师考试 → 大纲、真题、备考规划
    • 考研指南 → 中医综合考研复习

    🚀 快速开始：第一次使用本网站¶

    如果你是零基础：¶

    1. 先读 零基础入门规划 → 明确学习顺序
    2. 从 中医基础学 开始 → 每天读1-2节
    3. 配合 Anki记忆卡片 → 背诵中药、方剂
    4. 遇到问题 → 查 常见问题 或 学术资源

    如果你是中医专业学生：¶

    1. 先读 中医学生规划 → 配合学校课程
    2. 每学完教材一章 → 来本网站对应页面深化理解（看生活例子、临床意义）
    3. 每章学完 → 做 自测题 检验效果
    4. 实习前 → 重点读 临床跟师指南 和 名老中医医案

    如果你是备考执业医师：¶

    1. 直接去 执业医师考试 板块
    2. 先读 考试大纲 → 明确范围
    3. 按 备考规划 安排时间
    4. 刷 历年真题 → 熟悉题型

    💡 保姆级学习法：如何最大化利用本网站¶

    第一步：学前预习（5分钟）¶

    • 打开要学的章节 → 先看学习目标和重点提示
    • 浏览知识框架图 → 了解整体结构

    第二步：正式学习（30-60分钟）¶

    • 读正文 → 重点看生活例子（用大白话解释概念）
    • 理解临床意义 → 每个知识点都讲"有什么用"
    • 做笔记 → 用 Obsidian 整理

    第三步：学后测试（10-15分钟）¶

    • 做 自测习题（每个页面底部都有）→ 检验掌握程度
    • 错题 → 记在 Anki 里复习

    第四步：临床联系（可选）¶

    • 读对应的 名老中医医案 → 看临床怎么用
    • 如果有条件 → 去诊所/医院见习，观察实际病例

    📅 学习时间规划参考¶

    学习者类型 每天时间 学习节奏 完成周期
    零基础爱好者 1-2小时 每周3-4次 2-3年
    中医专业学生 配合课程 按学校进度 5年
    在职医务人员 2-3小时 每周5-6次 1-2年
    备考执业医师 4-6小时 每天学习 3-6个月

    ❓ 常见问题解答¶

    Q1：学中医一定要背很多东西吗？¶

    A：是的，但理解后的背诵比死记硬背有效10倍。本网站每个知识点都配了生活例子和记忆口诀，帮你理解后自然记住。

    Q2：零基础能学会中医吗？¶

    A：能！但要有心理准备：中医理论体系独特，初期会有"玄学"感。坚持学完中医基础学和中医诊断学后，你会突然"开窍"。

    Q3：学中医需要学西医内容吗？¶

    A：需要！现代中医必须中西医并重。本网站包含 西医基础 板块，就是为了解决这个问题。

    Q4：如何检验学习效果？¶

    A：每个页面底部的 自测习题 就是为你设计的。做对80%以上 → 过关；低于80% → 回头重学。

    Q5：跟师学习重要吗？¶

    A：极其重要！中医是经验医学，很多东西教材里没有，必须跟师。详见 临床跟师指南。
