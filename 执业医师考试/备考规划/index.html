    执业医师考试 —— 备考规划¶

    重要提醒

    中医执业医师资格考试通过率约30-40%，不是那么容易过的。

    必须系统复习，不能靠运气。

    本规划帮你： - 明确每个阶段学什么 - 明确每周任务是什么 - 明确怎么复习才高效 - 明确怎么刷题才有效

    📅 总体时间规划（12个月）¶

    阶段 时间 核心任务 每天时间
    第一阶段：系统复习 第1-6个月 系统复习14门考试科目 3-4小时
    第二阶段：刷题 第7-9个月 刷真题 + 整理错题 4-5小时
    第三阶段：模拟考试 第10-12个月 模拟考试 + 查漏补缺 5-6小时

    在职人员，时间不够？

    • 每天3-4小时 → 延长到18个月
    • 每天2-3小时 → 延长到24个月
    • 别贪多，坚持 > 速度。

    📖 第一阶段：系统复习（6个月）¶

    目标¶

    • 把所有考试科目过一遍
    • 理解80%以上的知识点
    • 做完章节练习题

    每周任务安排¶

    第1-2个月：中医基础 + 中医诊断

    本周任务： - 中医基础理论：阴阳学说、五行学说 - 中医诊断学：望诊、闻诊

    每天安排： - 周一、三、五：学新教材（各1小时） - 周二、四、六：复习 + 做章节练习题（各1小时） - 周日：休息 or 补漏

    自测标准： - 章节练习题得分 ≥ 70分 → 过关 - 章节练习题得分 < 70分 → 回头重学

    第2个月结束，你能做到

    • 理解阴阳、五行的核心概念
    • 能给自己做简单辨证（比如：你是阳虚还是阴虚？）

    第3-4个月：中药学 + 方剂学

    本周任务： - 中药学：解表药、清热药 - 方剂学：解表剂、清热剂

    每天安排：同上

    自测标准： - 章节练习题得分 ≥ 70分 → 过关 - 章节练习题得分 < 70分 → 回头重学

    第4个月结束，你能做到

    • 认识100+味中药（功效、主治）
    • 认识50+首方剂（组成、功效、主治）

    第5-6个月：中医内科学 + 针灸学

    本周任务： - 中医内科学：肺系病证、心系病证 - 针灸学：经络腧穴学、针灸治疗学

    每天安排：同上

    自测标准： - 章节练习题得分 ≥ 70分 → 过关 - 章节练习题得分 < 70分 → 回头重学

    第6个月结束，你能做到

    • 掌握50+种常见病的辨证论治
    • 认识100+个常用穴位

    📖 第二阶段：刷题（3个月）¶

    目标¶

    • 刷完10年真题（2018-2028）
    • 整理错题集
    • 提高答题速度

    每周任务安排¶

    第7-8个月：按年份刷题

    本周任务： - 刷2-3年的真题（每年600题 → 2年=1200题） - 整理错题

    每天安排： - 周一、三、五：刷真题（各50-100题，2小时） - 周二、四、六：整理错题 + 复习错题（各2小时） - 周日：休息 or 补漏

    自测标准： - 真题得分 ≥ 70分 → 过关 - 真题得分 < 70分 → 回头复习对应章节

    刷题技巧

    • 第一遍：按年份刷（2018、2019、2020……）
    • 第二遍：按科目刷（中基、中诊、中药……）
    • 第三遍：只刷错题

    第9个月：刷模拟题 + 复习错题

    本周任务： - 刷3-5套模拟题 - 复习所有错题

    每天安排： - 周一、三、五：刷模拟题（各1套，2小时） - 周二、四、六：复习错题 + 查漏补缺（各2小时） - 周日：休息

    自测标准： - 模拟题得分 ≥ 70分 → 过关 - 模拟题得分 < 70分 → 回头复习对应章节

    📖 第三阶段：模拟考试（3个月）¶

    目标¶

    • 适应考试节奏（上午2小时 + 下午2小时）
    • 提高答题速度（600题/4小时 = 平均24秒/题）
    • 查漏补缺，冲刺高分

    每周任务安排¶

    第10-11个月：每周1次全真模拟考试

    本周任务： - 周六上午8:30-10:30 → 模拟上午场（中医基础、中诊、中药、方剂） - 周六下午14:00-16:00 → 模拟下午场（内科、外科、妇科、儿科、针灸、西医） - 周日 → 对答案 + 整理错题

    每天安排： - 周一、二、三、四、五：复习错题 + 查漏补缺（各2小时） - 周六：模拟考试（4小时） - 周日：对答案 + 整理错题（4小时）

    自测标准： - 模拟考试得分 ≥ 75分 → 过关 - 模拟考试得分 < 75分 → 加强复习

    模拟考试，必须全真！

    • 时间全真：上午8:30-10:30，下午14:00-16:00
    • 环境全真：找个安静的地方，手机静音，不准查书
    • 流程全真：先写姓名、考号，再答题

    第12个月：冲刺复习 + 调整心态

    本周任务： - 复习所有错题（至少再过2遍） - 查漏补缺（重点复习高频考点） - 调整心态（别紧张，正常发挥）

    每天安排： - 周一、二、三、四、五：复习错题 + 查漏补缺（各2小时） - 周六：模拟考试（4小时）→ 选最简单的套题，增强信心 - 周日：休息 + 调整心态

    考前1周，别再刷题了

    • 复习错题集
    • 复习高频考点
    • 调整作息（别熬夜，保持和考试时间一致）
    • 准备考试用品（准考证、身份证、2B铅笔、橡皮……）

    📝 错题集整理方法¶

    方法：按考试科目整理¶

    推荐格式

    ## 考试科目：中医基础理论

### 高频考点1：阴阳学说
- 阴阳的对立制约
- 阴阳的互根互用
- 阴阳的消长平衡
- 阴阳的互相转化

### 我的错题
1. **题目**：下列哪项不是阴阳的对立制约关系？
   - A. 阴胜则阳病
   - B. 阳胜则阴病
   - C. 阴虚则阳亢
   - D. 阳虚则阴盛
   - E. 阴阳离决

   **错误答案**：A
   **正确答案**：E
   **解析**：阴阳离决是阴阳**离决**，不是对立制约。

2. **题目**：......

    错题集整理技巧

    • 重点记高频考点
    • 错题必须整理，并且定期复习（用Anki）
    • 错题要写解析：为什么错？正确思路是什么？

    💡 备考建议（避坑指南）¶

    误区1：只刷题，不复习教材

    错误做法：只看真题，不系统复习教材。

    后果：考试题型会变，只刷真题 = 碰运气。

    正确做法：先系统复习教材，再刷题。

    误区2：不整理错题

    错误做法：刷完题，对完答案，就不管了。

    后果：同一个坑，掉进去两次。

    正确做法：错题必须整理，并且定期复习（用Anki）。

    误区3：临时抱佛脚

    错误做法：考前3个月才开始复习。

    后果：时间不够，复习不系统，通过率低。

    正确做法：提前12个月开始备考（基础差的，提前18个月）。

    误区4：不模拟考试

    错误做法：只刷题，不模拟考试。

    后果：考试时节奏掌握不好，时间不够。

    正确做法：考前3个月，每周1次全真模拟考试。

    误区5：忽视西医部分

    错误做法：只复习中医部分，不复习西医部分。

    后果：西医部分占60分，忽视 = 少60分。

    正确做法：西医部分也要复习（但不用追求高分，拿40-50分即可）。

    🎯 备考目标分数¶

    科目 总分 目标分数 说明
    中医基础理论 50 45+ 基础题，必须拿高分
    中医诊断学 50 45+ 基础题，必须拿高分
    中药学 50 40+ 记忆量大
    方剂学 50 40+ 记忆量大
    中医内科学 150 120+ 重中之重，占一半分值
    中医外科学 50 40+ 重点科目
    中医妇科学 50 40+ 重点科目
    中医儿科学 50 40+ 重点科目
    针灸学 50 40+ 重点科目
    西医诊断学 30 20+ 西医部分，不用追求高分
    西医内科学 30 20+ 西医部分，不用追求高分
    卫生法规 10 8+ 背一下就行
    医学伦理 10 8+ 背一下就行
    总计 600 500+ 目标：500+（稳过）

    分数分析

    • 500分 = 稳过（历年通过线约360-380分，500分很稳）
    • 450分 = 较稳（需要考前冲刺）
    • 400分 = 危险（需要运气）

    建议：按500分的目标备考，留有余地。

    📞 下一步行动¶

    1. 确定备考时间：看你属于哪一类（基础好/中等/差）
    2. 按规划复习：按本规划的每周任务执行
    3. 刷真题：去 历年真题 刷题
    4. 模拟考试：考前3个月，每周1次全真模拟考试
